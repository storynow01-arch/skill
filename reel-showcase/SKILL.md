# 素材展示網站（REEL 架構）

所有專案的展示網頁**共用同一套程式與外觀**。這份 skill 的 `assets/` 就是標準版：新專案直接複製進去、改設定；舊專案拿來覆蓋更新。**不要在各專案各自改版面**，要改外觀先改這裡的 `assets/`，再同步到各專案（見第八節），這樣所有展示版面才會一致。

來源：2026-10-09 在「從 skill 中直接生成影片」專案（`04_版本庫/`）設計並實測。

## 一、設計目標
1. **不擠在同一頁**：首頁看全貌、分區頁挑片、單支頁仔細看。
2. **像專業作品集網站**：深色放映廳風格，影片是主角，文字退到旁邊。
3. **挑選不用複製貼上**：按鈕一按就自動存檔，使用者挑完只要說「挑完了」。
4. **自動產生**：新增版本後跑一次程式就重建，不手改網頁。

## 二、四個分區

| # | 分區 | 放什麼 | 對應資料夾 |
|---|---|---|---|
| 01 | 待挑選 | 新做好、還沒決定的 | `待挑選/` |
| 02 | 純廣告 | 確定保留、沒有旁白 | `無配音_廣告/` |
| 03 | 旁白影片 | 確定保留、有旁白字幕 | `有配音/` |
| 04 | 收進 skill | 收進 GitHub skill 倉庫當範本的 | 不是資料夾，從 02、03 篩出來 |

```
Claude 做好新影片 → 01 待挑選（版本.json 先寫好「分區」＝它該去 02 還是 03）
   使用者按「要」  ──→ 整理待挑選.py 依「分區」移到 02 或 03
   使用者按「不要」──→ 資源回收筒（不是永久刪除）
02／03 按「＋ 收進 skill」──→ 出現在 04，標「等待收進 skill」
   Claude 照該 skill 的範本規格收進去、經使用者同意才 push ──→ 版本.json 加「收進skill」，04 改標「已收進」
```

分區名稱與說明在 `產生展示網頁.py` 的 `SECTIONS` 可以改（例如非影片專案把「純廣告／旁白影片」改成「海報／簡報」），但**資料夾代號、四區結構、流程不要改**。

## 三、頁面架構
```
展示網頁.html（首頁）
 ├─ 展示網頁素材/區_待挑選.html、區_無配音_廣告.html、區_有配音.html、區_收進skill.html
 └─ 展示網頁素材/片_<版本名>.html（每支一頁）
```

**首頁**：固定頂欄（左品牌字＋網站名，點了回首頁；中間四個分區附支數；右「挑選進度」）→ 大標題區（背景是封面斜排縮圖牆、60 秒來回緩慢飄移；前景超大標、一句說明、三個統計：待挑選／已保留／收進 skill）→ 四張分區入口卡（兩排兩列、右上大編號 01～04、右側三張封面疊、滑過散開）→「最新加入」6 支。

**分區頁**：大標＋支數＋說明 → 工具列（篩選標籤依「系列」或「做法」括號前文字自動產生；待挑選另有「未決定／要／不要」篩選；右側搜尋框）→ 影片牆（寬螢幕一排三支、手機一排一支）。

**影片卡片**：16:9 封面（右下片長；滑過放大 4% 並播 6 秒無聲預覽）→ 系列／做法（橘色小字）→ 片名 → 說明（最多兩行）→ 品檢圓點＋日期 → 動作按鈕：
- 待挑選：「要｜不要」膠囊按鈕＋「選『要』→ 放到純廣告／旁白影片」；選要封面左上綠色「要」，選不要封面變灰
- 純廣告、旁白影片：「＋ 收進 skill」虛線按鈕，按下變橘色實線「✓ 等待收進 skill」；已收進顯示綠色「已收進 skill：範本X」

**單支頁**：麵包屑（← 分區、第幾支／共幾支）→ 大播放器（圓角、深陰影，像銀幕）→ 左欄（系列／做法、片名、說明、動作按鈕＋下載成片、品檢結果可展開，有說明項自動展開）＋右欄（所在分區、選要後去向、收進 skill 狀態、做法、系列、素材、試做專案、日期、規格、附件）→ 上一支／下一支（鍵盤左右鍵也可以）。

**挑選進度抽屜**：右側滑出，分組列「要（附去向）／不要／還沒決定／等待收進 skill」，底部顯示「已自動存檔 幾點幾分」。

## 四、視覺規格

| 用途 | 深色（預設） | 淺色（系統淺色模式自動切換） |
|---|---|---|
| 背景 | #0d0d0f | #f4f1ea |
| 卡片 | #17171b | #fffdf8 |
| 主要文字 | #f2efe8 | #16140f |
| 次要文字 | #9a968e | #615c52 |
| 重點色（唯一） | #ff5a36 訊號橘 | #e0401c |
| 確定／通過／要 | #5fd39a | #21875a |
| 說明項／存檔警告 | #f2b14c | #a86500 |

- 全站只有一個重點色（橘），只用在標籤、按鈕、等待中、滑過強調；綠色只表示「確定、通過」。
- 字體：中文 Noto Sans TC（標題 900）、英文數字 Space Grotesk（品牌字、統計、片長、英文眉標），Google Fonts 載入，離線退回微軟正黑體。
- 版寬 1320、左右留白 32（手機 16）；英文眉標全大寫、字距 .22em、橘色；圓角卡片 14、入口卡 22、按鈕全圓角；頂欄半透明＋背景模糊。
- 動態：卡片滑過 0.6 秒緩出、抽屜滑入 0.35 秒；系統「減少動態效果」時全部關掉。
- 手機（≤900px）：頂欄分區換到第二行可橫滑、入口卡一欄、單支頁改上下排。

## 五、檔案（assets/ 全部複製到專案的展示資料夾，例如 `04_版本庫/`）

| 檔案 | 用途 |
|---|---|
| `產生展示網頁.py` | 掃描三個資料夾，產生全部頁面、封面、6 秒預覽。**換專案只改開頭「網站設定」與 `SECTIONS`** |
| `啟動展示網頁.bat` | 使用者雙擊這個開網頁（Windows 雙擊 .py 常常打不開）。**Big5（cp950）編碼＋CRLF**，用 UTF-8 存會變亂碼跑不動 |
| `啟動展示網頁.py` | 本機小伺服器（127.0.0.1:8765），提供網頁與 `/api/state`（讀寫 `挑選紀錄.json`）；`--no-open` 不自動開瀏覽器 |
| `整理待挑選.py` | 「挑完了」時執行；`--dry-run` 先看會做什麼 |
| `展示網頁樣式/site.css`、`site.js` | 外觀與互動原始檔（產生程式會複製到 `展示網頁素材/`） |

程式自動產生、可整個刪掉重建：`展示網頁.html`、`展示網頁素材/`。使用者資料：`挑選紀錄.json`（不要刪）。

需求：Python 3.10+（只用標準函式庫）、ffmpeg／ffprobe 在 PATH。

## 六、版本資料夾格式
`<分區資料夾>/<版本名>/`：成片 mp4、`最終品檢/final_qa.md`（讀 `- ✓`／`- ✗` 開頭的行）、其他附件（mp4／jpg／png 自動列為附件）、`版本.json`：

| 欄位 | 必填 | 用途 |
|---|---|---|
| 名稱 | ✓ | 片名 |
| 分區 | ✓ | `無配音_廣告` 或 `有配音`；在待挑選時決定選「要」後去哪 |
| 成片 | ✓ | 成片檔名 |
| 做法 | ✓ | 括號前文字變篩選標籤 |
| 說明 | ✓ | 一兩句 |
| 素材、試做專案、日期 | ✓ | 單支頁右欄 |
| 封面位置 | ✓ | 0～1，封面與預覽取的位置 |
| 品檢說明 | 有 ✗ 項時 | 為什麼不是錯 |
| 系列 | 選填 | 例如「廣告30風格 第1批」，優先當篩選標籤 |
| 收進skill | 收進後 | 例如「範本I_漫畫風」 |

`挑選紀錄.json` 格式：`{"待挑選": {"<版本名>": "要"|"不要"}, "收進skill": ["<版本名>"], "更新時間": "..."}`（版本名裡的空白與 `\/:*?"<>|` 會換成 `_`）。

## 七、Claude 的操作步驟

**A. 新專案建展示網站**
1. 把 `assets/` 全部複製到展示資料夾；建 `待挑選/`、`無配音_廣告/`、`有配音/`。
2. 改 `產生展示網頁.py` 開頭的 `BRAND／SITE／HERO_EN／HERO_TITLE／HERO_TEXT`，必要時改 `SECTIONS` 的說明文字（第 4 區說明要寫該專案對應的 skill 名稱）。
3. 若專案的 Claude Code 預覽要用：在專案根目錄 `.claude/launch.json` 加 `python <展示資料夾>/啟動展示網頁.py --no-open`、port 8765。
4. `PYTHONUTF8=1 py 產生展示網頁.py`，用瀏覽器驗證首頁、分區頁、單支頁、按鈕存檔（看 `挑選紀錄.json` 有沒有更新）。

**B. 舊專案換成這套（已有自己的展示網頁）**
1. 先盤點舊網頁的資料：每支影片補成第六節的資料夾＋`版本.json`；已保留的放 02／03，還沒決定的放 01。
2. 舊的網頁檔、舊產生程式移到資源回收筒（不要永久刪除），再照 A 做。
3. 舊網頁有、這套沒有的功能：先問使用者要不要，要就**改這份 skill 的 assets/**（第八節），不要只改那個專案。

**C. 做好新影片**：放進 `待挑選/<版本名>/`，`版本.json` 一定要寫「分區」→ 重建網頁 → 告訴使用者「雙擊 啟動展示網頁.bat 挑選」。

**D. 使用者說「挑完了」**：讀 `挑選紀錄.json` 回報「要幾支（各去哪）、不要幾支、還沒決定幾支」→ `PYTHONUTF8=1 py 整理待挑選.py`（會自動重建網頁）。版本資料夾裡有 `node_modules` junction 的，程式會略過並提醒——先拆 junction 再處理，否則會刪到共用套件。

**E. 收進 skill**：`挑選紀錄.json` 的「收進skill」清單不會自動處理。逐支照目標 skill 的範本規格（例如 storynow-aimovie-make 的 `templates/範本規格.md`）說明要怎麼收 → 使用者同意 → 做、commit／push 前再確認 → 在該版本 `版本.json` 加 `"收進skill": "範本X_名稱"`、從挑選紀錄移除該筆 → 重建網頁。

## 八、要改外觀或功能時（保持各專案一致）
1. 改這份 skill 的 `assets/`（樣式改 `展示網頁樣式/`，結構改 `產生展示網頁.py`；**網站設定那一段以外**的改動才算共用改動）。
2. 更新本文件對應段落，commit／push（經使用者同意）。
3. 各專案同步：把 `assets/` 覆蓋過去，但**保留該專案 `產生展示網頁.py` 開頭的網站設定與 SECTIONS 說明**（覆蓋後再貼回），然後重建網頁。

## 九、實測踩過的坑
- **直接雙擊 html 按鈕不會存檔**：瀏覽器沒辦法寫檔案，所以要本機伺服器；直接開檔時頁面頂端會出現黃色提示，資料只暫存瀏覽器。
- **Windows 雙擊 .py 打不開**（沒有檔案關聯）→ 用 .bat。
- **.bat 用 UTF-8 存＋`chcp 65001` 會亂碼**（cmd 換字碼頁後重讀位移錯掉，出現 `'itle' 不是內部或外部命令`）→ 存成 Big5、不要 chcp；`.gitattributes` 設 `*.bat -text` 防止 git 轉換。
- **PowerShell 5 的 `Set-Content -Encoding UTF8` 會加 BOM**，bat 第一行就壞；寫 bat 用 Python 指定 `encoding='cp950'`。
- **Claude Code 的瀏覽器預覽開 file:// 只給靜態快照、不載入 CSS**，驗證要用 launch.json 開伺服器。
- 預覽影片 6 秒、寬 640、24fps、crf 30、無聲、faststart：9 支約幾 MB，滑過就能播。

## 十、系列教學模式（2026-10-09，YouTube 教學頻道的每一科）

**用在**：storynow-aimovie-make 的「系列教學影片」——每一節的成片要留在自己的專案資料夾（分鏡、修改紀錄、品檢跟著它），
所以**不搬檔案**；分類是一節影片的生命週期，不是「要／不要」。外觀與互動沿用同一套 `site.css`（加 `series.css`），挑版本模式（第一～九節）不受影響。

| # | 分區 | 放什麼 | 按鈕 |
|---|---|---|---|
| 01 | 待確認 | 最終品檢通過、還沒看的成片（沒有狀態＝待確認） | 確定使用／要修改 |
| 02 | 要修改 | 看過要改的；單支頁寫「哪裡要改」 | Claude 讀 `展示紀錄.json` 的修改備註去改，重出後清掉狀態回到待確認 |
| 03 | 確定使用 | 確定要上的；單支頁有**上架清單**（從系列設定的提醒清單讀）可以勾 | 已上架（跳出框貼 YouTube 網址） |
| 04 | 已上架 | 已上傳 YouTube | 封面右上 ▶ YouTube 直接開 |
| 05 | 全部節次 | 系列設定.md 大綱表每一節：未做／製作中／待確認／要修改／確定使用／已上架 | 有成片的「看影片 →」 |

**頻道總覽**：頻道資料夾最上層 `展示網頁.html`，每一科一張卡（封面、已成片／全部、待確認、要修改、已上架、進度條），點進去是那一科。

**檔案**（`assets/系列教學/`）：
| 檔案 | 用途 |
|---|---|
| `建立系列展示網頁.py <頻道資料夾>` | **一鍵建立／同步**：程式複製到 `<頻道>/_展示網頁/`（覆蓋成 skill 最新版）、頻道層與每一科寫 `啟動展示網頁.bat`（Big5＋CRLF，路徑用 `%~dp0.`，不放中文資料夾名）、重建全部頁面 |
| `產生頻道總覽.py` | 重建頻道總覽＋每一科（make_video 出片後自動跑） |
| `產生系列展示網頁.py <科目>` | 單科重建。讀 `系列設定.md`（大綱表、播放清單、上架提醒清單）＋每一節資料夾 `NN_<節次>_<主題>/out/*.mp4`（不含 `_` 開頭的暫存）＋`out/<片名>_品檢/final_qa.md` |
| `啟動展示網頁.py` | 本機伺服器 127.0.0.1:**8766**（挑版本模式是 8765，可同時開）；服務整個頻道資料夾；`/api/state?s=<科目>` 讀寫 `<科目>/展示紀錄.json`；已經在跑就只開網頁 |
| `series.js`、`series.css` | 狀態按鈕、網址、修改備註、上架清單；分區頁由 JS 依狀態即時篩選（按了馬上換區，不用重建） |

`展示紀錄.json`：`{"狀態": {"<節次>": "要修改"|"確定使用"|"已上架"}, "YouTube": {"<節次>": "https://…"}, "修改備註": {"<節次>": "…"}, "上架清單": {"<節次>": [true, …]}}`（節次裡 `0-9A-Za-z統-` 以外的字換成 `_`）。

**Claude 的操作**：
- **新頻道／新科目**：`python <skill>/assets/系列教學/建立系列展示網頁.py <頻道資料夾>`（新科目要先有 `系列設定.md`）；之後每節出片 make_video 自動更新。
- **使用者說「看完了／確認好了」**：讀各科 `展示紀錄.json` 回報；「要修改」的逐節讀修改備註 → 改 → 重出 → 該節狀態刪掉（回到待確認）。
- **上架**：照單支頁的上架清單帶使用者做（storynow-aimovie-make 的上架參考）；使用者貼網址後就在「已上架」。
- 改外觀：改 `assets/系列教學/` 或共用的 `展示網頁樣式/site.css`，再跑一次 `建立系列展示網頁.py` 同步。

# 參考提示詞 #1：旗艦科技宣傳片（Flagship Cyber Trailer）

> 來源：使用者最初的提示詞（2026-09-30），原文保存、不修改。
> 成果：範例高中資訊科「攜手築夢·智造未來」60 秒宣傳片，以及延伸的研習說明影片（使用者評價：最驚喜）。
> 用法：要做「科技旗艦感」的影片時，以此為範本，只替換 {} 內的內容。

## 原文（逐字保存）

```
I would like to see you create a 1 minute promotional video programmatically. The video should be coded and rendered using whatever tools you need, and you are free to download anything needed. The theme of the video is - an official flagship promotional trailer for the Department of Information Technology at Example Senior High School (範例高中資訊科), titled "攜手築夢·智造未來".
This should be a sleek, production-ready video showcasing cutting-edge tech education and student triumphs:

1. AI & Software Engineering: Core coding with C and Python, algorithmic data structures, AI edge computing, smart IoT modules (ESP32/Arduino), and collaborative robot arm programming.
2. The Cradle of Champions: Celebrating 10 WorldSkills international competitors, 12 national gold medals, and the 56th National Skills Competition sweep (Gold/Silver/Bronze).
3. Academic Triumphs & Future Pathways: Over 50% admission rate to national universities (Taiwan Tech, YunTech, NKUST) and golden career prospects in AI and software development.

The visuals should feature clean cyber graphics, dynamic code overlays, and animated data counters. The audio must feature modern, driving Tech House or Cinematic Hybrid beats with crisp, impactful digital sound design.
```

> ⚠️ 事實更正（製作時發現）：「56th National sweep」實為南區分區賽包辦、全國賽銅牌；「Over 50%」使用者更正為約 34%。
> 範本化時，事實一律以使用者提供的資料為準，提示詞只負責「調性與形式」。

## 範本化版本

```
Create a {長度} {影片類型} programmatically, coded and rendered with whatever tools you need.
Theme: an official flagship {用途} for {單位}, titled "{標題}".
This should be a sleek, production-ready video showcasing {核心主題}:

1. {段落一名稱}: {段落一重點，具體名詞}.
2. {段落二名稱}: {段落二重點，含數字}.
3. {段落三名稱}: {段落三重點，含數字與名稱}.

The visuals should feature clean cyber graphics, dynamic code overlays, and animated data counters.
The audio must feature modern, driving Tech House or Cinematic Hybrid beats with crisp, impactful digital sound design.
```

## 這段提示詞推導出的設計決定（為什麼成品會驚喜）

| 關鍵字 | 設計決定 |
|---|---|
| 1 minute | 128 BPM × 32 小節 = 60.0 秒，所有切點落在小節線 |
| official flagship trailer | 開機終端 → Logo → 標題重拍衝擊；HUD 四角框＋OFFICIAL TRAILER 標籤 |
| sleek, production-ready | 統一色票與字型；閃白、故障切片、RGB 色差、掃描線、暗角；響度校正 |
| 1./2./3. 三段 | 三個章節，各有章節標籤與專屬主色（青／金／紫） |
| 每個具體名詞（C、Python、演算法、AI、ESP32、機械手臂…） | **每個名詞各有一個專屬動畫子場景**（打字視窗、BST 與排序、神經網路、晶片＋感測器、逆向運動學手臂） |
| WorldSkills / medals | 旋轉地球、金牌彈出、頒獎台、時間軸 |
| animated data counters | 所有數字從 0 跑到目標值，配計數嗶聲 |
| clean cyber graphics | 深藍、青霓虹、3D 透視格線 |
| dynamic code overlays | 兩側捲動程式碼雨＋打字視窗 |
| Tech House / Cinematic Hybrid | 四拍大鼓律動＋章節交界用上升音與低頻衝擊 |
| crisp, impactful digital sound design | 衝擊、上升、whoosh、故障、計數嗶聲，全部對準畫面事件 |

**驚喜的關鍵**：①每個名詞都變成一個會動的畫面、②一套統一的設計系統、③聲音與畫面對拍。

# 三種創意概念 — 1-1 通訊協定與封包（2 分鐘教學）（待選 ⛔）

> 依據：01_內容分析.md。三個概念共用骨架：**衝突①（聽不懂）→ 協定 → 衝突②（大檔塞不進）→ 封包 → 伏筆 IP**
> 旁白會依概念改寫口吻，但觀念與比喻都保留；改寫稿會先給您審。

## 概念 1：物流中心模擬器 Packet Logistics

**一句話**：把網路變成一座**俯視角的物流中心**。原文的「寄信」「搬家紙箱」「門牌」「編號」，在物流中心裡全都是真的東西。

```
Create a 2-minute lesson video programmatically, coded and rendered with whatever tools you need, teaching
"通訊協定與封包" (Protocol & Packet) to first-year vocational high-school students.
The whole lesson takes place in an isometric, toy-like logistics hub seen from above — two warehouses (two computers)
connected by roads (the network).

1. The Jam: a truck from Warehouse A arrives at Warehouse B, but B's dock rejects it — wrong labels, wrong door.
   The road is fine; the two sides just never agreed on how to ship.
2. The Agreement: both warehouses sign one shared shipping manual — label format, stamp position, which door —
   stamped "雙方都同意". Now every truck docks smoothly. That manual is the PROTOCOL.
3. The Giant Crate: a huge crate (a big file) is too wide for the road; it gets stuck and cracks.
4. Boxing Line: a conveyor slices the file into small boxes; each box gets a label with an address (門牌) and a
   number (#3/8). Boxes take different roads; one truck crashes, only that one box is re-sent; at Warehouse B the
   boxes arrive out of order and are sorted by number. That box is a PACKET.
5. Wrap-up: the manual + the boxes, side by side. The camera zooms onto a box label — the address is blank:
   "那個門牌長什麼樣子？" → next lesson: IP.

Visuals: clean isometric 2.5D blocks, soft pastel palette, tiny trucks and conveyors moving continuously,
labels that zoom in to show the text. Camera glides over the map; no hard cuts.
Audio: light, bouncy marimba / plucked-synth groove at 100 BPM; conveyor clicks, stamp thuds, truck horns, a
"ding" when a box docks. Narration: a calm, clear teacher.
```

| 項目 | 設計 |
|---|---|
| 世界觀 | 兩間倉庫＝兩台電腦，馬路＝網路 |
| 協定怎麼呈現 | 雙方蓋章的「出貨手冊」；沒有手冊時卡車被退件 |
| 封包怎麼呈現 | 輸送帶把大貨櫃切成小箱，貼上門牌與編號的標籤 |
| 三個理由 | 大貨櫃卡在窄路／一台車翻覆只重送那一箱／小箱分走不同路 |
| 鏡頭 | 俯視等角視角，鏡頭在地圖上平滑移動，不硬切 |
| 配樂 | 木琴／撥弦輕快 100 BPM＋蓋章、喇叭、到貨叮聲 |
| 適合 | **最清楚、最貼近原文的比喻**，學生最容易懂 |

## 概念 2：電腦小劇場 Two Computers Sitcom

**一句話**：兩台**有表情的電腦「小 A」和「小 B」**演一齣短劇。原文的「對不上話」「聽不懂」，直接變成角色之間的誤會和笑點。

```
Create a 2-minute lesson video programmatically, coded and rendered with whatever tools you need, teaching
"通訊協定與封包" to first-year vocational high-school students, as a short comic sitcom starring two personified
computers, 小A and 小B, with screen faces and expressive eyes.

1. Misunderstanding: 小A happily sends a file; 小B receives a speech bubble full of nonsense symbols and looks confused.
   The cable between them glows fine — "線是好的，但他們聽不懂彼此".
2. The Deal: a referee hands them a rulebook; they shake hands; a big stamp "雙方都同意的規則" — PROTOCOL.
   Quick quiz beat: 小B asks the audience "協定管的是電線，還是規則？" with a 3-second pause, then the answer pops.
3. Too Big: 小A tries to shove a giant file through the thin cable — it gets stuck like a sofa in a doorway; 小A sweats.
4. Cut It Up: 小A slices the file into small boxes, writes an address and a number on each, and launches them; they
   take different paths, one box falls off, 小B shouts "第 5 箱沒到！" and only that box is re-sent; 小B reassembles
   them by number with a happy face. Each box is a PACKET.
5. Ending: both bow like actors; 小B holds up a box with a blank address tag — "下一集：門牌是什麼？" (IP).

Visuals: flat cartoon characters with bouncy squash-and-stretch, comic speech bubbles, emoji-style reactions,
comic panel splits for before/after, bold onomatopoeia text (咚！卡住！). Bright, friendly colors.
Audio: playful ukulele / pizzicato comedy cue at 110 BPM, cartoon sound effects (boing, pop, slide whistle).
Narration: a lively narrator, with 小A and 小B voiced as short speech bubbles (two different TTS voices).
```

| 項目 | 設計 |
|---|---|
| 世界觀 | 兩台電腦是有表情的角色，整節課是一齣短劇 |
| 協定怎麼呈現 | 裁判遞規則書，兩人握手，大印章「雙方都同意」 |
| 封包怎麼呈現 | 小 A 把卡在網路線裡的大檔切成小箱，寫上門牌和編號再發射 |
| 互動 | 小 B 轉頭問觀眾課中測驗，停 3 秒 |
| 鏡頭 | 漫畫分格、角色特寫、誇張的擠壓伸展動畫 |
| 配樂 | 烏克麗麗／撥奏喜劇配樂 110 BPM＋卡通音效 |
| 聲音 | 旁白＋小 A、小 B 用兩個不同的 TTS 聲音說短句 |
| 適合 | **最好笑、最好記**，高一新生最有感 |

## 概念 3：穿越網路線 Inside the Cable

**一句話**：鏡頭**直接鑽進網路線裡面**，像科學紀錄片一樣，跟著資料在光的隧道裡旅行。

```
Create a 2-minute lesson video programmatically, coded and rendered with whatever tools you need, teaching
"通訊協定與封包" to first-year vocational high-school students, as a sci-fi documentary journey inside the network cable.

1. Dive In: the camera zooms from a classroom laptop into the network cable and into a glowing data tunnel.
   A message arrives at the other end but bounces off a locked gate — the two ends speak different "shapes".
2. The Handshake Gate: both ends hold matching keys; a gate unlocks only when both shapes match — "雙方都同意的規則".
   That agreement is the PROTOCOL. A floating label debunks the myth: "不是加速軟體，是聽得懂的規則".
3. Traffic Jam: a massive data block enters the tunnel and jams it, cracking with red warning lights.
4. Capsules: the block splits into glowing capsules, each tagged with an address and a sequence number; the tunnel
   branches into several routes; capsules race through different branches; one capsule shatters and only that one
   is re-sent; at the exit they dock in numbered order and rebuild the picture. Each capsule is a PACKET.
5. Exit: pull back out of the cable to the classroom; a capsule's address tag flickers "???" → next lesson: IP.

Visuals: neon light tunnel with depth, particles and speed lines, holographic labels, x-ray zoom-ins on capsules;
continuous forward camera motion through 3D-like space. Deep blue and cyan with warm orange accents.
Audio: cinematic ambient-electronic at 120 BPM with whooshes, scanner beeps and docking clicks.
Narration: a documentary-style narrator, curious and calm.
```

| 項目 | 設計 |
|---|---|
| 世界觀 | 網路線內部的光隧道，資料是發光的膠囊 |
| 協定怎麼呈現 | 兩端鑰匙形狀一致，閘門才打開 |
| 封包怎麼呈現 | 大資料塊卡住隧道 → 裂成貼了門牌、編號的膠囊 → 分走岔路 → 依序對接 |
| 鏡頭 | 一路往前衝的 3D 縱深鏡頭、速度線、X 光放大 |
| 配樂 | 電影感電子氛圍 120 BPM＋穿梭聲、掃描嗶聲 |
| 適合 | **最有科技感、最震撼**，跟資訊科形象最一致 |

| | 1 物流中心模擬器 | 2 電腦小劇場 | 3 穿越網路線 |

## 一、網址與網域的唸法（使用者確認，必照做）

稿子與字幕一律寫**專業寫法**（`www.google.com`、`com`、`edu.tw`），唸法只在「送進 Gemini 的文字」裡轉換，字幕不變。

| 稿子寫法 | 送 Gemini 的文字 | 唸出來 | 為什麼 |
|---|---|---|---|
| `mail.google.com` | `mail點google點com` | mail 點 google 點 com | 寫「.」時 Gemini 有時唸中文「點」、有時英文 dot，**不穩定**；直接寫中文「點」才穩 |
| 單獨的 `com`（「最右邊那一段 com」） | `點com` | 點 com | 原樣送：有時唸「點 com」、有時英文「dot com」、有時唸成中文「抗」（聲調錯）。寫成 `.com` 也一樣不穩 |
| `edu.tw`、`gov.tw` | `點E D U點T W`、`點G O V點T W` | 點 E D U 點 T W | **edu、gov 被唸成英文單字是錯的**（使用者抽檢 1-3 1:30）→ 逐字母 |
| 單獨的 `edu`／`gov`／`org`／`net` | 前面加「點」；edu／gov／tw 逐字母 | | 同上 |
| `www`（含單獨出現的「最左邊的 www」） | `triple W` | triple W | **不要唸「三 W」**（2026-10-05 使用者指定） |

實作（順序有關係，依序套用；skill 範本 A～D 的 `build.py` 已從 `engine/scripts/voices.json` 的 `gemini_replace` 自動套用這 3 條，另加「主機:埠號 冒號」「路徑 / 斜線」「拿掉中英文之間的空格」共 6 條，送 Gemini 時不再套 edge 時代的權宜詞典）：

```python
GEMINI_REPLACE = [
    # 1. 字母之間的「.」→ 中文「點」（網址）
    (r"(?<=[A-Za-z])\.(?=[A-Za-z])", "點"),
    # 2. 單獨出現的網域尾碼前面加「點」
    (r"(?<![A-Za-z.點])(com|edu|gov|org|net)(?=點tw|[^A-Za-z0-9]|$)", r"點\g<1>"),
    # （另有：www → triple W，見 voices.json）
    # 3. edu／gov／tw 逐字母
    (r"(?<=點)(edu|gov|tw)(?![A-Za-z])", lambda m: " ".join(m.group(0).upper())),
]
```

注意：JSON 裡寫反向參照要用 `"點\\g<1>"`；在 Windows 用 heredoc 產生 JSON 時 `\1` 會變成控制字元 `\u0001`（踩過），寫完要讀回來檢查。

## 二、其他唸法規則（同一專案已驗證）

| 寫法 | 唸法 | 備註 |
|---|---|---|
| `localhost:3000` | localhost 冒號 3000 | 規則：字母後面接「:數字」→「冒號」 |
| 路徑 `/`、`/about` | 斜線、斜線 about | 規則：前面不是英數字的「/」→「斜線」（`MB/s` 不動） |
| 連接埠、號碼 443、1023、49151、65535、104 | 逐字唸（四四三、一零二三…） | 3000 照開發者慣例唸「三千」 |
| `2.4 GHz` | 二點四 G H z | 個位數.個位數 逐字唸，避免「二又四」 |
| `12.5`、`99.9%` | 交給聲音唸「十二點五」「九十九點九」 | **不要逐字唸**（2026-10-06 抓到：舊規則把兩位數小數也逐字，12.5 變「一二點五」）；只有個位數（2.4）與三位數（IP 前綴 192.168）逐字 |
| 版本號 `3.11`、`3.12` | 三點十一、三點十二 | 寫在數字詞典，且數字詞典要比兩段式數字規則**先**套用 |
| 「切成」「要切」 | qiē | 多音字清單若寫 qiè 是清單錯 |

edge-tts 時代的權宜寫法（多音詞同音字替換、ping→聘、about→額抱特、mail／GET／gov 逐字母、Mega→Megah）**送 Gemini 時要跳過**（Gemini 唸得好，替換反而怪）。但 edu／gov 在網域裡仍要逐字母（上一節）。

## 三、Gemini 配音的已知坑

1. **「；」會被切成兩句**：Gemini＋faster-whisper 對齊後的句級時間會在分號切開，原文「一行一句」對不上 → 字幕還原失敗、物件 cue 找不到。
   修法：原文切句候選多一組「在 。？！； 切」，或稿子避免用「；」連兩句。
2. **「……」停頓行會被當成一句**（edge-tts 不會），而且可能被唸成「嗯」：清完標點變成空白字幕頁（畫面閃 1 秒空字幕）。
   修法：對句前先濾掉唸不出聲音的句子；字幕清完標點是空的就不出那一頁。
3. **改稿要連分鏡畫面文字一起改**：只改旁白，畫面上會留舊說法（例：旁白改成「UDP 是平信」，卡片還寫「UDP 是廣播」）。footer 文字跟旁白不同也會被「文不對題」擋下。
4. **語速**：同一個聲音、不同風格指示，同一段 135 字可以從 23 秒到 36 秒。換聲音或風格後先量「字/秒」，再估整集長度。
5. **重配會整段重來**：Gemini 每次結果不同，改一場的字，同一段（約 700 字）的其他場也會變 → 整節要重新聽檢、重渲。
6. **AI 耳朵要知道唸法約定**：提示詞要寫明「網址的點唸『點』、單獨 com／edu.tw 前加唸『點』、edu／gov／tw 逐字母、主機:埠號 唸冒號、路徑 / 唸斜線，照這樣唸不算錯」，否則每一場都報「多唸了點」。
7. **AI 耳朵每次結果不一定一樣**（同一段第一次說「快取」唸歪、第二次沒抓到）→ 抓到的疑點都要給人聽，不要只看 0 疑點就放行。
8. **中英文之間的半形空格可能讓字母前後停頓**（2026-10-05，07_skill實作 1-1）：「用 B 方式送」用 02 聲音整段配音時 B 後面停了 0.3 秒；同一句用克隆聲音單句試配，有空格、沒空格都沒停。→ 不是每次都會發生，但空格是誘因之一。
   修法：稿子與字幕照排版規則留空格，送 Gemini 前拿掉（`voices.json` 的 gemini_replace 第 6 條；skill 範本 A～D 的 `build.py` 已自動套用）。

## 四、克隆聲音 storynow01（使用者本人）

| 項目 | 內容 |
|---|---|
| 聲音 id | `voice_nnlcixjak9lc`（replicated，gemini-3.8-flash-tts） |
| 存在哪 | Google AI Studio 付費專案（金鑰指紋 ff300a38）。**別的專案 `.env.local` 必須放同一把金鑰**，換金鑰就找不到 |
| 期限 | 最後一次使用後保留一年 |
| **選定風格（11C）** | `道地台灣華語口音，不捲舌、不兒化，像跟學生面對面輕鬆講解，口語自然但咬字清楚，語速稍快、節奏明快，句與句之間停頓短` |
| 風格 11（不加速） | `道地台灣華語口音，不捲舌、不兒化，像跟學生面對面輕鬆講解，口語自然但咬字清楚` |
| 也很像的風格 | 05 `像跟學生面對面聊天，口語、放鬆，語氣隨性但清楚`；09 `道地台灣華語口音，不捲舌、不兒化，輕聲自然，像台灣本地老師說話` |
| 不要用 | 「講座講師、沉穩、語速偏快」這類風格 → 克隆聲音會不像本人 |
| 語速 | **11C 約 5.2 字/秒**（選定；30 分鐘約 9,400 字）。風格 11 不加速只有 4.3～4.8 字/秒，比 edge-tts 舊聲音長 13～26%，教學整集會超過 33 分 → 使用者選 11C（另兩個方案：錄好後 atempo 1.10／1.15 加速） |

怎麼判斷「不像」是風格還是樣本的問題：先用**不加風格**合成一段——不加風格就像，問題在風格指示；連不加風格都不像，要重錄克隆樣本（30～60 秒、平常上課語氣、無回音雜音）。

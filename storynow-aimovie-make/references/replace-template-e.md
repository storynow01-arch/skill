## ② 範本E 自我測試的 22 種做壞

影片、字幕、同步三層：`python final_qa/acceptance_e.py <專案>`，用範本E selftest 同一套 ffmpeg 做壞方法，做壞一支系列影片（卡諾圖 2，範本D），交給系列品檢實際跑。

| 層 | 範本E 的項目 | 系列品檢由誰抓 | 結果 |
|---|---|---|:-:|
| 影片 | 黑畫面 | final_qa F3 | ✓ |
| 影片 | 中段無聲 | final_qa F7 | ✓ |
| 影片 | 響度差 10 dB | final_qa F6 | ✓ |
| 影片 | 凍結 6 秒 | final_qa F4（參考值，範本E 也只列數值）；講話時 ≥8 秒另有 D4 | ✓ |
| 影片 | 單格突跳 | final_qa F11 | ✓（**修過**，見下） |
| 影片 | 字幕閃 1 格 | final_qa F1 | ✓（**修過**） |
| 影片 | 字幕抖動 | final_qa F2 | ✓（**修過**） |
| 字幕 | 句尾標點、唸法殘留、以「的」開頭、超過 18 字、和稿子不符 | final_qa G1、G5、G6、G2、G3 | ✓×5 |
| 同步 | 物件沒對旁白 | build.py 文不對題 | ✓ |
| 同步 | 講完又循環 | — | 不適用（範本E 自己的焦點輪播動畫，2026-10-03 已移除；範本 A～H 沒有） |
| 版面 | 超出畫面 | QaProbe | ✓（原本就有） |
| 版面 | 對比不足 | QaProbe L.對比 | ✓（移植，範本D 實測） |
| 版面 | 標題過長、詞中斷行 | QaProbe（HTML 自動換行的字） | 移植；範本 A～D 遇到長句是縮小字級或拆段，幾乎碰不到 |
| 版面 | 畫面空白 | qa.py（場景開始 4 秒還沒有內容文字） | 移植 |
| 版面 | 間距過小、圖塊重疊、版面偏移 | QaProbe（範本標 `data-qa-strict` 才量） | 移植；範本E 卡片式排版專用——範本A 像素方塊、範本H 視窗互疊套用會有上百處誤報 |

**13/13 項有效**（影片＋字幕＋同步，另 1 項不適用）。版面層 8 項都已移植；「故意做壞會被抓到」範本E 用自己的測試場景（`_qa_fixture`），範本 A～H 沒有對應，所以這幾項只驗證了「真實影片不誤報」。

### 驗收過程抓到的系列品檢漏洞（都已修好、已加進自我測試）

| 漏洞 | 原因 | 影響 |
|---|---|---|
| F1 字幕閃爍、F2 字幕抖動永遠 0 | 字幕偵測只找 >190 的白，範本D 白板紙 ≈238，整條字幕帶都被當成字幕 | **所有淺色範本**的這兩項一直是假通過 |
| F11 單格突跳抓不到 | 一格跑掉又跳回來＝連續兩格一樣大的變化，「下一格要小於 1/3」兩格都不成立 | 最常見的「閃一下」從來抓不到（深淺色都一樣） |
| F2 誤報 | 範本D 的馬克筆滑進字幕帶，外框變了 | 改成比整頁字幕的輪廓平移 |
| F1 誤報 | 字幕淡入時黑邊是半透明灰；馬克筆筆尖在兩頁空檔滑過字幕帶 | 黑邊門檻 70 → 160；面積不到一般字幕 20% 不算 |

自我測試加了「淺色底／深色底 × 乾淨／閃 1 格／抖動／單格突跳」8 個案例，避免再發生「只在範本E 的深色背景驗證過」。

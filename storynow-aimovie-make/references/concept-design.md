# 創意概念設計（第 ④ 步）

## 「不同」要不同在哪一層
| 層級 | 例子 | 只改這層的結果 |
|---|---|---|
| **1 世界觀**（影片是什麼世界、怎麼說故事） | 遊戲闖關／手繪筆記／物流中心／角色短劇／光隧道 | — |
| **2 構圖與鏡頭** | 側捲軸／一鏡到底／等角俯視／漫畫分格／縱深衝刺 | — |
| **3 剪接節奏** | 每半拍硬切／零剪接長鏡頭／分格切換 | — |
| 4 外觀 | 色票、字型、背景、光暈 | 使用者說「看起來差不多」 |
| 5 微動畫 | 解碼、霓虹閃爍、彈跳 | 使用者說「受限在原始提示詞」 |

**3 個概念必須在 1–3 層都不同**，4–5 層跟著概念走。只在 4–5 層變化＝換皮，不能當成三個概念交出去。

## 從內容推概念的方法
1. 從 ② 的分析拿出：**觀眾、想要的感覺、內容骨架（衝突→解答）、原文比喻**。
2. 每個概念回答一句話：「這支影片就是 ____」。好的答案是一個具體的世界：
   - 「整支影片就是一款遊戲，國中生是 Lv.1 新手」
   - 「網路是一座物流中心，寄信和紙箱都是真的東西」
   - 「兩台有表情的電腦在演短劇，聽不懂＝角色誤會」
3. 三個概念刻意分散在不同的情緒：**好玩／溫暖理解／震撼酷炫**（或依問答結果調整）。
4. 把內容骨架的每一步，翻譯成這個世界裡的事件（協定＝出貨手冊蓋章、封包＝輸送帶切箱）。
5. 為每個概念指定：鏡頭語言、剪接節奏、配樂曲風與 BPM、音效家族、字幕樣式、旁白口吻。

## 內容 → 視覺化對照表
| 內容類型 | 視覺化方式（任選，要配合概念世界） |
|---|---|
| 數字 | 計數器＋計數音效、數字本身變成畫面（「10」裡是地圖）、經驗值條 |
| 流程 | 光點／車輛／膠囊沿路徑前進、輸送帶、關卡地圖 |
| 清單 | 逐項亮起、打勾、道具欄解鎖 |
| 定義 | 關鍵字高亮＋底線、取得道具、蓋章 |
| 比較／迷思 | 左右對照、敵人 vs 勇者、✕ 與 ✓ |
| 時間 | 時間軸、關卡進度 |
| 地點 | 路線圖、地圖釘 |
| 程式 | 打字視窗、程式碼碎片、終端機 |
| 榮耀 | 獎牌掉落、頒獎台、名人堂、拍立得 |
| 問答 | 選單游標跳動→揭曉、思考計時條、停頓 2–3 秒 |
| 抽象觀念 | 用原文比喻做成實景（寄信、搬家、紙箱、門牌） |

## 提示詞格式（沿用使用者原始提示詞的寫法）
```
Create a {長度} {類型} programmatically, coded and rendered with whatever tools you need, {目的與觀眾}.
{一句話世界觀}. Title: "{標題}".

1. {段落}: {這個世界裡發生什麼，含具體名詞與數字}.
2. ...
5. {結尾／伏筆}.

Visuals: {構圖、鏡頭、剪接、質感}.
Audio: {曲風 BPM、音效家族}. Narration: {口吻、聲音數}.
Avoid: {不放的術語、個資、資料外的說法}.
```
每個概念另附：中文對照、設計表（世界觀／協定或主題怎麼呈現／鏡頭／配樂／適合誰），最後一張三概念比較表。

**共通音效**：衝擊（Impact：低頻爆破＋高頻碎裂＋殘響）、上升音（Riser：掃頻噪音＋滑音，自動加在衝擊前一小節）、轉場 Whoosh、數字計數 Blip。
**教學模式（`--bed`）**：鼓組降到 55%、拿掉主旋律、音效降到 45%，並在旁白出現時自動把音樂壓到 14%（ducking）。

## 四、怎麼選：情境建議

| 科系 / 學校宣傳片 | 賽博霓虹 | 玻璃擬態、電影金色 | 要有「旗艦感」、數字計數器最亮眼 |

## 五、實務注意

| 項目 | 說明 |
|---|---|
| 投影機環境 | 亮色系（明亮簡潔、瑞士極簡）在教室白天最清楚；深色系在暗場、大螢幕最有氣勢 |
| 算圖速度 | 玻璃擬態最慢（大量背景模糊）；駭客終端次之（矩陣雨字元多）；其餘相近 |
| 字多的場景 | 像素遊戲的英數字很寬，長網址、長數字建議改用其他風格 |
| 旁白搭配 | 教學類旁白最搭：工程藍圖、黑板手寫、明亮簡潔（配樂最不搶話） |
| 無旁白宣傳 | 能量高的風格：賽博霓虹、駭客終端、Future Bass（玻璃擬態） |
| 換風格成本 | 只改 `style` 一個欄位，重新 build（幾秒）＋ 重新算圖；分鏡、旁白、字幕都不用動 |

# 廣告範本工作流（廣A、廣B…共用）

> 2026-10-09 建立。廣告範本＝**沒有旁白**的短廣告風格（網站「廣告」區、`範本清單.json` 的 `"kind": "ad"`）。
> 每個廣告範本都是**通用的**：吃任何文本，片長隨內容多寡伸縮；範本只規定「風格與動態」，內容全部寫在 `storyboard.json`。
> 這份說明講所有廣告範本共通的事：**文本怎麼變成 storyboard、內容太多太少怎麼辦、怎麼出片與品檢**。
> 每個範本自己的欄位（欄位名、幾條、每條最多幾字、可不可以省略）寫在該範本 README 的「內容欄位」。

## 一、觸發與流程
使用者說「**廣A／廣B…**」「用＿＿廣告範本做」或在選範本時選某個廣告範本，並給一份文本（活動通知、店家介紹、科系簡介、產品說明……）。

1. **讀文本 → 列出「可以上畫面的東西」**：名稱、一句話標語、2～6 個重點、數字（含單位）、行動呼籲（報名、預約、網址、電話）。
2. **對照範本 README 的「內容欄位」**，把上面的東西填進欄位（見第二節的取捨規則），寫成 `storyboard.json`。
3. **給使用者看 rundown** ⛔：一張表列出「第幾段／狀態或段落型別／畫面上的字」，以及預估片長（`python <範本>/engine/timeline.py storyboard.json` 會印出）。使用者確認後才出片。
4. **先抽格**：`python <skill>/engine/ad/make_ad.py <代號> <專案> --stills` → 看 `抽格/_總覽.jpg`（文字超框、重疊、太空、太擠）。
5. **出片**：`python <skill>/engine/ad/make_ad.py <代號> <專案>` → `out/<name>.mp4`，自動跑最終品檢（無旁白模式）。
6. **品檢**：讀 `qa/最終品檢/` 報告；「畫面突跳」是廣告的設計（硬切、彈跳），照樣逐格看連續格確認；峰值超標是真錯（加 `--limit 0.6` 重做）。照範本 README 的「概念忠實度檢查」逐項核對。

專案資料夾裡只要有 `storyboard.json`；`make_ad.py` 會自己放好畫面程式、時間表、配樂。
node_modules：專案沒有時依序找 `--modules`、環境變數 `AD_MODULES`、往上層的 `_共用/node_modules`，都沒有就 `npm install`（固定 Remotion 4.0.300）。

## 二、文本 → 欄位的取捨規則
**只講一件事**：廣告不是簡報。先決定「看完要記得哪一句」（通常是名稱＋一個最強的好處或行動），其他都是陪襯。

### 內容太多
1. **先刪重複與次要**：同一件事的不同說法只留一個；「歷史沿革、承辦單位、注意事項細節」通常不上畫面。
2. **數字優先**：有數字的重點（48 席、8 折、3000 冊、免學費）比形容詞好上畫面，優先保留。
3. **合併**：三個類似的重點可以合成一個欄位裡的「a・b・c」（但不能超過字數上限）。
4. **還是太多**：拆成兩支廣告（每支只講一件事），不要把字縮小塞進去。

### 內容太少
1. **可省略的段落就省略**（每個範本 README 標了哪些欄位／段落可以省略）。片長會跟著變短，這是正常的。
2. **不要編造事實**：可以把已有的資訊換個角度（例：「11 月 1 日開幕」→ 倒數、日期、星期分開上畫面），但不能生出文本沒有的數字或承諾。
3. 真的太少（例：只有一句標語）→ 跟使用者說，建議換「一句話就能撐住」的範本，或請使用者補資料。

### 字數超過上限
- 欄位上限是**畫面寬度**算出來的（中文一字＝一個字級寬、英數約 0.6 字級），`timeline.py` 會擋下並告訴你哪個欄位、最多約幾字。
- **改寫，不要縮字級**：去掉虛詞（的、了、我們）、用數字代替國字、用名詞片語代替句子（「歡迎大家踴躍報名參加」→「立即報名」）。
- 專有名詞不可以改寫或簡稱錯（校名、店名、法規名稱照原文；太長就放在允許較長的欄位）。

### 數字與標語怎麼挑
- 數字要**能比較或能感受**：「48 席」「前 100 名」「8 折」好過「多元」「豐富」。
- 長條圖類欄位的數值**要是同一種單位**（座位數比座位數），不同單位的數字不要放進同一張圖。
- 標語挑文本裡**最短、最有畫面**的那一句；文本沒有標語就用「名稱＋最強好處」。
- 行動呼籲（網址、電話、報名期限）放在最後一段，照原文。

## 三、片長
- 片長＝各段的「基本動作長度」＋依字數加的停留時間（每個範本的 `timeline.py` 寫了算法；多數範本可在 storyboard 寫 `"pace"` 調整閱讀速度）。
- **示範片**（範本資料夾 `示範/`）一律 25～35 秒、1920×1080、有聲（範本規格）；一般出片的長度由內容決定，使用者另有要求時照使用者。

## 四、新增一個廣告範本（從本機 REEL「純廣告」收進 skill）
1. 資料夾 `templates/範本廣<字母>_<名稱>/`，代號依改造順序 廣A、廣B、廣C…（網站網址用 `ad-a`、`ad-b`…）。
2. `engine/`：`timeline.py`（`build(sb)`：欄位檢查＋依內容排時間表＋音效清單）、`music.py`（`render(tl, wav)`：依時間表合成配樂與音效）、`remotion/src/`（Composition id 一律 `Ad`，片長與事件只讀 `src/timeline.json`，字全部讀 `timeline.json` 裡的 storyboard 內容）。**程式裡不能寫死任何題材的字**。
3. 字型：中文字型依 `allText` 只載入用到的子集；日文字型常缺繁體字，只能用在固定的英文或符號上，或先排全字測試圖。
4. 示範：用 `engine/ad/範例文本_小店開幕.md`（虛構）寫示範分鏡 → `make_ad.py <代號> <專案> --demo <範本>/示範` 直接產生 `示範.mp4`（壓縮版）、`poster.jpg`、`總覽.jpg`、`storyboard.json`。
5. 通用性實測：另找一份**完全不同題材的真實文本**，只換 storyboard、不改程式出片一次，在 README 記錄結果。
6. README（範本規格第三節段落＋「內容欄位」表）、`提示詞_範本廣<字母>完整版.md`、登記（`範本清單.json` 加 `"kind": "ad"`、`"type": "standalone"`；SKILL.md 快速指令與工具；根目錄 README；`site/build.mjs` 的 `TEMPLATES`）。
7. `python templates/check_templates.py` 全綠。

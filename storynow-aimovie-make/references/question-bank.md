# 定調問答題庫（第 ③ 步）

用 AskUserQuestion，每輪最多 4 題、全部選擇題、把推薦項放第一個並標「(推薦)」。
**依②的分析預先選好推薦**（例：國中生觀眾 → 推薦 1 分鐘、強烈配樂）。
使用者回答模糊或互相矛盾時，下一輪用一題確認，不要猜。

## 第 0 題（資料不足時才問）
- 事實資料從哪來？用現有檔案 (推薦)／我等一下放新資料／不用資料，用問的

## 第 1 輪：目的
| 題目 | 選項 |
|---|---|
| 用途 | 宣傳／招生／教學／活動說明／成果發表／典禮 |
| 主要觀眾 | 國中生／國中生＋家長／家長／高中生／老師／評審 |
| 播放場合（可複選） | 宣導大螢幕（有音響）／YouTube・官網（常靜音）／IG・FB 短影音（9:16）／教室投影 |
| 長度 | 30 秒／1 分鐘／2 分鐘／3–4 分鐘／依內容 |

## 第 2 輪：調性
| 題目 | 選項 |
|---|---|
| 看完的感覺（可複選） | 好酷我也想玩／原來可以這麼強／我也做得到／未來有前途／安心理解／好笑好記 |
| 風格 | **幫我產生 3 個概念並做試看 (推薦)**／指定方向（遊戲、手繪、快剪、紀錄片……） |
| 旁白 | 純音樂＋大字卡／旁白＋字幕／學生口吻旁白／角色對話（多聲音） |
| 配樂能量 | 強烈推進／中等律動／安靜底樂／由概念決定 |

## 第 3 輪：細節
| 題目 | 選項 |
|---|---|
| 開場前 3 秒的鉤子 | 寫程式打字／機械手臂動起來／數字衝擊／生活情境問題 |
| 片尾 | 校名＋口號／官網 QR Code（要網址）／入學管道（要正確資訊）／下一節預告 |
| 段落取捨 | 例：升學段放一小段 (推薦)／不放／完整 |
| 個資 | 聯絡方式放哪些？（手機預設不放） |

## 教學類加問
| 題目 | 選項 |
|---|---|
| 輸入 | 只用旁白純文字 (推薦)／使用者另給講義 |
| 旁白 | 配合概念改寫 (推薦)／逐字保留／只保留觀念重寫 |
| 長度 | 維持原長／縮成 2 分鐘／縮成 1 分鐘 |

## 煞車點的問法
- 概念：「請選一個概念」或「3 個都做 10 秒試看」
- 文本：「旁白、大字卡、畫面有沒有要改？」
- 試看：「選一個（可混搭，例如開場用 A、榮耀段用 C）」
- 聲音：附三個試聽檔，問聲音＋語速

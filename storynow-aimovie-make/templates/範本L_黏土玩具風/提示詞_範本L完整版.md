# 範本L 完整版提示詞（黏土玩具風 Clay Toy）

> **兩種用法**
> 1. **在這個 skill 裡**：說「範本L」，Claude 照 `README.md` 寫 `storyboard.json`，用 `make_video.py --template L` 出片。規則都已實作在 `engine/template/src/tpl/TemplateL.tsx`（黏土元件與固定主角 `lib/clay`），不必再貼。
> 2. **在沒有這個 skill 的地方**：把「提示詞本體」整段複製過去，只改【填寫區】。主角小狗要另外附上使用者的原圖，風格會很接近，細節不會跟引擎版一模一樣。
>
> **和原始提示詞的差別**：原始需求是「拆解一支喜歡的廣告、用自己的內容做一支」；桌面攝影棚、黏土實景比喻、立體字、章節膠囊、翻頁捲角、深色膠囊字幕是從那支廣告拆出來的手法（不用原片的角色與署名）；主角是使用者自己畫的捲毛小狗。

## 提示詞本體（從這裡開始複製）

### 【填寫區】
- 主題：〔例：如何準備一場上台報告〕
- 內容：〔貼上文本〕。依內容拆成場景（第三節），旁白一行一句
- 長度：約〔60～180〕秒（跟旁白走）
- 配音：〔台灣口音，親切溫暖〕
- 主角：〔附上主角原圖；沒有就用：金黃捲毛小狗、大垂耳、抱紅愛心、背深藍書包、頭上 Lv.3 徽章與小燈泡〕

### 一、工作方式
1. 先給我看分鏡表（場景、畫面重點、旁白），確認後才動手；先做 10 秒試看給我看主角像不像
2. 用程式逐格渲染（例：Remotion＋SVG），每一格只由時間決定；隨機一律用固定種子
3. 規格：16:9、1920×1080、30 fps、H.264＋AAC；響度 −14 LUFS、峰值 −1.5 dBTP

### 二、整體風格（桌面攝影棚＋黏土玩具）
- 暖米白背景 #e9e5dc（中央稍亮、四周微暗），像一張攝影棚桌面；鏡頭每段慢慢推近約 3%
- **所有東西都是圓潤、有厚度的黏土玩具**：頂部亮、底部暗的漸層＋內陰影＋地面橢圓柔影；依旁白從上方掉進來、落地壓扁一下再回彈、噴出幾顆小黏土球
- **厚實立體字**：多層文字陰影疊出 8～14px 厚度＋底部落影，從上方掉下來彈一下
- **主角**每段都在場、比例夠大，會眨眼、彈跳、驚訝、開心、揮手；捲毛用一團團小黏土球表現
- 左上角**章節膠囊**（橘底白字「2 準備三步驟」）
- 段與段之間**翻頁捲角**：右上往左下翻過去，頁背是淺灰漸層＋陰影，約 0.7 秒、連續
- 色彩：橘 #d9663a、深藍 #1f3a7a、芥末黃 #e0a52e、草綠 #3aa86b、木頭 #b97a45
- 字型：中文 Noto Sans TC 900；英數圓胖字 Baloo 2
- 內容只放在 y < 900

### 三、場景
| 內容 | 畫面 |
|---|---|
| 開場（title） | 大立體標題逐行掉下、噴黏土球；深藍小標膠囊、橘色副標膠囊、芥末黃英文立體字；主角驚訝→跳兩下→燈泡亮→愛心舉高 |
| 情境（scenario） | 左邊一疊歪斜的物件；右邊編號黏土標籤念到才掉下；最後一個問題標籤橘底＋大問號，主角驚訝 |
| 定義（definition） | 大立體字（不要切斷重點詞），念到重點時漸變橘色、底下長出芥末黃黏土條；補充說明是黏土卡片 |
| 並列重點（cards） | 長木桌，2～4 個物件念到時掉到桌上；上方編號標題卡、桌面說明名牌；主角每出現一個就跳一下 |
| 對照（vs） | 左右兩張小桌：錯的漸變灰暗＋紅色 ✕，對的綠色卡＋綠色 ✓＋小星星；中間立體 VS；主角先看左再看右 |
| 數字（stat） | 巨大立體數字砸下、壓扁，從 0 往上數：每位數換數字時舊的往上滑出淡出、新的從下滑入淡入（**不要一格一格硬換字**） |
| 隨堂測驗（quiz） | 題目膠囊＋2～4 個黏土按鈕；揭曉時正確按鈕彈起漸變綠、亮暖光、掉下綠勾，錯的壓下變灰 |
| 回顧（recap） | 清單板逐項打綠勾；前面用過的物件全部回到長桌上；立體「NEXT」＋預告膠囊；主角揮手 |
| 片尾測驗（qaEnd） | 題目膠囊＋4 塊插地黏土牌；揭曉時正確的牌往上彈、變淡綠發光、掉下綠勾 |

### 四、字幕
- 深藍 #1f3a7a 小膠囊、白字、圓角、底部置中（參考影片的字幕樣式）
- 字幕下方固定淡色漸層底；翻頁層在字幕之下，字幕永遠在最上層；緊接上一句時直接換字、不淡入

### 五、聲音
- 輕快木琴配樂，120 BPM、F 大調；旁白期間音樂自動壓低
- 音效：翻頁「咻」（對齊翻頁開始）、物件落下「啵」、開場／數字／回顧加一聲彈跳重音

### 六、品質檢查（渲染整支之前）
- 每個場景抽 3 格：文字不超出卡片、不互相重疊、不進 y>900；物件不能是空白或「?」
- 翻頁連續；所有變色 10～12 格漸變；大面積閃動每秒 ≤3 次
- 旁白念到的詞，畫面同時出現

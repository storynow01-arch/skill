# 範本C 完整版提示詞（動態字體快剪 Kinetic Type）

> **兩種用法**
> 1. **在這個 skill 裡**：說「範本C」，Claude 照 `README.md` 寫 `storyboard.json`，用 `make_video.py --template C` 出片。規則都已實作在 `engine/template/src/tpl/TemplateC.tsx`（碎裂 `lib/kinetic`、隧道 `lib/tunnel`、霓虹線稿 `lib/iconkit`），不必再貼。
> 2. **在沒有這個 skill 的地方**：把「提示詞本體」整段複製過去，只改【填寫區】。風格會很接近，細節不會跟引擎版一模一樣。
>
> **和原始提示詞的差別**：原始提示詞寫了概念（文字就是畫面、拍點砸入、硬切），沒有規定色碼、字型、節拍換算與每種內容畫成什麼；這份把它們寫成規則。

## 提示詞本體（從這裡開始複製）

### 【填寫區】
- 主題：〔例：資訊科成果發表〕
- 內容：〔貼上文本〕。依內容拆成場景（第三節），旁白一行一句
- 長度：約〔60〕秒；節拍〔145〕BPM
- 配音：〔有自信、節奏感強的年輕聲音〕

### 一、工作方式
1. 先給我看分鏡表（場景、畫面重點、旁白），確認後才動手；確認後一路做到成片
2. 用程式逐格渲染，每一格只由時間決定；**所有字的出現都對齊拍點**（1 拍＝60 ÷ BPM 秒）
3. 規格：16:9、1920×1080、30 fps、H.264＋AAC；響度 −14 LUFS、峰值 −1.5 dBTP

### 二、整體風格（黑白＋單一螢光色，文字就是畫面）
- 色票：黑 #000、白 #FFF、**螢光黃綠 #D4FF00（唯一的強調色）**；警示紅 #FF3B4E、金 #FFC23D 只用在問題與數字
- 字型：中文 Noto Sans TC 900；英文與數字 Inter 900；行高 1.05、不換行
- **砸入（slam）**：每個字詞出現時從 2.4 倍縮到 1 倍（4 格、cubic out），同時模糊 14px → 0，前 5 格隨機震動 ±10px
- **場景之間硬切**，切點閃一下螢光黃（3 格淡出）
- 底色在黑、白、螢光黃之間輪替（字色反過來）；版面以「一個畫面一個大字」為主
- 圖示一律是**霓虹線稿**（白／黑描邊＋螢光色），不用彩色 emoji

### 三、場景
| 內容 | 畫面 |
|---|---|
| 開場（title） | 標題切成 2～3 字一組，**一拍砸一組**、每組換一次底色（黑→白→螢光）；最後整句在黑底組合起來，上方螢光標籤（節次）、下方螢光英文（字距 12） |
| 情境、痛點（scenario） | 先是霓虹線稿大圖示＋標題；接著每一條**從速度隧道深處衝到眼前**（前 8 格指數加速、隧道之後慢下來）；已講過的條目變成上方白色「✓」標籤；最後一條是問題：整個畫面變紅、白字「?!」砸入 |
| 定義（definition） | 黑底大字砸入；念到重點詞時，那幾個字變螢光色、底下螢光橫條從左長出，同時**重點字碎裂成碎片**飛散（約 1 秒）；下方白色標籤註解依序砸入 |
| 並列重點（cards） | 先標題；每一張：第 1 拍**標題巨大砸入**，第 2 拍**每個字飛向左邊圖示的位置、縮小旋轉消失，霓虹線稿同時描出**（字變成東西）；然後定格：左圖示、右標題＋螢光說明；上方一排編號標籤標出目前第幾張；奇數張黑底、偶數張白底 |
| 對照（vs） | 畫面左右分割：左黑右白，兩半分別從上、下滑入（6 格）；各自霓虹線稿＋大字；錯的紅色✕、對的綠色✓砸在圖示右上；中間螢光圓形「VS」 |
| 隨堂測驗（quiz） | 螢光「QUIZ」標籤、題目、白底選項依序砸入；思考時間底部螢光進度條；揭曉時答案變螢光底＋✓，其他變暗 |
| 數字（stat） | 巨大數字（Inter 900、字距 −20、螢光描邊 6px）**裡面塞滿內容**：用標籤文字排成斜向重複圖樣，填進數字內部並緩慢移動；數字 0.8 秒滾到目標值；下方白色標籤 |
| 回顧（recap） | 每一句帶走的話砸入（白、螢光交替）；講「下一節」之前，所有句子往中線**壓扁收成一條線**，然後螢光底「NEXT ▶ 下一節」 |
| 片尾測驗（qaEnd） | 2×2 白底選項，紅色倒數條；時間到答案變螢光；**最後一拍所有東西收成影片標題一句**（螢光細線收縮、標題由扁變正），停住、切黑 |

### 四、字幕
- 底部置中小黑條（80% 黑、左邊 6px 螢光豎線），Noto Sans TC 700、36px 白字（大螢幕、靜音 YouTube 都看得懂）

### 五、聲音
- phonk／重低音電子配樂，145 BPM、E 小調；旁白期間音樂自動壓低
- 音效：每次砸入一聲重擊、切場一聲短刷、碎裂一聲玻璃碎
- 場景長度補足到整數小節

### 六、品質檢查（渲染整支之前）
- 場景交界抽連續格：硬切、一拍一個詞；卡片場景抽連續格：要看得到「字飛成圖示」
- 大字不出畫面、不壓到字幕條；旁白念到的詞畫面同時砸入

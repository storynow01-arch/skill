# 提示詞：範本廣K 完整版（紅點作品集）

> 在沒有這個 skill 的地方，把下面整段（含程式規則）貼給 AI，再附上你的文本，就能做出同風格的影片。
> 有 skill 時不用貼：直接說「廣K」＋給文本，照 README 寫 storyboard，`make_ad.py` 一行出片。
> 出處：skillry.dev 人氣第 1 名提示詞（逐字見 `原始提示詞_H1.txt`）——「做一支動態設計作品集 showreel，go all out」；這份是把它落地成可重複的規格。

```
請把我附上的文本做成一支「動態設計作品集（showreel）風格」的短廣告（沒有旁白、沒有字幕），規格與規則如下，全部照做。

【要做的事】
先讀我的文本，挑出：名稱（和一個英文縮寫或 2～4 字的短名）、0～4 組「數字＋單位」、
（只有文本真的有「前→後」兩個值時）一組前後值、0～3 個最有感的大數字、0 或 2～9 個項目名稱、一句標語、網址或電話。
先給我一張表（第幾段／段落型別／畫面上的字／預估秒數）讓我確認，確認後才寫程式。
只講一件事：字放不下就改寫成名詞片語，不要縮小字；不要編造文本沒有的數字（尤其「劃掉換數字」那段，沒有前後兩個值就整段不要）。

【風格】
像動態設計師的作品集：炫技、快、每一拍都有事，但用「一顆紅點」把所有手法串成一條不斷的線。
米白紙底 #F2ECDF＋淡淡的 64px 點陣、墨黑 #17151B、訊號紅 #FF4B1F（主角）、螢光綠 #D8FF3C（只用在膠囊小標的字）。
中文用高反差宋體（Noto Serif TC 900，不要黑體），縮寫、數字、網址用 Anton 窄體；Anton 沒有中文，中文與 × ＋ 這類符號退回宋體。
每個拍點整個畫面推一下（約 7%）震一下（約 26px、指數衰減）；換段時背景點陣比前景早 10 格先滑走。
動態模糊一律用「殘影」（同一畫面在過去幾格各畫一次、逐層變淡），不要 CSS blur。

【段落（依內容挑，可省略；至少要開場與 LOGO）】
1. 開場：紅點從畫面上方落下（殘影）、落地壓扁回彈、兩圈漣漪；往右一跳一跳，每跳一下蓋出縮寫的一個字
   （字從上下交替滑進、帶殘影，一字半拍），上方小字、下方紅色英文用遮罩上滑。
2. 數字組合（0～4 組）：甩鏡進場（7 格橫移 2100px＋殘影）；同一條連續鏡頭一組一組推近「數字＋單位」：
   數字吃角子老虎滾停，單位先被紅色色塊刷開再收走（最後一組用黑色塊），紅點在後面一跳一跳跟著；
   最後鏡頭拉遠把全部排成一行，上下兩條跑馬燈（● 分隔）。
3. 鑽進紅點：鏡頭對準最後一顆紅點一路推進 70 倍，整個畫面變紅。（沒有數字組合時，直接鑽進開場最後一顆紅點）
4. 劃掉換數字（可省）：紅底上標題遮罩上滑，前一個值每位數滾停，一刀黑線斜斜劃掉，
   字一個個碎掉往下掉（拋物線＋旋轉），後一個值帶 3 層殘影從 2.8 倍砸下（漣漪圈），單位跟著蓋上，下方說明淡入。
   （省略時只留一拍紅底）
5. 紅色整個收成畫面中央一顆米白小點、靜半拍 → DROP：米白圓 7 格內炸開滿版。
6. 大數字（0～3 個）：第 1、3 個是紅色星形底（跟著拍子跳、慢慢轉），數字滾停、單位放大蓋上；
   第 2 個是圓環（灰底環＋紅色環畫出比例，％ 照比例，其他畫滿一圈，環頭一顆米白小點）；
   每個之間甩鏡（星形先變形成圓再甩出去）。
7. 名稱（0 或 2～9 個）：深色膠囊小標＋宋體名稱從右邊一刀一刀滑進（殘影），舊的往上推、變淡，
   前 5 個每個半拍、之後每個四分之一拍（越疊越快），左邊一顆紅點。
8. 全部縮成一點吸回 → LOGO 重擊：紅圓（縮寫）彈簧彈出、名稱帶殘影從右邊砸上、底線畫出，
   標語兩段遮罩上滑（第二段紅色），網址淡入，停到片尾。

【節奏與片長】
128 BPM，一拍 14.0625 格（30 fps），所有事件落在半拍或四分之一拍上。
開場 4 拍起、每組數字 2 拍、排成一行與鑽進 2.5 拍、劃掉換數字 4 拍起、每個大數字 4 拍起、名稱 2～5 拍、LOGO 5.5 拍起；
字多的段落依閱讀速度（每秒約 6～7 字）多停一點。內容少時約 15 秒，一般 20～30 秒。

【配樂（自己用程式合成，不要用素材）】
128 BPM，F 小調 Fm–Db–Ab–Eb。開場：下墜音（音高一路往下＋氣音）→ 落地重拍＋悶鼓＋撥弦 → 每個字一下拍手＋上行撥弦。
數字組合：四拍鼓組、sub 貝斯、16 分琶音，每組一下衝擊＋銅管；排成一行前 riser、排好 supersaw；鑽進紅點反向吸入＋咻。
紅底：衝擊＋一路到 DROP 的長 riser、數字滾動喀喀聲、越來越密的小鼓、reese 貝斯；劃掉咻＋小鼓；碎字掉落叮叮咚咚；後一個值印章聲；收成小點時只剩吸氣。
DROP：大衝擊，全編制（四拍 kick、16 分 hat、拍手、supersaw、pad），大數字滾動喀喀，甩鏡咻；名稱一個一音往上爬＋拍手；吸回紅點反向吸入。
LOGO：大衝擊、低音 kick、supersaw 長和弦、reese 貝斯，標語出現時兩聲鐘，最後淡出。
音效要對準畫面事件（同一份時間表）。母帶：先用 4 倍超取樣的真峰值正規化、再前瞻限幅只壓最尖的約 1 dB；成品響度 −14 LUFS、真峰值 ≤ −2 dBTP。

【程式規則】
1. 先寫一份時間表（每段第幾拍開始、每個事件第幾格、每個拍點的重擊強度），畫面與配樂都只讀這份表。
2. 每一格的畫面只由「格數」算出來（不要 CSS transition、計時器、隨機數；隨機用固定種子）。
3. 數字滾動用「舊的往上滑出淡出、新的從下滑入」，不要逐格硬換數字。
4. 版面依字數自動算：縮寫依字數縮字級、數字組合依總寬決定推近與拉遠倍率、大數字依字數縮；縮到下限還放不下就停下來告訴我哪個欄位太長。
5. 中文字型只載入用到的字；做完排一張「全字測試圖」確認沒有缺字。
6. 先出 12～20 張抽格總覽給我看（字有沒有超框、重疊），再整支算圖；1920×1080、30 fps。
```

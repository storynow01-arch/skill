# 提示詞：範本廣L 完整版（新創快剪）

> 在沒有這個 skill 的地方，把下面整段（含程式規則）貼給 AI，再附上你的文本，就能做出同風格的影片。
> 有 skill 時不用貼：直接說「廣L」＋給文本，照 README 寫 storyboard，`make_ad.py` 一行出片。
> 出處：skillry.dev 人氣第 7 名提示詞（逐字見 `原始提示詞_H3.txt`）——「給一間做 inference 的現代新創做一支 modern、slick、punchy 的影片」；這份是把它落地成可重複的規格。

```
請把我附上的文本做成一支「新創公司產品發表風格」的短廣告（沒有旁白、沒有字幕），規格與規則如下，全部照做。

【要做的事】
先讀我的文本，挑出：品牌字（英文名或縮寫最好）、一句打進輸入框的話、一～兩行價值主張＋一行副標、
1～3 個最有感的數字（文本沒有數字就用 1～4 字的關鍵字，不要編數字）、2～4 個產品／區域／單元（卡片）、
2～4 個指標（只用文本有的數字；只有文本真的有「前→後」兩個值時才做劃掉換數字）、2～4 個功能、名稱＋標語＋按鈕字＋網址或電話。
卡片、指標、功能三段可以省略，但至少留一段。
先給我一張表（第幾段／段落型別／畫面上的字／預估秒數）讓我確認，確認後才寫程式。
只講一件事：字放不下就改寫成名詞片語，不要縮小字；不要編造文本沒有的事實。

【風格】
像一間現代新創的產品發表：大量留白、俐落、有衝擊力。
米白 #F3F3EF 底＋80px 細線格（每 4 格一條主線）＋淡淡的噪點；墨黑 #0D0E12、灰 #6B6F7A、只有一個品牌藍 #2B4BFF（暗場用淺藍 #7C93FF）、暗場 #23262E。
英數、大數字用 Geist（細體 300）；中文用思源黑體 Noto Sans TC 300／500。Geist 沒有中文，中文自動退回思源黑體；箭頭、Enter 符號用 SVG 畫。
左上一直有品牌小方塊＋品牌字，右上是「01 / PROMPT」這種段落編號（在藍底與暗場上變白）。
每個轉場背景格線比前景早 5 格先滑走；動態模糊一律用「殘影」（同一畫面在過去幾格各畫一次、逐層變淡），不要 CSS blur。

【段落】
1. 輸入框：大圓角輸入框（白、細框、陰影），上方品牌小標，下方左小標、右「ENTER ↵」；
   一字一字打進一句話（每字約 5 格、藍色游標閃爍），按 Enter（圓形按鈕變藍、縮一下），整個輸入框加速往上甩出（殘影）。
2. Hero：從下方滑上來；品牌小標；一～兩行大字逐字遮罩上推（最後一行品牌藍、粗一階，後面一顆藍點彈出）；
   副標遮罩上滑（後半段黑色加粗）；右上「Announcing＋品牌字」；鏡頭慢慢推近、微微左移。
3. build-up：DROP 的每一項各一拍：巨大細體數字（或關鍵字）＋說明＋一顆藍點，從右邊甩進來、鏡頭重擊，左上「01 / 03」。
4. 鑽進游標點：三圈藍色漣漪，一顆藍點用三次方加速一拍內放大成滿版藍底。
5. DROP：藍底上「a ＋ b ＋ c」一拍砸一個（從 1.5 倍縮回），每項下方說明；最後細線畫出、一行總結逐字上推。
6. 產品線卡片（可省）：卡片軌道從右邊滑進，一拍一拍停在游標下（每張卡：編號、右上膠囊小標、名稱、英文小字、兩行說明、細線、藍色重點）；
   停住的那張浮起、藍框；游標在旁邊輕輕晃。藍底在這時從右邊被推走。
7. 指標牆（可省）：暗場從右邊推進；每個指標：小標、（前綴小字）大數字吃角子老虎每位數依序滾停（每停一位一聲 blip）、單位、說明、補充；
   右邊圓環畫出（％ 照比例，其他畫滿一圈，環頭一顆發光白點）。
   有「前一個值」時改成：前值滾出、一刀淺藍線劃掉、後值從 1.6 倍砸下（鏡頭重擊）。每個指標之間鏡頭往下捲一整個畫面。
8. 功能（可省）：每個功能一個畫面（左：小標、標題、說明；右：白色視窗裡的小動畫——晶片長出接腳、路線畫出、旋轉線框方塊＋層層堆疊、打勾清單），
   鏡頭往左甩一整個畫面。
9. CTA：品牌小標、名稱逐字上推、標語逐字上推、黑色膠囊按鈕浮出（按鈕字＋箭頭），游標移過去按下（變藍、漣漪擴散），網址淡入；背景一團淡藍光。

【節奏與片長】
120 BPM，一拍正好 15 格（30 fps），所有事件都落在拍上。
輸入框約 3 秒、Hero 3 秒起、build-up 與 DROP 每項各一拍＋2 拍、卡片每張 2 拍起、指標每個 4 拍起、功能每個 2 拍起、CTA 3 秒起；
字多的段落依閱讀速度（每秒約 7 字）多停一點。一般 25～35 秒。

【配樂（自己用程式合成，不要用素材）】
120 BPM，A 小調 Am–F–C–G，16 分撥弦琶音貫穿全片（低通濾波器隨段落打開）。
輸入框：暗的琶音＋pad，每個字一下鍵盤喀聲，Enter 一聲點擊。
Hero：低通四拍底鼓、反拍 hat、sub 貝斯；兩行大字各一下重擊。
build-up：每一項一下點擊、小鼓由八分加速到十六分、riser 一路到 DROP，最後半拍抽空；鑽進游標點一聲咻。
DROP 到 CTA 前：全編制（四拍 kick、hat、2／4 拍手、每小節 supersaw 和弦、reese 反拍低音、sine 低音）；DROP 大衝擊＋sub 下墜、每項小衝擊；
卡片進場咻、每張停下柔咻＋點擊；暗場一下衝擊、往下捲柔咻、數字鎖定 blip、劃掉換數字一下衝擊；功能每個硬切柔咻＋點擊。
CTA：大衝擊、pad 長和弦，按鈕按下點擊＋blip＋電鋼琴和弦，底鼓到按下後一拍收掉，尾巴淡出。
音效要對準畫面事件（同一份時間表）。母帶：先用 4 倍超取樣的真峰值正規化、再前瞻限幅只壓最尖的約 1 dB；成品響度 −14 LUFS、真峰值 ≤ −2 dBTP。

【程式規則】
1. 先寫一份時間表（每段第幾格開始、每個事件第幾格、每個數字第幾格鎖定），畫面與配樂都只讀這份表。
2. 每一格的畫面只由「格數」算出來（不要 CSS transition、計時器、隨機數；噪點用固定種子）。
3. 數字滾動用「舊的往上滑出淡出、新的從下滑入」，不要逐格硬換數字。
4. 版面依字數自動算：Hero 依最長一行縮、build-up 大字依「數字＋說明」寬度縮、DROP 一排依總寬縮；縮到下限還放不下就停下來告訴我哪個欄位太長。
5. 中文字型只載入用到的字；做完排一張「全字測試圖」確認沒有缺字。
6. 先出 12～20 張抽格總覽給我看（字有沒有超框、重疊），再整支算圖；1920×1080、30 fps。
```

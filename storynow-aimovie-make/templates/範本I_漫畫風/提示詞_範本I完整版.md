# 範本I 完整版提示詞（漫畫風 Comic）

> **兩種用法**
> 1. **在這個 skill 裡**：說「範本I」，Claude 照 `README.md` 寫 `storyboard.json`，用 `make_video.py --template I` 出片。規則都已實作在 `engine/template/src/tpl/TemplateI.tsx`（漫畫元件 `lib/comic`），不必再貼。
> 2. **在沒有這個 skill 的地方**：把「提示詞本體」整段複製過去，只改【填寫區】。風格會很接近，細節不會跟引擎版一模一樣。
>
> **和原始提示詞的差別**：原始提示詞只說「漫畫風」；白紙分格、網點、集中線、擬聲字、簡筆小人、黑白配黃、翻頁轉場都是製作時決定的，收進範本時再把集中線改靜止、數字往上數改成滑動淡入淡出（為了通過最終品檢、保留特效）。這份把它們寫成規則。

## 提示詞本體（從這裡開始複製）

### 【填寫區】
- 主題：〔例：如何準備一場上台報告〕
- 內容：〔貼上文本〕。依內容拆成場景（第三節），旁白一行一句
- 長度：約〔60～180〕秒（跟旁白走）
- 配音：〔台灣口音男聲，語速自然〕

### 一、工作方式
1. 先給我看分鏡表（場景、畫面重點、旁白），確認後才動手；確認後一路做到成片
2. 用程式逐格渲染（例：Remotion＋SVG），每一格只由時間決定；隨機一律用固定種子
3. 規格：16:9、1920×1080、30 fps、H.264＋AAC；響度 −14 LUFS、峰值 −1.5 dBTP

### 二、整體風格（每段一頁漫畫）
- 頁面：米白紙 #fdfcf7，外圍深色桌面；每個場景是一頁，畫面範圍 y 24～890
- 分格：6～8px 粗黑框，格與格之間留白；依旁白念到時一格一格出現（淡入＋從 0.94 放大到 1，約 0.4 秒），**不要白閃**
- 網點：圓點網格（點徑約 3px、間距 14px），放在背景格或強調格
- 集中線：從格子中心放射的黑色三角細線，**靜止不動**（形狀固定，不要每幾格換形）
- 速度線：水平細線，慢速平移
- 對話框、旁白框：白底粗黑框，對話框有尾巴；旁白框是方框
- 擬聲字：黃色 #ffd23f 粗字＋黑色粗描邊＋微旋轉（鏘！砰！？！叮咚！正解！讚！）
- 漫畫小人：簡筆（圓頭、短髮、白襯衫黃領帶），表情有揮手、思考、驚訝、歡呼；輕微上下晃動
- 色彩：黑白為主，強調色只用黃 #ffd23f，答案紅圈用紅 #e2342b
- 字型：中文 Noto Sans TC 900；英數大字與擬聲字 Bangers
- 換頁：舊頁往左滑出並旋轉約 −6°（約 0.6 秒，緩入緩出），新頁在下面；**不要瞬間大面積黑白反轉**
- 內容只放在 y < 900（下面留給字幕）

### 三、場景
| 內容 | 畫面 |
|---|---|
| 開場（title） | 左格網點底＋小人揮手＋對話框寫小標；右上集中線格寫大標題＋「鏘！」；右下速度線格寫副標＋英文 |
| 情境、痛點（scenario） | 左格黃框標題＋情境圖示＋思考小人；右邊每個痛點一格，念到才出現（有編號方塊）；最後一格集中線＋黃字黑邊問題＋「？！」，小人變驚訝 |
| 定義（definition） | 上格集中線＋大字，念到重點詞時畫黃色底線＋「重點！」；下排小人格＋補充格依序出現 |
| 並列重點（cards） | 速度線標題格；2～4 格並排（編號、圖示、黃框標題、灰色說明）；最後一條黃色網點結論格 |
| 對照（vs） | 左右兩格（錯的網點底＋NG!，對的集中線底＋OK!），各有圖示、小人、說明；中間黃字大「VS」；下方結論黃框 |
| 數字（stat） | 左格集中線＋巨大數字（英數 Bangers）砸出後從 0 往上數到目標值：每位數換數字時舊的往上滑出淡出、新的從下滑入淡入，約 1.2 秒、前快後慢（**不要一格一格硬換字**）＋驚訝小人＋「砰！」；右側說明 |
| 隨堂測驗（quiz） | 上格 QUIZ 標籤＋題目＋思考小人；下格每個選項是一個小人的對話框；揭曉時紅筆圈出答案＋「叮咚！」＋答對的小人歡呼，再出現補充 |
| 回顧（recap） | 左格「重點回顧」，每條念到時打黃勾；右上清單＋歡呼小人；右下速度線 NEXT＋下一節預告 |
| 片尾測驗（qaEnd） | 上格集中線題目＋FINAL QUIZ；下方 A～D 四格；時間到答案格變黃＋紅圈＋「正解！」 |

### 四、字幕
- 畫面底部置中（y≈952），Noto Sans TC 900、白字＋粗黑描邊
- 字幕下方固定一條深色漸層底（y 900→1080，透明→約 0.85），背景動時字幕不晃

### 五、聲音
- 輕快喜劇配樂，120 BPM、C 調；旁白期間音樂自動壓低
- 音效：換頁「咻」、每格出現「啵」、數字／測驗／回顧加一聲重音

### 六、品質檢查（渲染整支之前）
- 每個場景抽 3 格：文字不超出框、不互相重疊、不進 y>900；圖示不能是空白或「?」
- 任何大面積閃動每秒 ≤3 次；集中線不抖；換頁平滑
- 旁白念到的詞，畫面同時出現

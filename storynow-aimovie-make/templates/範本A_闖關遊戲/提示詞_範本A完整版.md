# 範本A 完整版提示詞（闖關遊戲 LEVEL UP）

> **兩種用法**
> 1. **在這個 skill 裡**：說「範本A」，Claude 照 `README.md` 把文本寫成 `storyboard.json`，用 `make_video.py --template A` 出片。下面的規則都已實作在 `engine/template/src/tpl/TemplateA.tsx`，不必再貼。
> 2. **在沒有這個 skill 的地方**（別台電腦、別的 AI）：把「提示詞本體」整段複製過去，只改【填寫區】。AI 會照規則重寫程式，風格會很接近，細節不會跟引擎版一模一樣。
>
> **和原始提示詞（README 裡的招生片版）的差別**：原始提示詞只寫了概念（整支片是一款復古遊戲、世界地圖、SKILL UNLOCKED），沒有規定色碼、字型、各種內容要畫成什麼。這份把那些「當時 AI 自己決定」的部分全部寫成規則，換文本才會長得一樣。

## 提示詞本體（從這裡開始複製）

### 【填寫區】
- 主題：〔例：1-3 IP 位址〕
- 內容：〔貼上文本或講義〕。依內容拆成場景（見第三節），旁白一行一句
- 長度：約〔60〕秒（跟旁白走）
- 旁白角色：〔學長〕（對話框名牌顯示這兩個字）；配音〔台灣男聲，語速稍快〕
- 左上 HUD 文字：〔WORLD 1-3〕

### 一、工作方式
1. 先給我看分鏡表（場景型別、畫面重點、旁白），我確認後才動手；確認後一路做到成片
2. 用程式逐格渲染（例：Remotion／HTML Canvas＋逐格截圖），每一格畫面只由時間決定；動畫一律「每 2 格才更新一次」（像素遊戲的頓挫感）
3. 規格：16:9、1920×1080、30 fps、H.264＋AAC；響度 −14 LUFS、峰值 −1.5 dBTP

### 二、整體風格（復古像素遊戲）
- 背景：由上往下 #1A1C2C → #3B5DC9 的夜空漸層；70 顆 4px 方形星星（每 9 顆有一顆 8px，偶爾閃金色）；底部一排深藍 #29366F 三角形山（半透明）
- 色票：金 #FFCD75、白 #F4F4F4、藍 #41A6F6、綠 #A7F070、紅 #EF7D57、面板深藍灰 #333C57、墨色 #1A1C2C
- 字型：英文與數字用 Press Start 2P；中文用 Noto Sans TC 900；所有字加墨色硬陰影（位移約字級的 1/14，不模糊）
- 面板：深藍灰底＋8px 實線框（顏色依用途）＋10px 黑色硬陰影，**直角、不要圓角**
- 位置一律對齊 8px 格點；整個畫面疊一層 2px 掃描線（12% 黑）
- 主角：12×13 格的像素小人（棕髮、膚色臉、藍衣、深藍褲），每格 10px；走路時兩幀交替
- 圖示：一律是**像素圖**（線稿點陣化），不要彩色 emoji
- 不要：漸層按鈕、圓角卡片、柔和陰影、扁平向量插圖

### 三、場景（每種內容一種遊戲畫面）
| 內容 | 畫面 |
|---|---|
| 開場（title） | 「WORLD 1-3」金色像素字；標題一個字一個字從上方掉下來彈跳（間隔 3 格）；英文副標藍色；「▶ PRESS START」每半秒閃一次；左下綠色地塊，主角從上方掉進畫面 |
| 情境、痛點（scenario） | 頂部「★ QUEST ★」橫幅彈出；左邊大框放像素圖示；右邊任務清單，旁白念到才打勾（綠框✓），最後一項是問題：紅框✕、字變紅、加「?!」並抖動 |
| 定義（definition） | 「✦ NEW ITEM GET! ✦」橫幅；14 顆小方塊繞著道具卡轉；道具卡（金框）大字，念到重點詞時那幾個字變金色＋粗底線；下方綠框註解依序彈出（▸ 開頭） |
| 並列重點（cards） | 「INVENTORY」藍色橫幅；2～4 個鎖住的「?」格，旁白念到才解鎖：框變金、跳一下、噴 8 枚金幣、露出像素圖示＋標題＋藍色說明；左上金色編號；最後可彈出紅框「TIP：…」 |
| 對照（vs） | 左右兩張大卡：危險＝紅框「ENEMY」、正確＝綠框「HERO」、其他＝藍框「PLAYER」；中間金色「VS」緩慢縮放 |
| 數字（stat） | 「STATUS」綠色橫幅；金框大數字一格一格跳到目標值，停住時噴金幣 |
| 隨堂測驗（quiz） | 紅色「!! QUIZ BATTLE !!」；題目框；選項並排，▶ 游標在選項間跳；揭曉時答案框變綠、其他變暗，「CORRECT! +100 XP」綠字彈出＋金幣 |
| 回顧（recap） | 三顆金星依序彈出、「STAGE CLEAR!」綠字；左邊金框「LOOT」條列帶走的重點（念到才亮）；右邊藍框「RESULT」打勾清單；最後「NEXT ▶ 下一節」 |
| 片尾測驗（qaEnd） | 紅色「FINAL BOSS QUIZ」；紅色血條倒數；四個選項 2×2；時間到答案變綠打勾，「STAGE CLEAR!」 |

### 四、世界地圖（招牌特徵，場景之間一定要有）
- 每個場景＝地圖上的一關。上一關旁白講完 → 旗子由紅變綠升起＋金幣噴出＋畫面震動 6 格 → 主角**走**到下一關（橫向捲動、遠山視差 0.4 倍）→ 抵達時跳一下 → 像素溶解（24×14 格隨機轉黑）進入下一關
- 每關的牌子：「STAGE n」＋遊戲名稱（START／QUEST／ITEM／SHOP／VS／STATUS／BATTLE／CLEAR／BOSS）＋這一關的前 7 個字
- 走到一半時，上方金框跳出「SKILL UNLOCKED!」＋上一關的名稱
- 地面：64px 磚塊，綠色草皮頂

### 五、HUD（全片常駐）
- 左上「LV.n」金字＋白框 XP 條（綠色，依過關數填滿）＋「XP」；右上「SCORE 00n000」（每過一關 +1000）

### 六、字幕＝RPG 對話框
- 底部墨色底、8px 白框、硬陰影的對話框；左上藍色名牌（旁白角色名）；字幕逐字打出（每頁在 80% 時間內打完），每行最多 30 字

### 七、聲音
- 8-bit chiptune 配樂，140 BPM、C 調；旁白期間音樂自動壓低
- 事件音效：投幣（開場）、金幣（解鎖、答對）、升級和弦（過關）、錯誤蜂鳴（問題項）、過關號角（STAGE CLEAR）
- 場景長度補足到整數小節，切點落在拍點上

### 八、品質檢查（渲染整支之前）
- 抽每個場景結尾一格＋每個場景交界的連續格：文字不重疊、不出畫面、不壓到對話框；世界地圖真的有「走」
- 旁白念到的詞，畫面上同一時間要出現；畫面文字要跟旁白的說法一致

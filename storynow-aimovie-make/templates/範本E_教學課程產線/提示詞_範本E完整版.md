# 範本E 完整版提示詞（教學課程產線・garychen-dark）

> **兩種用法**
> 1. **在這個 skill 裡**：說「範本E」，Claude 照 `README.md` 與 `規範/完整工作流程.md`（15 步）建課程、寫雙軌稿與分鏡、配音、品檢、出片。下面的規則都已實作在 `engine/`（Remotion 畫面、build_data 品檢、tts、assemble），不必再貼。
> 2. **在沒有這個 skill 的地方**：把「提示詞本體」整段複製過去，只改【填寫區】。風格會很接近，細節不會跟引擎版一模一樣。
>
> 範本E 跟其他範本最大的不同：它是**一整門課的產線**（幾十節、風格完全一致、合併成集），重點是內容正確、字幕與唸法零錯誤；畫面刻意沉穩、不搶戲。

## 提示詞本體（從這裡開始複製）

### 【填寫區】
- 課程：〔例：雲端服務概念（4 單元、每單元 2 集、每集 7 節）〕
- 這一節：〔例：1-3 DNS〕；文稿：〔貼上或給檔案〕
- 每節長度：約〔3～5〕分鐘；每集合併後 28～33 分鐘
- 配音：〔沉穩專業的台灣男老師〕；有 Gemini API 金鑰就用 Gemini Flash TTS，否則 edge-tts
- 封面、片頭、LOGO：〔有就給檔案；沒有就不加〕

### 一、工作方式（15 步，詳見完整工作流程）
1. 文稿與分鏡一起寫（雙軌稿：每場景「畫面型別｜畫面文字」＋旁白），**旁白念到什麼、畫面才出現什麼**
2. 配音前：文稿檢查（專業寫法、台灣用語）→ AI 逐字審稿 → 我審稿 → 分鏡預覽頁（每場一張截圖＋旁白）給我看
3. 配音後：AI 耳朵聽檢＋whisper 交叉聽、句內停頓；建置時字幕覆蓋 >85%、每頁 ≤16 字、≤9 字/秒；渲染前版面探針 0 問題才渲染
4. 規格：16:9、1920×1080、30 fps、H.264＋AAC；整集響度 −16 LUFS

### 二、整體風格（garychen-dark：沉穩、科技感、高對比、不喧鬧）
- 色票：背景 #181818（純中性灰，無藍調）、面板 #202020、卡片 #282828、框線 #383838；強調橘 #F89800（帶柔和外發光 rgba(248,152,0,.18)）；成功綠 #20C058；次要紫 #604098；危險紅 #E05252；文字白 #FFFFFF、內文 #D8D8D8、次要 #9A9A9A
- 字型：Noto Sans TC（標題 700、內文 400、行高 1.6）；程式碼 JetBrains Mono
- 字級（1080p）：hero 148、h1 84、h2 64、h3 46、內文 38、卡片標題 44、卡片說明 38（**放不下就改版型，不縮字**）
- 版面：置中為主、大量留白、單一焦點；左右安全邊 120px；主標題下方置中一條短橘線（約 80×3px）
- 左上角「節次＋節名」小字；頂端 4px 橘色進度條；字幕在底部（y≈954）半透明深底白字、**不加標點**
- 動態原則：每個項目在**旁白念到時才出現並亮起，全部唸完後固定**；不做任何循環動畫；場景切換 0.4 秒淡化；畫面可以停很久但每 3.5 秒內要有一個小變化（星點、光暈、下一項出現）

### 三、場景型別（13 種）
| 型別 | 用途與畫面 |
|---|---|
| title_card | 節次（大字的一半）＋節名＋英文副標＋短橘線 |
| scenario | 生活情境：大圖示＋膠囊標籤逐一亮起，最後一個是問題 |
| definition | 一個名詞的定義：標籤＋大字（重點詞橘色）＋右側註解依序出現 |
| concept_cards | 2～4 張並列卡片（編號、圖示、標題、說明），念到哪張亮哪張，前一張變暗 |
| comparison | 左右對照（錯紅框、對綠框），中間 vs／＋／≠，下方結論膠囊 |
| flow_arrows | 3～5 步流程，箭頭依序點亮 |
| layer_stack | 分層架構（例：七層技術堆疊），念到哪層亮哪層，光點滑到該層 |
| network_diagram | 節點與連線的網路圖，封包沿線移動 |
| ui_mock | 主控台模擬畫面（不錄真實螢幕）：游標移動、點擊、高亮框完整框住目標列 |
| terminal | 終端機：指令逐字打出、輸出依旁白逐行出現 |
| quiz | 隨堂測驗：題目＋選項，思考停頓（倒數圈），揭曉時答案亮橘色光暈一次 |
| closing_card | 結語一句（橘色掃光）＋重點膠囊＋下一節預告；開頭有比喻的節，左右帶回開頭比喻的兩個圖示 |
| qa_endcard | 片尾 6 秒測驗：四選一、倒數、揭曉 |

### 四、特效（輕量，只為了好懂）
- 數字滾動：卡片或結論裡的數字出現時 0.8 秒從 0 滾到目標值
- 輕音效：卡片亮起「噠」、測驗揭曉「叮」，音量約 −20dB；**不要換場咻聲**（白噪音聽起來像雜音）
- 不要：聚光燈微推近、循環輪播、花俏轉場、背景配樂

### 五、配音與唸法
- 專業寫法留在文稿與字幕（mail.google.com、192.168.0.1、2.4 GHz），唸法交給程式轉：IP 逐字、網址的點唸「點」、www 唸 triple W、edu／gov／tw 逐字母
- 每節配完先估整集長度；Gemini 偶爾回傳整段無聲的音檔：任一場每秒不到 2 字或中間空白超過 6 秒就重配那一段

### 六、合併成集
- 封面 3 秒 → 片頭 → 各節（節與節之間短過渡）→ 整集響度 −16 LUFS；每集一份品檢報告（HTML＋MD）

# 提示詞：範本廣A 完整版（一個形狀不剪接）

> 在沒有這個 skill 的地方，把下面整段（含程式規則）貼給 AI，再附上你的文本，就能做出同風格的影片。
> 有 skill 時不用貼：直接說「廣A」＋給文本，照 README 寫 storyboard，`make_ad.py` 一行出片。

```
請把我附上的文本做成一支「UI 動態廣告」影片（沒有旁白、沒有字幕），規格與規則如下，全部照做。

【要做的事】
先讀我的文本，挑出：名稱、一個最強的好處或行動呼籲、2～4 個短重點、1～3 個同單位的數字。
把它們分配到下面的「狀態」裡，先給我一張表（第幾個狀態／型別／畫面上的字／預估秒數）讓我確認，確認後才寫程式。
只講一件事：字放不下就改寫成名詞片語，不要縮小字；不要編造文本沒有的數字。

【風格】
Dribbble 等級的 UI 動態。畫面上只有一個形狀，從頭到尾不剪接：每個狀態都是同一個元素在改變尺寸、圓角、明暗，
內容換掉時帶一下短模糊（約 6 格、最大 9px）。一個游標真的去點、去拖，驅動每一次變化。
背景暖灰 #E8E4DE＋44px 點陣（點也跟著鏡頭縮放）；元件黑 #141312、白、灰，柔和雙層陰影；字型 Geist＋Noto Sans TC（粗 700）。
到處都是彈簧，最多一點點過衝。鏡頭縮放讓每個狀態填滿畫面（鏡頭彈簧比形狀慢一點）。最後一格接回第一格，可以循環。
禁止：彈跳誇張的緩動、粒子爆炸、發光、UI 上的漸層、粗細不一的圖示線條、空白時間、看起來像樣板的東西。

【狀態（依內容挑選、排序，可重複、可省略；建議第一個是按鈕）】
按鈕（黑膠囊，游標移上去變灰、按下）→ 讀取圈轉一圈後打勾 → 動態島（呼吸小圓點＋字＋跳動音量條）
→ 音樂播放器（封面方塊、標題、副標、進度條；播放三角形變形成暫停；拖進度條）
→ 音量滑桿（拖過最大值時整個形狀被拉長，放開從當下長度彈回）→ 開關（移上去鈕變大，在拍點上翻到 ON）
→ 開關鈕變成液態分頁指示器（左右兩邊不同彈簧：前緣快、後緣慢，所以移動時會拉長）
→ 分頁打開成長條圖（自己長出來，游標停在一根上，其他變淡，跳出深色提示框）
→ 收成 ⌘K 搜尋框（一個字一個字打字、跳出結果、按 Enter）→ 通知（打勾＋一句話）→ 變回第一個狀態。

【節奏】
120 BPM，一拍 15 格（30 fps），每一拍都有事情發生。每個狀態有基本動作長度
（按鈕 1 秒、讀取 1.5 秒、動態島 1 秒、播放器 3 秒、滑桿 1.5 秒、開關 1.5 秒、分頁每頁 0.5 秒、長條圖 1 秒、搜尋 0.6 秒＋每字 0.2 秒、通知 0.5 秒），
再依畫面上的字數加停留：每 4 個字加一拍。片尾 0.5 秒變回第一個狀態。所以片長由內容決定。

【程式規則】
1. 1920×1080、30 fps。每一格的樣子都是時間的純函數：不能用 CSS transition、計時器、跨格狀態。
2. 彈簧用封閉解的階躍響應；一個值多次換目標＝每次變化一個彈簧相加；整支循環，所以每個彈簧也把上一輪的尾巴算進來。
3. 分頁指示器的兩個邊坐不同的彈簧（開關鈕同一招）。
4. 拖曳是直接操作：按住時數值由游標位置算；放開後從當下的位置彈回或繼續。
5. 先寫一份「時間表」（每個狀態的起訖格、每個事件第幾格、音效清單），畫面和配樂都只讀這份，聲音才會對準畫面。
6. 配樂：numpy 合成 120 BPM 極簡電子（kick、clap、hat、shaker、反拍 sub bass、Fm9→D♭maj7→A♭→E♭ pad＋撥弦琶音，最後一小節回主和弦、結尾淡出），
   每次點擊（click）、按住（grab）、拖曳每 3 格一聲刻度（scrub）、放開（release）、換狀態（swoosh）、滑過（tick）、打字（key）、Enter、打勾（ding）、通知（chime）都有細小音效。
7. 響度 −14 LUFS、峰值 −2 dBTP。
8. 交付前用連續格檢查：只有一個形狀、游標真的在點和拖、滑桿拉長、指示器前快後慢、最後一格接回第一格。
```

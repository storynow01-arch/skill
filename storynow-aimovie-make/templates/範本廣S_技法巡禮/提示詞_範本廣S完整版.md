# 提示詞：範本廣S 完整版（技法巡禮）

> 在沒有這個 skill 的地方，把下面整段（含程式規則）貼給 AI，再附上你的文本，就能做出同風格的影片。
> 有 skill 時不用貼：直接說「廣S」＋給文本，照 README 寫 storyboard，`make_ad.py` 一行出片。
> 出處：showreel 提示詞 60 秒版（逐字見 `原始提示詞_showreel.txt`）——「做一支動態設計作品集 showreel，go all out」；這份是把它落地成可重複的規格。

```
請把我附上的文本做成一支「動態設計作品集（showreel）技法巡禮」風格的短廣告（沒有旁白、沒有字幕），規格與規則如下，全部照做。

【要做的事】
先讀我的文本，挑出：名稱（＋一個英文縮寫或英文名）、一句可以拆成兩行的標語、2～4 個「數字＋單位」、
3～9 個項目（名稱＋一句說明）、一個地點或場所＋2～4 個標註、2～6 個流程或單元、1～4 組「小標＋大標＋1～3 條項目」、
最後的名稱、標語、網址或電話。
從下面 8 種章挑 5～6 章（開場與 LOGO 必備，其他依內容挑、順序可換、可省略），先給我一張表
（第幾章／章型／畫面上的字／預估秒數）讓我確認，確認後才寫程式。
只講一件事：字放不下就改寫成名詞片語，不要縮小字；不要編造文本沒有的數字或說法。

【風格】
像動態設計師的作品集：每一章炫一種動態設計手法，右上角用小字標出技法名（KINETIC TYPE、TYPE DECONSTRUCT、DATA VISUALIZATION、
SWISS GRID SYSTEM、2.5D ISOMETRIC、LINES & PATHS、SHAPE MORPH、LOGO LOCKUP）＋章號「03 / 05」（數字滾動切換）；
左上角一行固定小字（名稱 — MOTION REEL）、四角細框線。深藍墨底 #171a27、電光藍 #2f6bff、螢光珊瑚 #ff5a4e、暖白 #f4efe6。
中文 Noto Sans TC 900，數字與英文大字 Archivo Black，小標 Space Grotesk；兩個英文字型沒有中文，中文退回黑體。
畫面最下方 180px 只放靜止的角標（不要快速變化的字）。不做真 3D（等角場景用平面多邊形畫）。

【章型】
1. 開場 KINETIC TYPE（必備）：中央細線往兩側畫開、兩端小標；三個幾何形狀（藍圓、珊瑚方塊、白色三角框）依拍點彈出，
   每拍硬切一個背景大字（MOTION／DESIGN／SHOW／REEL）、形狀螺旋收攏撞在一起 → 爆開（震波環、碎片、單次閃白）→
   名稱大字一字一字從 2.4 倍彈下（上下兩半切片位移兩次）、英文縮寫描邊字從中心飛出排好再由左往右填色、上方小字遮罩上滑、背景巨大描邊字橫移；最後整群推近。
2. 字體拆解 TYPE DECONSTRUCT：兩行字（各 2～6 字）逐字砸入（第一行上下交錯砸、第二行從右斜滑入）→ 合併成一行、中間一顆珊瑚圓點 →
   描邊／填色波浪交替、上下切片位移、逐字翻轉、重點字以外退暗＋底線 → 炸散，圓點放大（接圓形擦除轉場）。
3. 數據視覺化 DATA VISUALIZATION：2～4 個面板橫向排成一列，每個面板結束時甩鏡（橫移＋歪斜）到下一個：
   環形圖（% 照比例畫）／24 片堆疊柱＋大數字＋單位彈出／吃角子老虎數字格＋圓形印章蓋下／粒子聚成點陣數字。數字都用吃角子老虎滾動停住。
4. 瑞士格線 SWISS GRID SYSTEM：12 欄格線畫出 → 3～9 張卡片依拍點從左右滑入 → 波浪翻面（背面是說明）再翻回 →
   每拍重排版面、輪流放大一張 → 其他卡片縮走、聚焦一張（變成格線平面圖，接「鏡頭穿越卡片」轉場）。
5. 2.5D 等角 ISOMETRIC：2D 平面圖（格線、虛線框）→ 整個世界轉 45°、壓扁、長出高度變成等角場景（逐層長高的塔、雷射描星形的平台、燈與相機腳架、懸浮平板）→
   2～4 個標註引線一拍一個指向物件，鏡頭推近再橫移；左上標題、「從 2D 到 2→3D」數字滾動。
6. 線條與路徑 LINES & PATHS：晶片描邊 → 裝飾走線點亮 → 2～6 條走線一拍一條通往標籤（左右交替）→ 晶片通電、晶圓格點亮、脈衝沿線跑、鏡頭推近 → 描線畫出英文字標再填色。
7. 形狀變形 SHAPE MORPH：右側色塊每段由下往上換色（藍→珊瑚→白→藍），圖示依拍點一個變一個（飛機、地球、山、咖啡杯、證章、房子、愛心、提袋、獎盃），
   最後變成圓；左側每段換一組字（色塊小標、大標、—項目），舊的往上滑出。
8. LOGO LOCKUP（必備）：同心環每拍收縮、前面各章的數字與名稱＋幾何形狀螺旋收斂、每拍硬切一個詞 → 重擊（閃白、震動、震波環、碎片）→
   三個幾何形狀組成 logo、英文小字、名稱、標語（・珊瑚色）、底線畫出、網址電話，慢速轉動的虛線外環，停到片尾。

【轉場（每個換章點一種，相鄰不重複）】
斜向色條掃過／上一章的圓點放大成珊瑚圓、下一章以圓形擦除打開／8×5 方格磚依對角線長出再縮掉／
鏡頭穿越聚焦的卡片（卡片框內就是下一章）／珊瑚、藍兩層液態波浪上漲／下一章切成 8 條橫向切片左右交錯滑入／
上一章的主圖形放大成白圓蓋滿、再從中心打開一個洞穿越到下一章。字體拆解之後用圓點擦除、格線之後用穿越卡片、進 LOGO 用圖形放大穿越。

【節奏與片長】
128 BPM，一拍 14.0625 格（30 fps），所有關鍵動作落在拍點；每章長度進位到整小節（4 拍＝1.875 秒），
章內「停留讀字」的長度依字數伸縮（閱讀速度每秒約 7 字），動作本身照原速。5～6 章約 25～35 秒。

【配樂（自己用程式合成，不要用素材）】
tech house 128 BPM、A 小調：四拍大鼓、第 2、4 拍拍手、反拍 open hi-hat、16 分音符 closed hi-hat、切分 sub 低音、16 分琶音、每兩小節換和弦的墊底。
第一章只有墊底＋反拍 hi-hat，第二章起全編制，最後兩小節回到墊底、尾巴淡出。換章前一小節 riser、換章那拍重擊；LOGO 重擊前 riser＋大重擊。
章內：形狀彈出 blip、硬切大字拍手、爆開小重擊、逐字砸入咚、數字停住喀、印章、甩鏡與翻面的咻，都對準畫面事件（同一份時間表）。
母帶：打擊樂起音 2.5 ms 淡入、前 12 ms 高頻收一點，同拍疊加時降一點，開場墊底拉高、慢速音量騎乘、16 kHz 低通、4 倍超取樣真峰值正規化；
成品響度 −14 LUFS、真峰值 ≤ −3 dBTP。

【程式規則】
1. 先寫一份時間表（每章第幾拍開始、章內每個動作第幾拍、轉場種類、音效事件），畫面與配樂都只讀這份表。
2. 每一格的畫面只由「格數」算出來（不要 CSS transition、計時器、隨機數；隨機用固定種子）。
3. 數字滾動用「舊的往上滑出淡出、新的從下滑入」，不要逐格硬換數字。
4. 版面依字數自動算字級，縮到下限還放不下就停下來告訴我哪個欄位太長。
5. 中文字型只載入用到的字；做完排一張「全字測試圖」確認沒有缺字。
```

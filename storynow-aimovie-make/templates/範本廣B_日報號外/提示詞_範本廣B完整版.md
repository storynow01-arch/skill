# 提示詞：範本廣B 完整版（日報號外）

> 在沒有這個 skill 的地方，把下面整段貼給 AI，再附上你的文本，就能做出同風格的影片。
> 有 skill 時不用貼：直接說「廣B」＋給文本，照 README 寫 storyboard，`make_ad.py` 一行出片。

```
請把我附上的文本做成一支「報紙號外」廣告影片（沒有旁白、沒有字幕），規格與規則如下，全部照做。

【要做的事】
先讀文本，找出：一個可以當「新聞頭條」的大事（1～2 行，每行 6 字內）、2～4 塊可以上報的重點
（一個比例或人數 → 圖示小人；一個百分比或折扣 → 圓餅；2～4 個要點 → 打勾清單；一個數字 → 分類廣告）、
三個關鍵詞（第二版三張照片的標題）、名稱、一句標語、網址或地址。
先給我一張表（每一塊放什麼字、預估秒數）讓我確認，確認後才寫程式。只講一件事；字太長就改寫，不縮字；不要編造文本沒有的數字。

【故事（整支的結構，不要做成卡片輪播）】
深夜趕印號外：輪轉印刷機滾筒轉動、紙帶上印著一張張小報紙往左跑，每拍震一下 →
抽出一份報紙飛起來（3D 傾斜、帶 2 層殘影）攤平在木桌上，紅色「號外」印章旋轉放大後蓋下 →
鏡頭像讀者的眼睛，在一張 2400×3400 的大報紙上平移推近（讀的時候慢慢漂移）：
  頭條像打字機一個字一個字打出來（字錘落下、紅色游標閃爍，指定的字是紅色）→ 副標也逐字打出 →
  圖示統計：10 個小人一個個被點成紅色，大數字吃角子老虎式滾動停住 →
  圓餅：紅色扇形被畫出來，紅筆拉一條折線到標註，再把紅色大字圈起來 →
  專欄：2～4 條清單逐條在方框裡打勾 →
  分類廣告：紅框裡數字滾動兩圈停住、被紅筆圈起來 →
整版 3D 翻頁到第二版（三張網點照片一張張顯影、標題放大落下）→ 第二版對摺（下半張翻上來，背面是大名報頭）→
摺好的報紙拋物線丟上旁邊的報紙堆（帶殘影）→ 鏡頭推到背面：大名（超大宋體）被紅筆畫一條線，標語、網址、全名，報童手搖鈴。
貫穿全片的主角：一支編輯的紅鉛筆（筆身印英文報名），筆尖指著正在讀的地方、跟著打字、點小人、畫圓餅、打勾、畫圈、最後畫線；
抬筆時筆變大一點、投影離開紙面；快速移動時畫 3 層逐漸透明的殘影（不用 blur）。

【版面與風格】
報紙 #efeadf（邊緣舊化）、墨 #1a1714、紅 #c8102e；木桌 #4b423a＋橫向木紋（背景比前景早 4 格先動）。
報眉（英文報名／中間說明／紅字號外 EXTRA）、粗細雙線、左上框、超大報名、紅色號外章、英文斜體副標；
頭條區右邊一張網點「照片」（用幾何形狀算濃淡排成網點，不用真照片）；沒內容的地方用灰色橫線當假內文。
字型：Noto Serif TC（900 標題、500 內文）＋Playfair Display（英文）。拍點（蓋章、塗紅、打勾、照片、丟上報紙堆）整個畫面推一下 2.8%。

【節奏】
100 BPM，一拍 18 格（30 fps）。開場印刷機 4 秒；頭條每字 5 格、副標每字 3 格；每個專欄 2～3 秒；
翻頁＋第二版約 4 秒；摺報＋丟＋背面約 5 秒；再依畫面上的字數加停留（每 5 字半拍）。片長由內容決定（約 25～40 秒）。

【配樂（numpy 合成，聲音和畫面讀同一份時間表）】
鋼琴 F 大調 I–vi–IV–V 主題＋跨步低音，遠處印刷機八分音符「喀喀」當節拍器；專欄段疊弦樂；
開場：印刷機低頻「咚」＋金屬「喀」＋紙張嘶聲，剪紙、落紙、蓋章；打字機每個字一聲＋換行鈴；
小人一個一個「蓋章」聲、筆刷聲（速度隨畫圈）、打勾短筆刷、滾數字嗶嗶；翻頁聲；
第二版鋼琴升八度、印刷機越來越快（間隔 0.42 秒 → 0.07 秒）、摺紙沙沙、上升音、丟上報紙堆「啪」＋斷電下滑音；
報童手搖鈴（不和諧泛音）＋終止和弦。響度 −14 LUFS、峰值 −2 dBTP。

【程式規則】
1920×1080、30 fps；每一格只由格數決定（不用 CSS 動畫、計時器、隨機）。數字用滾動（舊的往上滑出、新的從下滑入），不要逐格硬換。
畫面最下面 180 像素不要放逐字出現的字。交付前用連續格檢查上面每一個動作，並確認沒有字超出版面。
```

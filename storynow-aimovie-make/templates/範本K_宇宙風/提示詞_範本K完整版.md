# 範本K 完整版提示詞（宇宙風 Cosmos）

> **兩種用法**
> 1. **在這個 skill 裡**：說「範本K」，Claude 照 `README.md` 寫 `storyboard.json`，用 `make_video.py --template K` 出片。規則都已實作在 `engine/template/src/tpl/TemplateK.tsx`（宇宙元件 `lib/cosmos`），不必再貼。
> 2. **在沒有這個 skill 的地方**：把「提示詞本體」整段複製過去，只改【填寫區】。風格會很接近，細節不會跟引擎版一模一樣。
>
> **和原始提示詞的差別**：原始提示詞只說「宇宙風格」；太空船航行、每個重點一顆星體、HUD 鎖定、全像資料面板、星圖都是製作時決定的；收進範本時把星空限制在字幕區以上、數字往上數改成滑動淡入淡出（為了通過最終品檢、保留特效）。

## 提示詞本體（從這裡開始複製）

### 【填寫區】
- 主題：〔例：如何準備一場上台報告〕
- 內容：〔貼上文本〕。依內容拆成場景（第三節），旁白一行一句
- 長度：約〔60～180〕秒（跟旁白走）
- 配音：〔台灣口音男聲，沉穩有未來感〕

### 一、工作方式
1. 先給我看分鏡表（場景、畫面重點、旁白），確認後才動手；確認後一路做到成片
2. 用程式逐格渲染（例：Remotion＋SVG），每一格只由時間決定；隨機一律用固定種子
3. 規格：16:9、1920×1080、30 fps、H.264＋AAC；響度 −14 LUFS、峰值 −1.5 dBTP

### 二、整體風格（星際航行）
- 深空 #05070f；星點約 250 顆、分 3 層視差、各自以 2～6 秒週期閃爍（不要全畫面同步）；星雲用幾個紫 #6b4bd8／藍的放射漸層橢圓
- **每個場景是一顆星體**（行星各有配色、特徵環、雲帶），排成蛇形航線；換場前 14 格出發、換場後 16 格抵達，太空船沿曲線航線飛，途中拉遠、星點拉成短光線
- 抵達時**鎖定框**由大縮小鎖住星體並轉橘 #ffa040，「LOCKED」標籤只在標籤範圍柔和脈動 2 次
- **全像資料面板**（青 #36e2ff 細框、半透明深底）先橫向再縱向展開，內容依旁白逐行出現；場景最後 12 格收起
- HUD：四角框線、左上小雷達＋「STARSHIP NAV ▸ SECTOR 03」、右上場景進度點；飛行中顯示準星與「航向 ▸ 下一站」
- 字型：中文 Noto Sans TC 700／900；英數 HUD 與大數字 Orbitron
- 內容只放在 y < 900；**星空只畫到 y 900**，下緣漸隱

### 三、場景
| 內容 | 畫面 |
|---|---|
| 開場（title） | 母星特寫（帶環、繞行小衛星），鏡頭推近；小標、發光大標題、橘色副標由中間往兩側展開 |
| 情境（scenario） | 紅色警戒星＋擴散警示環（WARNING）；右側 ALERT 面板，每個問題出現時雷達多一個光點；最後一條紅底＋「?!」 |
| 定義（definition） | 行星鎖定後連線到全像框；大字定義，念到重點詞時轉青色並長出發光底線；下方補充卡 |
| 並列重點（cards） | 中央行星＋2～4 顆衛星在橢圓軌道上，念到時亮起並垂下連線到資料卡 |
| 對照（vs） | 紅色危險星（DANGER）對綠色宜居星 #6cf0a0（SAFE），各自鎖定；中間 VS＋流動虛線；下方 NG／OK 面板 |
| 數字（stat） | 恆星鎖定，旁邊大掃描圈旋轉；發光大數字從 0 往上數：每位數換數字時舊的往上滑出淡出、新的從下滑入淡入，約 1.2 秒（**不要一格一格硬換字**） |
| 隨堂測驗（quiz） | 星門＋三條流動虛線航道通往 A/B/C；揭曉時正確航道亮起、太空船飛過去，錯的轉紅變暗 |
| 回顧（recap） | 鏡頭拉遠成整張星圖，走過的星依序點亮打勾、航線全亮；右側任務日誌逐條打勾＋「NEXT DESTINATION」 |
| 片尾測驗（qaEnd） | 四顆目的地行星＋A～D；時間到正確那顆被鎖定（LOCKED ANSWER）加光環 |

### 四、字幕
- 畫面底部置中（y≈952），Noto Sans TC 900、白字＋深色描邊
- 字幕下方固定深色漸層底（y 900→1080）；緊接上一句時直接換字、不淡入

### 五、聲音
- 極簡電子配樂，120 BPM、A 小調；旁白期間音樂自動壓低
- 音效：換場前上升音、資料面板逐行出現時「嗶」、開場／數字／最後測驗的鎖定重音

### 六、品質檢查（渲染整支之前）
- 每個場景抽 3 格：文字不超出面板、不互相重疊、不進 y>900；圖示不能是空白或「?」
- 星點不在字幕區移動或閃爍；循環動畫繞回的瞬間要在畫面外或透明度 0；變化用 10 格以上漸變
- 旁白念到的詞，畫面同時出現

# 提示詞：範本廣H 完整版（晶片之旅）

> 在沒有這個 skill 的地方，把下面整段貼給 AI，再附上你的文本，就能做出同風格的影片。
> 有 skill 時不用貼：直接說「廣H」＋給文本，照 README 寫 storyboard，`make_ad.py` 一行出片。

```
請把我附上的文本做成一支「晶片之旅」廣告影片（沒有旁白、沒有字幕），規格與規則如下，全部照做。

【要做的事】
先讀文本，決定「看完要記得哪一句」，把能上畫面的東西分給這一趟旅程的位置：
  電路板絲印：上方一行（13 字內）、下方一行（17 字內）、
  晶片封裝蓋的雷射刻字：1～2 行（每行 19 字內）＋右下英數小字（例：店名英文、課程代號），
  發光城市 3～6 座地標：每座一塊看板（9 字內，例：一個重點、一個數字、一個單元名稱），
  drop 大標：1～2 段（兩段合計 14 字內，第二段晚一小節出現），
  收尾：名稱（2～8 字，走線排成方塊點陣；太長用簡稱）、標語（一整句 21 字內，或左右兩半各 11 字內）、網址或電話。
除了地標看板與名稱，其他都可以不放。
先給我一張表（每一層畫面上的字、預估秒數）讓我確認，確認後才寫程式。只講一件事；字太長就改寫；不要編造文本沒有的事。

【故事（一個不中斷的鏡頭，主角是一顆電子光點）】
綠色電路板（銅走線、導通孔、表面黏著元件、點陣底紋）：光點從左邊沿一條走線一路轉彎跑向中央的晶片，
  晶片上下的絲印像印表機一樣由左往右一格一格印出來 →
鏡頭無限推進（每一層是上一層中央的 1/5，背景微塵先動、越過鏡頭拉出殘影）：
  灰色晶片封裝蓋（雷射刻字、觀察窗發光）→ 導線架與金線（光點沿金線跑）→ 彩虹干涉色的晶粒表面（標準元件列、金屬層）
  → 晶粒中央是一座俯視的發光電路城市 → 鏡頭從正上方慢慢壓低成追車視角（2.5D：自己算透視投影，用 SVG 畫，不用 3D 引擎）。
城市：電晶體＝大樓（琥珀窗戶燈列、遠處起霧）、導線＝道路格線、車流光點帶拖尾、光點走的主幹道發光；
  光點沿主幹道跑，每經過一座地標塔（左右交替），塔頂點亮、窗戶全亮，一條虛線拉到看板，看板寫「01 / 04」和這座的字；
  最後衝向一座站在路上的巨大 AND 邏輯閘（加速、鏡頭往後拉把整座閘框進來）→
**完全靜音一拍**：所有動態停住、畫面暗一階、聲音完全切掉（殘響也切）→
drop：白光一閃、畫面震動，邏輯閘上方的 6 層神經網路像煙火一層一層連鎖點亮（每層半拍，節點放射光芒，連線上有光點流動），
  光點沿各層中間節點往上竄、在頂端繞圈；上方用像素字由左往右掃出 drop 大標（兩段時第二段晚一小節）→
一路拉遠：鏡頭穿回晶粒、金線、封裝蓋，回到電路板，整塊板往下移讓出上方 →
走線把名稱排成方塊點陣（每個像素是一塊銅墊）：光點沿匯流排跑、每到一個字就往上接到字底，那個字由下往上一格格亮起；
  再由左往右掃出標語、最上方掃出網址。
鏡頭重擊：推進時每拍一下、城市每小節一下、drop 每拍一下；光點有 5 層漸淡殘影＋拖尾（不用 blur）。

【版面與風格】
電路板 #1f6545、銅 #d9a24a、封裝蓋灰 #4f5662、金線 #ffd35e、晶粒彩虹漸層、城市藍 #1f5684、霓虹青 #7ff6ff、琥珀 #ffc860。
字型：像素字 DotGothic16（日文點陣字，會缺繁體字，串接 Noto Sans TC 補字，先排一張全部用字的測試圖確認）；英數小字 Silkscreen；
中文字型只載入用到的字。名稱點陣用 Noto Sans TC 畫在 22×22 小網格上取樣（英數 13 欄寬），2～8 字自動縮放排成一列。

【節奏】
125 BPM，一拍 14.4 格、一小節 57.6 格（30 fps）。電路板 1.5 小節、每一層 1 小節、每座地標 1 小節（看板字多 1.5 小節）、
衝向邏輯閘 2 小節（riser）、靜音一拍、drop 2 小節、拉遠約 1.75 小節、收尾約 3 小節。4 座地標約 34 秒。

【配樂（numpy 合成，聲音和畫面讀同一份時間表）】
techno 漸強，Am–F–C–G（以 drop 為小節起點）：開場只有低頻嗡嗡＋電路滴答 → 穿過封裝加 kick → 晶粒加反拍 hat → 晶圓加 16 分琶音（濾波漸開）與長音 sub
→ 城市加 clap、反拍貝斯 → 衝向邏輯閘 riser＋上升 blip、最後幾拍 16 分 kick → 完全靜音一拍 → drop 衝擊＋超鋸齒和弦＋reese 貝斯
→ 拉遠寬闊 pad＋弦樂＋sine 貝斯。音效：光點轉彎「嗶」、穿層「咻」（拉遠時反向咻）、地標點亮「叮」、神經網路每層一串 blip、
名稱每個字一聲鐘、標語長鐘、網址三個 blip。混音最後做前瞻峰值限幅（只壓最尖的幾毫秒），響度 −14 LUFS、峰值 −2 dBTP 以下。

【程式規則】
1920×1080、30 fps；每一格只由格數決定（不用 CSS 動畫、計時器、Math.random）。
推進、地標、靜音、drop、拉遠、名稱每個字的格數全部先在時間表裡算好，畫面只照表畫，配樂讀同一份；靜音那一拍畫面與聲音要同一格。
所有字不可以超出畫面或看板；字太長就改寫，不要縮小到看不清。
交付前用連續格檢查（推進穿層、每座地標點亮、靜音一拍、drop 連鎖點亮、拉遠穿層、名稱點陣逐字亮起）。
```

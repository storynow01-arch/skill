# 資訊科範本1 完整版提示詞（活動說明＋科系宣傳片）

> **兩種用法**
> 1. **在這個 skill 裡**：說「資訊科範本1」，Claude 照 `README.md` 問三件事、改說明段分鏡（`notice/notice_template.json`），用 `make_info1.py` 一行出片（說明段＋宣傳片串接）。下面的規則都已實作，不必再貼。
> 2. **在沒有這個 skill 的地方**：把「提示詞本體」整段複製過去，只改【填寫區】。風格會很接近，細節不會跟引擎版一模一樣。

## 提示詞本體（從這裡開始複製）

### 【填寫區】
- 活動：〔例：教師 AI 程式設計增能研習〕；日期梯次〔115.09.30（三）· 第 1 梯〕
- 活動資料：〔貼上行前通知或文字〕
- 要額外加的提醒：〔例：洗手間位置、餐盒帶回〕
- 承辦人與聯絡方式：〔只放分機與公務 Email，不放手機〕
- 宣傳片的事實：〔國手人數、金牌數、錄取率、錄取學校、出路……，逐條附來源〕
- 總長：約〔3 分半〕（說明段約 2 分半＋宣傳片 60 秒）

### 一、工作方式
1. 先把每段「畫面＋旁白」整理成表給我確認；數字逐條對資料；個資（手機、學生姓名）先問再放
2. 確認後一路做到成片；說明段與宣傳片各自響度 −14 LUFS 後串接成一支
3. 規格：16:9、1920×1080、30 fps、H.264＋AAC

### 二、說明段風格（賽博霓虹 cyber-neon）
- 背景：深藍夜空 #040814 → #0A1A36，下半部 **3D 透視格線地面**（青色細線往遠方收斂），零星星點
- 色票：文字 #ECF6FF、次要 #7890AA、面板 #0A1830；主色**青色霓虹 #00E5FF**（外發光）、金 #FFC840、紫 #9664FF、正確綠 #3CFFAA、錯誤桃紅 #FF4696
- 字型：中文 Noto Sans TC（500／700／900）；編號與數字 Orbitron（等寬未來感）
- 四角細線框角＋左上、右上小字 HUD（活動名稱、日期）；標題左上，霓虹發光，下方英文小字（字距加大）
- 動態：每個項目在旁白念到時亮起（框線變亮、編號發光），全部念完後固定；開場與結尾標題有衝擊感（放大彈入＋閃光）
- 字幕：底部半透明深色條、白字、無標點

### 三、說明段的段落（活動沒有的段落就刪）
| # | 段落 | 畫面 |
|---|---|---|
| A1 | 開場 | 活動名稱大字（衝擊彈入）、副標、日期梯次、英文名 |
| A2 | 活動資訊 | 資訊格：時間／地點／講師／主持，念到哪格亮哪格（附小字補充，例「共 3 小時」） |
| A3 | 交通與電梯 | 校門→警衛室→停車場路線圖＋電梯；「提前 10 分鐘到校」 |
| A4 | 簽到簽退 | 三步驟流程（簽到 → 研習 → 簽退）＋「＝核給研習時數」 |
| A5 | 課前準備 | 清單逐項打勾（帳號可登入、手機放手邊、工具已裝好、零基礎也 OK） |
| A6 | 個資提醒 | 左右對照：✓ 模擬（假）資料 vs ✕ 真實名冊 |
| A7 | 課程流程 | 時間表，念到哪幾列亮哪幾列 |
| A8 | 生活提醒 | 2 張卡片（洗手間、餐盒） |
| A9 | 聯絡與轉場 | 承辦人、分機、Email → 「接下來先認識○○科」（衝擊彈入） |

### 四、宣傳片（約 60 秒，旗艦科技感）
- 結構：開場標語 → 國際與全國競賽成績（大數字跳動、獎牌） → 歷屆國際賽時間軸 → 升學（錄取率圓環＋數字、錄取學校） → 出路（四個領域） → 結尾標語＋科系名稱
- 大數字從 0 跳到目標值；圓環依百分比畫滿；時間軸依年份逐點亮起；每個事實出現時配一聲衝擊音效
- Tech House 配樂 128 BPM；切點對拍；結尾標語停在最後一拍

### 五、品質檢查
- 抽 12 格（說明段每段一格＋宣傳片 3 格）：文字不重疊、不出畫面、不壓字幕；數字與資料逐條相符；沒有手機號碼等個資
- 長度與響度（−14 LUFS）符合；旁白念到的項目畫面同時亮起

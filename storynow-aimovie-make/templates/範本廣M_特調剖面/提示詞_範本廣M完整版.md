# 提示詞：範本廣M 完整版（特調剖面）

> 在沒有這個 skill 的地方，把下面整段（含程式規則）貼給 AI，再附上你的文本，就能做出同風格的影片。
> 有 skill 時不用貼：直接說「廣M」＋給文本，照 README 寫 storyboard，`make_ad.py` 一行出片。
> 出處：skillry.dev 人氣第 17 名提示詞（逐字見 `原始提示詞_H5.txt`）——「用動態圖像做一支 30 秒的調酒食譜說明影片：從空杯到完成，材料與份量倒進杯子時顯示出來」；這份是把它落地成可重複的規格，並把任何主題包裝成一杯特調。

```
請把我附上的文本做成一支「特調剖面圖」風格的短廣告（沒有旁白、沒有字幕），規格與規則如下，全部照做。

【要做的事】
把文本包裝成一杯特調：先讀文本，挑出：
- 杯名（一～兩行，每行約 5 字）、標題上方一個小膠囊、下方一行小字；
- 2～7 個依序疊起來的組成（區域、單元、步驟、特色、優惠），每個是一層：名稱（約 6 字）、份量數字＋單位（只用文本有的數字，沒有就省略）、一句小字（2 行內）、右邊小標籤的短名；
  每層選一種型態：液體／氣泡／浮層／冰塊／攪拌／裝飾（裝飾只能放最後，冰塊、裝飾各最多一層）；
- 可選：一個「顏色反應」——指定某一層倒完後變成另一個顏色，配一行說明（例：優惠、轉折）；
- 完成時的杯名與一個小膠囊；可選：印章上中下三段字；
- 黑板收尾：小膠囊、一行（可指定重點字）、名稱大字、標語、網址或電話。
先給我一張表（第幾層／型態／畫面上的字／預估秒數）讓我確認，確認後才寫程式。
「杯名」與「哪一項當哪一層」是包裝，可以自己取；份量數字與說明都要出自文本，不要編造。字放不下就改寫成名詞片語，不要縮小字。

【風格】
明亮的吧台插畫，一個連續鏡頭：米白牆（#FBF6EA→#EEF3EA）＋淡磁磚、層架上一排粉彩瓶罐與盆栽、兩道斜窗光、木頭吧台 #E3BC8E；墨色 #2A2833。
中文用霞鶩文楷 TC（400／700），數字與英數用 Fredoka（500／600）；Fredoka 沒有中文，中文自動退回楷體。
背景是視差層：鏡頭移動時背景只動 55%、而且比前景早 5 格先動。動態模糊一律用「殘影」（同一物件在過去幾格各畫一次、逐層變淡），不要 CSS blur。
液體每層一個顏色（預設色盤依序：#E59A2E 琥珀、#E0607E 玫瑰、#E8B21E 金黃、#3550D9 靛藍、#2FB3A8 青綠、#7A4FC8 紫、#FF8A1F 橘），每層上端略淡、交界柔和；冰塊 #5AA9D6、裝飾 #3FAE6A。

【段落】
1. 開場：一只空玻璃杯從畫面上方加速掉到吧台（殘影、落地壓扁回彈、鏡頭震一下）。左邊遮罩上滑：小膠囊、杯名大字（最後一行用各層顏色漸層字）、一行小字。
2. 每一層：左邊大標註依序遮罩上滑——「步驟 N」膠囊（該層顏色）、名稱大字、份量（Fredoka 大數字＋小一號單位）、倒入進度條、一句小字。
   一條細線從標註右緣伸出，終點的白圈色點釘在杯中「正在倒的那一層」（液面跟著升，線也跟著移）。鏡頭隨液面慢慢推近（1.07→1.22 倍）。
   型態：液體＝瓶子（小瓶／玻璃壺／小壺輪流）從右上進場、傾斜、液柱落下、離場；氣泡＝汽水瓶倒入，杯裡一直冒上升氣泡＋一圈泡沫；
   浮層＝長柄匙伸進杯裡，液體倒在匙背上浮在最上面；冰塊＝3～6 顆一顆一顆落下（殘影、濺水、杯子微晃、鏡頭小震），標註下方一排小冰塊依序彈出；
   攪拌＝長柄匙轉圈、漩渦，前面幾層的交界變柔；裝飾＝檸檬片落在杯口、兩片薄荷葉飄下、吸管斜插進去，標註最多 3 行小字依序出現。
   倒完那一層：大標註往上收走，一條折線從那一層的右壁畫到右邊，小標籤（白底膠囊、色點＋短名）滑進來釘住；標籤高度照完成時各層的位置自動排開。
3. 顏色反應（可省）：指定那層倒完後，從交界往上慢慢變成指定顏色（下段完全變、上段只變一點），標註多一行粗體說明。
4. 完成：鏡頭拉遠成整杯完整剖面圖（右邊一排標籤），「完成！」、杯名、小膠囊遮罩上滑；紅色雙圈印章從 2.6 倍砸下（殘影、鏡頭重震）。
5. 黑板：小標籤淡出，杯子沿吧台滑出去，鏡頭往右推到牆上的黑板：粉筆框小膠囊、一行（重點字黃色加底線）、虛線畫出、名稱大字、黃色標語、網址電話。

【節奏與片長】
90 BPM，一拍正好 20 格（30 fps），每一層的開始落在拍上。
開場約 2.7 秒、液體／氣泡／浮層每層 5 拍起、冰塊約 3 秒、攪拌 3 拍、裝飾 4 拍；字多的層依閱讀速度（每秒約 7 字）多停一點；
完成 2.5 秒、推鏡 1 秒、黑板 3～4.5 秒。一般 25～40 秒。

【配樂（自己用程式合成，不要用素材）】
90 BPM 輕鬆 lounge，F 大調 Fmaj9–Am7–Dm9–Bbmaj7。開場只有電鋼琴長和弦＋沙鈴；第一層起電鋼琴切分和弦、sub 低音、刷鼓（大鼓 1、3 拍，小鼓 2、4 拍）、反拍腳踏鈸、沙鈴十六分；
高潮（顏色反應那一層，沒有就最後一層液體）起全樂團：低音加重、弦樂墊、顫音琴旋律，到「完成」為止；黑板前收成長和弦＋顫音琴琶音，尾巴淡出。
音效要對準畫面事件（同一份時間表）：落杯悶響＋玻璃叮、倒液體（帶通噪音＋咕嘟，杯子越滿聲音越高）、氣泡嘶嘶、冰塊每顆一聲玻璃叮＋濺水、攪拌每圈碰杯、
高潮前 riser＋衝擊、顏色反應一串高音顫音琴閃光、檸檬片「啵」（音高下滑）、薄荷葉沙沙、吸管咻＋叮、蓋章悶響、推鏡咻。
母帶：先做慢速音量騎乘（3 秒滑動 RMS、最多 ±4 dB）把響度範圍壓到 9 LU 以下，再用 4 倍超取樣的真峰值正規化、前瞻限幅只壓最尖的約 1 dB；成品響度 −14 LUFS、真峰值 ≤ −2 dBTP。

【程式規則】
1. 先寫一份時間表（每層第幾格開始、倒入的起訖、每顆冰塊、攪拌、裝飾、顏色反應、完成、蓋章、推鏡、黑板），畫面與配樂都只讀這份表。
2. 每一格的畫面只由「格數」算出來（不要 CSS transition、計時器、隨機數；亂數用固定種子）。
3. 液面高度＝各層倒入進度×份量（各層平分杯子容量，冰塊排開的體積加在當時最上層）；液體用一條垂直漸層畫，色標由各層位置算出。
4. 版面依字數自動算：每個欄位有字級上下限，縮到下限還放不下就停下來告訴我哪個欄位太長、最多約幾字。
5. 中文字型只載入用到的字；做完排一張「全字測試圖」確認沒有缺字。
6. 先出 12～20 張抽格總覽給我看（字有沒有超框、重疊、標註線有沒有指對層），再整支算圖；1920×1080、30 fps。
```

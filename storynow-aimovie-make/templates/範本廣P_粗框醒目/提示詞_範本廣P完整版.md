# 提示詞：範本廣P 完整版（粗框醒目）

> 在沒有這個 skill 的地方，把下面整段（含程式規則）貼給 AI，再附上你的文本，就能做出同風格的影片。
> 有 skill 時不用貼：直接說「廣P」＋給文本，照 README 挑章、寫 storyboard，`make_ad.py` 一行出片。
> 出處：showreel 母提示詞「make a dynamic 60-second motion graphics video that shows what an incredible motion designer you are, like it's your showreel for a résumé. go all out.」延伸的「廣告 30 風格」第 1 批第 05 支（新粗野主義 Neo-Brutalism，逐字見 `原始提示詞_05.txt`）；這份是把它落地成可重複的規格，並讓任何文本都能套用。

```
請把我附上的文本做成一支「粗框醒目風（新粗野主義 Neo-Brutalism）」的短廣告（沒有旁白、沒有字幕），規格與規則如下，全部照做。

【要做的事】
故事裝置：一個行銷網頁介面活過來。所有東西都是粗黑框＋硬陰影的視窗、按鈕、卡片、貼紙；一支白色箭頭游標一直在按、在拖，每一拍都有東西彈出、被按下、被拖走。
先讀文本，從下面 8 種章裡挑 4～6 章（第一章一定是「開始按鈕」、最後一章一定是「logo 大按鈕」，中間可任選、順序可換、同一種可以用兩次）：
1. 開始按鈕：黃色點陣桌面，粉紅「開始 ▶」大按鈕彈出 → 游標滑過去按下 → 按鈕縮掉、白色大視窗（標題列「名稱.exe」）爆出、彩色小方塊四散 → 視窗裡名稱大字＋一行等寬字「> ＿＿_」從下滑出 → 右上藍色小視窗（英文大字）歪著彈出 → 等寬字貼紙、1～2 張中文貼紙一張張啪地貼上 → 最上方跑馬燈膠帶展開。
2. 大按鈕：藍色點陣桌面，上方白框標題歪著砸下；2～3 顆大按鈕（大字或數字＋小單位＋英文小框）從上方掉下來；游標一顆顆按下（陰影縮成 0、按鈕往右下沉），下方彈出說明小視窗、按鈕角落貼上「已選 ✓」；最後「SELECT ALL ✓」貼紙。
3. 看板拖曳：薄荷綠桌面上一個大「＿＿.board」視窗，裡面有虛線格子（01、02…）；2～4 張卡片（上方色條英文、名稱、說明）被游標一張張抓起（陰影加深、微微歪斜）拖進格子後彈一下落定，卡片上的貼紙再一張張貼上。兩種拖法：從左邊牌堆拖進格子，或從畫面上方拖下來（最後彈出「通知.msg」視窗）。
4. 勾選清單：白色桌面上「＿＿.todo」視窗，2～5 項一列列從左滑入；游標一項項打勾、那一列底色從左填滿（黃、粉、薄荷輪流），下方「完成 n/N」滾動計數＋藍色進度條；可在右側貼 1～3 張貼紙。
5. 計數器＋收據：左邊計數器視窗（綠框標籤＋大數字吃角子老虎滾動停住＋單位），右上粉紅印表機，游標按 PRINT，收據紙一格一格往下印出（RECEIPT 標題、虛線、1～3 列「左小字／右大字」、可加滾動總數、THANK YOU、鋸齒邊）；紅框印章放大 2.4 倍蓋下；下方 1～2 個小數字視窗彈出。
6. 設定面板開關：藍色桌面，左邊「設定 ▸ ＿＿」視窗 2～4 列，每列文字＋圓角開關；游標一個個打開開關，那一列換成原色底；右邊「預覽.png」視窗跟著換成圖示方塊＋大字＋說明框（可加滾動小數字）；最後「全部開啟 ✓」貼紙。
7. 視窗堆疊→一鍵清空：白色桌面，3～9 個小視窗一拍一個彈出疊成一大疊（可再加一個大視窗），鏡頭慢慢推近；「WINDOWS ×N」與「全部打開！」貼紙；黃色「一鍵清空桌面」大按鈕彈出，游標按下 → 畫面一震，視窗從上到下依序往左右兩側甩出畫面 → 「桌面已清空 ✓」系統訊息彈出、可加一張貼紙。
8. logo 大按鈕：白色桌面，粉紅大按鈕（標語一行）從 1.4 倍砸下、彩色小方塊炸開；名稱小視窗、英文貼紙、全名貼紙；游標按下大按鈕再炸一次；網址列視窗；電話貼紙；上方跑馬燈膠帶。
先給我一張表（第幾章／章型／畫面上的字／預估秒數）讓我確認，確認後才寫程式。
數字只能用文本有的數字；名稱、說明、貼紙都要出自文本，不要編造。字放不下就改寫成名詞片語，不要縮小字。介面字（開始、已選 ✓、SELECT ALL、PRINT、RECEIPT、THANK YOU、設定、全部開啟、一鍵清空桌面、Ctrl+Z、載入中…）可以保留或換掉。

【風格】
配色（原色）：黃 #ffe14d、藍 #3a5bff、粉紅 #ff6fb5、薄荷綠 #4dffb8、米白 #fffdf5、黑 #111；每一章一種桌面底色（44 px 點陣）。
粗框：所有視窗、按鈕、卡片、貼紙、開關都是 6 px 黑框＋往右下 8～16 px 的純黑硬陰影（不模糊）；視窗標題列有三個彩色小方塊、等寬字標題、右上 × 按鈕。
動作：彈出用帶一點過衝的彈簧；按鈕按下時陰影縮成 0、按鈕往右下沉同樣距離；貼紙從 1.8 倍、歪斜啪一聲貼上；游標路徑急進急出，按下時有一圈放射短線。
字：中文 Noto Sans TC 900／700；數字與英文大字 Space Grotesk 700；介面字、網址、英文條 IBM Plex Mono 700。兩個英文字型沒有中文，字型串接時一律接 Noto Sans TC。
畫面最下方固定一條靜止工作列（y ≥ 994：名稱小方塊、名稱.exe、網址），整支都不動；下方 180 px 不放快速變化的字。
招牌轉場（每個換章點一種，依序輪流；進最後一章一律用大色塊視窗）：游標抓住整個畫面像拖視窗一樣甩出去（後面已是下一章）、大色塊視窗從中間放大蓋滿全畫面（大字「＿＿ 載入中…」＋進度條）再往上收走、整個看板往左橫向捲動（下方有捲軸）、Ctrl＋Z 兩顆大鍵彈出被按下、上一章倒帶播回開頭後鍵盤往上飛走。

【節奏與聲音】
drum & bass 160 BPM、E 小調，一拍 11.25 格；每一章從小節頭開始、長度是整小節；字依讀字量（每秒 7 字，英數算半個字）決定停多久；下一個轉場會提早吃掉章尾，最後一個動作之後至少留 3 拍。
第一章：每小節換和弦的墊底＋8 分音符 hi-hat；第二章起兩步鼓（大鼓在第 1 拍與第 3 拍後半、小鼓在第 2、4 拍）、16 分音符 hi-hat、每兩小節一個 reese 長低音、高兩個八度的撥弦琶音；最後兩小節回到墊底，1.4 秒淡出。
音效：開頭重擊；換章前一小節 riser、換章那拍重擊；最後一章前兩小節 riser＋重擊；游標按下的「嗒」、視窗彈出的上滑「啵」、拖曳與甩出的「咻」、貼紙啪一聲、數字停住的嗶、印章、Ctrl+Z 倒帶的下滑磁帶聲——全部對準時間表的事件。
母帶：換章那拍的大鼓降一點、打擊樂起音前 1～2.5 ms 短淡入並收一點高頻瞬間（避免 AAC 預回音突波）、開場墊底拉高讓響度範圍 < 9 LU、慢速音量騎乘、16 kHz 低通、4 倍超取樣真峰值正規化、前瞻限幅只壓最尖的約 0.5 dB；成品響度 −14 LUFS、真峰值 ≤ −3 dBTP。

【程式規則】
1. 先寫一份時間表（每一章第幾格開始、用哪種轉場、章內每個項目登場與被按下的拍點、音效事件），畫面與配樂都只讀這份表。
2. 每一格的畫面只由「格數」算出來（不要 CSS transition、計時器、Math.random；亂數用固定種子）。
3. 數字一律用滾動（舊數字往上滑出、新數字從下滑入），不要逐格硬換。
4. 大面積閃光每秒最多 3 次；不要整片微幅呼吸縮放（要縮放就大方地推近）。
5. 游標進出畫面走右側 y ≤ 800 的位置，不要掃過下方 180 px 的字幕帶。
6. 版面依字數自動算：每個欄位有字級上下限，縮到下限還放不下就停下來告訴我哪個欄位太長、最多約幾字。
7. 中文字型只載入用到的字；做完排一張「全字測試圖」（每種字型串接各排一次）確認沒有缺字。
8. 先出 12～24 張抽格總覽給我看（每章中段、每個換章點前後），再整支算圖；1920×1080、30 fps。
```

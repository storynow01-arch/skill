# 範本D 完整版提示詞（白板手繪 Whiteboard）

> **兩種用法**
> 1. **在這個 skill 裡**：說「範本D」，Claude 照 `README.md` 寫 `storyboard.json`，用 `make_video.py --template D` 出片。規則都已實作在 `engine/template/src/tpl/TemplateD.tsx`（白板元件 `lib/whiteboard`），不必再貼。
> 2. **在沒有這個 skill 的地方**：把「提示詞本體」整段複製過去，只改【填寫區】。風格會很接近，細節不會跟引擎版一模一樣。
>
> **和原始提示詞的差別**：原始提示詞只要求質感（精緻、轉場順、音效緊湊）；白板畫風、一支馬克筆、先描線再上色、扁平配色都是製作時決定的。這份把它們寫成規則。

---

## 提示詞本體（從這裡開始複製）

### 【填寫區】
- 主題：〔例：1-1 協定與封包〕
- 內容：〔貼上文本〕。依內容拆成場景（第三節），旁白一行一句；多用生活比喻（寄信、搬家、門牌）
- 長度：約〔60〕秒（跟旁白走）
- 配音：〔親切的老師，語速稍快〕

### 一、工作方式
1. 先給我看分鏡表（場景、畫面重點、旁白），確認後才動手；確認後一路做到成片
2. 用程式逐格渲染（例：Remotion＋SVG），每一格只由時間決定
3. 規格：16:9、1920×1080、30 fps、H.264＋AAC；響度 −14 LUFS、峰值 −1.5 dBTP

### 二、整體風格（一張大白板，一支馬克筆）
- 白板：淺灰紙面（中央 #F6F6F7 往外漸暗到 #DFE0E3 的放射漸層）＋140 顆淡灰小點紋理
- 每個場景畫在白板上的一塊 1920×1080 區域，區域之間間隔（橫 2150、直 1300），三欄**蛇行**排列（第二列反向，鏡頭移動最短）
- 鏡頭：換場時用 cubic in-out 平移到下一塊（約 0.9 秒），**移動途中微微拉遠再拉近**；開場從 1.12 倍推到 1 倍；最後一句旁白講完後，鏡頭拉遠看**整張白板**（全景放在字幕區上方）
- **一支馬克筆**：畫面上只有一支筆，**筆尖永遠貼著正在畫的那一筆**；一次只畫一樣東西（同一場景的物件依序排隊，排不下就整場等比例加快，保證換場前畫完）；兩筆之間空檔短就滑過去（弧形移動）、空檔長就收到右下角畫面外
- **先描線、再上色**：圖示與卡片先用墨色描出外框，描完才填色並輕輕彈一下
- 圖示：扁平風格，主色藍、橘、黃、紅（不要漸層、不要照片、不要 emoji 直接貼）
- 卡片底色：淡藍 #DFF0F9、淡橘 #FDE9CF、淡黃 #FFF3C4、淡綠 #E3F4E6（錯的用淡紅 #FDE3DF）
- 字型：手寫字用霞鶩文楷（粗）；大標與字幕用 Noto Sans TC 900；所有字都是逐字寫出（每字約 2.2 格）
- 內容只放在每塊區域的 y < 900（下面留給字幕）

### 三、場景
| 內容 | 畫面 |
|---|---|
| 開場（title） | 藍色小標（節次）→ 粗體大標題寫出（叮一聲）→ 標題下畫一條底線 → 灰色英文副標；可在上方畫一個圖示 |
| 情境、痛點（scenario） | 藍色標題；左邊大圖示（約 1.9 倍）；右邊條列，念到才畫勾（啵）；最後一項是問題：紅叉（嗡）＋紅字 |
| 定義（definition） | 淡藍標籤卡＋藍字；粗體橘色大字（最多兩行）寫出（叮）；念到重點詞時紅筆在下面畫底線；下方 2～3 張淡彩卡片註解依序出現 |
| 並列重點（cards） | 藍色標題；2～4 張淡彩卡片，念到哪張才畫：卡片框 → 圖示 → 粗體標題 → 灰色說明；最後一行紅字「★ 重點」 |
| 對照（vs） | 左右兩張大卡（錯的淡紅、對的淡綠、其他淡藍），各有圖示與文字；錯的右上畫紅叉（嗡）、對的畫勾（叮）；中間橘色「vs」；最後紅字「→ 結論」 |
| 數字（stat） | 巨大橘色粗體數字寫出（叮）→ 紅筆把它圈起來 → 右邊寫說明（藍色補充） |
| 隨堂測驗（quiz） | 左上橘底白字「小測驗」標籤（依字寬畫）；題目；選項方框依序畫出；揭曉時紅筆圈出答案（叮）；下面紅字補充 |
| 回顧（recap） | 藍字「今天帶走」；每一條念到時先畫勾（啵）再寫字；右邊灰色小條列；最後畫房子圖示＋橘色粗體「下一節：…」（叮） |
| 片尾測驗（qaEnd） | 藍色題目；2×2 方框選項；時間到紅筆圈出答案（叮） |

### 四、字幕
- 畫面底部置中，Noto Sans TC 900、54px **白字＋10px 深色描邊**（#1D232A）＋淡陰影；每句淡入；片尾拉遠時字幕收起

### 五、聲音（每個畫面動作都有音效）
- 馬林巴配樂，112 BPM、D 調；旁白期間音樂自動壓低
- 音效：畫線與寫字時馬克筆「沙沙」聲（隨筆跡長短）、上色完成「啵」、重點出現「叮」、錯誤「嗡」、換場「咻」
- 場景長度補足到整數小節

### 六、品質檢查（渲染整支之前）
- 每個場景抽 3 格（寫字中、畫圖中、空檔）：筆尖要貼在筆跡尖端，空檔時筆收起來；同一時間只畫一樣東西
- 文字不超出卡片、不壓到字幕；片尾全景在字幕區上方、不被 LOGO 擋住；旁白念到的詞畫面同時出現

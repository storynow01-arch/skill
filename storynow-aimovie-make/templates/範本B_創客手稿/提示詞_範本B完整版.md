# 範本B 完整版提示詞（創客手稿 Maker's Notebook）

> **兩種用法**
> 1. **在這個 skill 裡**：說「範本B」，Claude 照 `README.md` 寫 `storyboard.json`，用 `make_video.py --template B` 出片。規則都已實作在 `engine/template/src/tpl/TemplateB.tsx`（筆跡引擎 `lib/penkit`、線稿 `lib/sketches`），不必再貼。
> 2. **在沒有這個 skill 的地方**：把「提示詞本體」整段複製過去，只改【填寫區】。風格會很接近，細節不會跟引擎版一模一樣。
>
> **和原始提示詞的差別**：原始提示詞寫了概念（一鏡到底、看不見的筆、草圖活起來、便利貼），沒有規定版面、色碼、字型與每種內容畫成什麼；這份把它們寫成規則。

## 提示詞本體（從這裡開始複製）

### 【填寫區】
- 主題：〔例：1-1 協定與封包〕
- 內容：〔貼上文本〕。依內容拆成場景（第三節），旁白一行一句
- 長度：約〔60〕秒（跟旁白走）
- 配音：〔溫暖的學姐，像拿自己的筆記本給你看〕

### 一、工作方式
1. 先給我看分鏡表（場景、畫面重點、旁白），確認後才動手；確認後一路做到成片
2. 用程式逐格渲染（例：Remotion＋SVG），每一格只由時間決定
3. 規格：16:9、1920×1080、30 fps、H.264＋AAC；響度 −14 LUFS、峰值 −1.5 dBTP

### 二、整體風格（創客的方格筆記本）
- **一鏡到底**：所有場景畫在同一本超大筆記本上——每個場景是一個 1700×1000 的區塊，三欄排列、區塊間隔 180；鏡頭用 cubic in-out 從上一個區塊滑到下一個（場景長度的 30%、最多 40 格），每個區塊鏡頭微微傾斜 ±1.2°（左右交替）；**不硬切**。片尾最後 2 秒拉遠，看見整本筆記
- 桌面：木紋（#8A6A4A 系直條紋）；筆記本：米白紙 #FBF8F1、圓角 24、深陰影、50px 淡藍方格線 #CFDCF0、隨機散落幾個淡彩小圓點
- 色票：墨色 #23324A、紅筆 #E2483D、螢光黃 #FFD84D、藍筆 #2F6FD6、綠筆 #2E9E5B
- 字型：中文霞鶩文楷（粗）；英文與大數字手寫體 Caveat（粗）
- **看不見的筆**：所有字和圖都是逐筆描出來的（stroke reveal，每個字約 1.6 格）；畫面上有一個筆尖，**永遠停在正在畫的那一筆的尖端**，沒在畫時收起來
- 線稿：圖示一律是線稿逐筆描出，畫完會「活起來」（上色＋閃燈／轉動／擴散）；不用 emoji 當主視覺
- 便利貼：黃 #FFE680、粉 #FFC8DD、藍 #BDE0FE、綠 #CDEAC0，上緣一條半透明白膠帶，貼上時從下方 120px 彈上來（back easing）、略微旋轉

### 三、場景（每種內容一種手稿畫面）
| 內容 | 畫面 |
|---|---|
| 開場（title） | 藍色手寫小標（節次）→ 大標題逐字寫出 → 紅筆在下面畫一條弧形底線 → 藍色英文副標 |
| 情境、痛點（scenario） | 標題手寫；左邊線稿大圖示；右邊手繪核取方塊，念到才畫勾（綠）；最後一項是問題：紅叉＋紅字 |
| 定義（definition） | 左上淡藍標籤貼紙；大字描出；念到重點詞時，螢光黃像螢光筆一樣從左畫到右蓋住那幾個字，再用紅筆在下面劃線；下方 2～3 張便利貼註解依序貼上 |
| 並列重點（cards） | 2～4 張彩色便利貼，念到哪張才貼上：線稿圖示描出 → 標題 → 藍字說明；最後一行紅字「★ 重點」 |
| 對照（vs） | 兩個手繪方框，各有線稿與文字；寫完後右上角「蓋章」：錯的紅圈✕、對的綠圈✓（從 2.2 倍縮回 1 倍、轉 −12°）；中間手寫「vs」；最後一行紅字「→ 結論」 |
| 隨堂測驗（quiz） | 左上粉紅「小測驗」貼紙；題目手寫；選項方框依序畫出；揭曉時紅筆把答案圈起來；下面紅字補充 |
| 數字（stat） | 巨大手寫數字（紅、Caveat）→ 紅筆把它圈起來 → 右邊寫說明 |
| 回顧（recap） | 紅字「今天帶走」；每一條念到時先畫綠勾再寫字；右邊藍色小條列；最後紅筆箭頭＋「下一節：…」 |
| 片尾測驗（qaEnd） | 題目＋2×2 選項框，時間到紅筆圈出答案 |

### 四、字幕＝紙膠帶
- 底部置中一條淡黃紙膠帶 #FFF4C7（左右黃色虛線邊、微旋轉 −0.8°、陰影），霞鶩文楷 42px 墨色字

### 五、聲音
- 溫暖的 lo-fi／木吉他配樂，90 BPM、G 調；旁白期間音樂自動壓低
- 音效：鉛筆沙沙聲（每次落筆）、紙張滑入（換區塊）、貼紙「啪」（便利貼、蓋章）
- 場景長度補足到整數小節

### 六、品質檢查（渲染整支之前）
- 每個場景抽 3 格（寫字中、畫圖中、空檔）：筆尖要貼在筆跡尖端；場景交界抽 5 格連續格：一鏡到底沒有硬切
- 文字不重疊、不出區塊、不壓到紙膠帶字幕；旁白念到的詞畫面上同時出現

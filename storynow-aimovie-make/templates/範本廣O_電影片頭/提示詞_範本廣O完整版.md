# 提示詞：範本廣O 完整版（電影片頭）

> 在沒有這個 skill 的地方，把下面整段（含程式規則）貼給 AI，再附上你的文本，就能做出同風格的影片。
> 有 skill 時不用貼：直接說「廣O」＋給文本，照 README 挑章、寫 storyboard，`make_ad.py` 一行出片。
> 出處：showreel 母提示詞「make a dynamic 60-second motion graphics video that shows what an incredible motion designer you are, like it's your showreel for a résumé. go all out.」延伸的「廣告 30 風格」第 1 批第 04 支（Saul Bass 電影片頭，逐字見 `原始提示詞_04.txt`）；這份是把它落地成可重複的規格，並讓任何文本都能套用。

```
請把我附上的文本做成一支「經典電影片頭（Saul Bass 風）」的短廣告（沒有旁白、沒有字幕），規格與規則如下，全部照做。

【要做的事】
故事裝置：整支是一部電影的片頭字幕。片名＝名稱，主演＝文本裡的主角（產品、課程、科別、招牌項目），工作人員名單＝文本裡的分工或流程，票房＝文本的數字；最後 THE END。
先讀文本，從下面 9 種章裡挑 4～6 章（第一章一定是「片名卡」、最後一章一定是「片尾」，中間可任選、順序可換、同一種可以用兩次）：
1. 片名卡：橘底，6 根黑條一根根沿自己的方向滑入組成構圖 → 左上「＿＿ 出品」、右上英文一行 → 米色剪紙卡從下方飛上來 → 片名（約 6 字內）在卡上逐字從上方落位 → 紅點彈出 → 英文片名（窄體大寫、字距很寬）→ 左側兩根直條之間一行豎排字。
2. 三片剪紙圓：1～3 片剪紙圓（橘、深青、芥末）依拍彈出旋轉落定，圓上是數字（最多約 4 位數）＋小單位，圓下一個標籤；右上紅字一句，左上英文標題；黑條在圓之間滑入。
3. 主演名單：深青底，左邊米色長條上豎排「主演」＋STARRING；2～6 位主演一位一位登場：剪影畫在一片手剪色塊上從上方落下、名字從黑條底下抽出、英文一行、角色小字、芥末色重點小框彈出；換人時舊的往下掉、黑條抽走。
4. 剪紙卡：芥末底，十字黑條，2～4 張米色剪紙卡從左右兩側飛入（剪影＋名字＋說明＋英文），中央紅色標（例「特別演出」）在銅管搶拍彈出。
5. 劇情大綱：左上黑底小標「劇情大綱 SYNOPSIS」；2～4 個剪影小場景，每場 1～3 行字（大、中、小），下一場整片從右邊推進來；四種場景手法輪流：紅太陽前的剪影、閃光放射、三縷蒸氣、旋轉轉進來；可加一個圓形印章字。
6. 票房紀錄：橘底，「票房紀錄 BOX OFFICE」＋一排輪流亮的燈泡；1～2 張剪紙電影票飛入，票上一行、大數字吃角子老虎滾動停住＋紅色單位、票下小字（預設 ADMIT ONE）；第二張進場時第一張被撞得抖一下；紅色圓章從放大 2.4 倍蓋下。
7. 剪紙全景橫搖：深青底一條黑色馬路，2～4 段場景排成一整條，鏡頭一段一段急進急出橫搖過去；場景可選交通車開進來、大樓窗戶一格格亮起、泳池波浪＋游泳的人、夜晚月亮星星檯燈，或任何剪影畫在大剪紙圓上；每段左邊三行字。
8. 迷魂記螺旋＋工作人員名單：米色底，中央橘色圓盤裡同心色環不斷往外長、黑色螺旋旋轉、中心紅點隨拍跳；兩側直條滑入；「職稱／名字」兩兩一組在螺旋左右落下（2～10 筆）；章尾螺旋加速旋轉縮成一點。
9. 片尾：四根黑條框住畫面、紅色剪紙圓章（英數 5 字內）旋轉蓋上、標語兩行逐字落下（第二行橘色）、THE END（可被紅線劃掉、往下掉，換上一句話）、全名一行、網址或電話。
先給我一張表（第幾章／章型／畫面上的字／預估秒數）讓我確認，確認後才寫程式。
數字只能用文本有的數字（可以數文本的項目，例：實作一～四 → 4 個實作），名字、說明都要出自文本，不要編造人名或片名以外的事實。字放不下就改寫成名詞片語，不要縮小字。電影介面字（主演、STARRING、劇情大綱、SYNOPSIS、票房紀錄、BOX OFFICE、ADMIT ONE、ON LOCATION、PRODUCTION CREDITS、THE END）可以保留或換掉。

【風格】
配色：橘 #e8572a、米 #f2e6cf、深青 #1f5f6b、芥末 #e0a526、墨 #161412、白 #fbf6ea、紅 #c62a22、深棕 #2e2824；每一章一種底色。
剪紙：所有色塊都是多邊形，邊緣每 38 px 取一點、沿法線固定亂數偏移（手剪不規則）＋每 4 格換一次的小偏移（逐格動畫的「沸騰」感），帶 (7, 9) px 的淡投影；滑入的黑條沿自己長軸方向滑進來。
字：中文 Noto Serif TC 900（明體，手排鉛字感：每個字微微歪斜、高低不齊、逐字從上方回彈落位）；數字與英文襯線 DM Serif Display；英文窄體大寫 Bebas Neue。兩個英文字型沒有中文，字型串接時一律接 Noto Serif TC。
全畫面一層固定的紙張顆粒（320 個小點）＋四周淡淡暗角。
剪影圖庫（200×200 框內的幾何剪影）：學生、廚師、飛機、相機、晶片、背包、親子、餐盤、電影攝影機、交通車、檯燈、咖啡杯、書、蛋糕、筆電、時鐘、地標、房子、電影票。
招牌轉場（每個換章點一種，依序輪流；進片尾一律光圈）：斜向黑條掃過（掃過處已是下一章）、剪刀剪開（先畫白色虛線剪線，再兩片紙往兩側掀開）、光圈收縮到一點再從下一章打開（深棕底＋淡圓環＋紅點）、橫條百葉左右交錯掃過、色塊撕開（白色紙纖維撕口）、同心色環往外擴散、直條落下。

【節奏與聲音】
搖擺爵士大樂隊 140 BPM、D 小調，一拍 12.86 格，搖擺反拍落在三連音第三個（0.66 拍）；每一章從小節頭開始、長度是整小節；字依讀字量（每秒 7 字，英數算半個字）決定停多久。
第一章：walking bass 每拍一音＋搖擺 ride＋鋼琴長和弦；第二章起加大鼓（每小節頭）、小鼓（第 4 拍後半）、鋼琴切分和弦（第 2、3 拍後半）、銅管齊奏打點（每章第 2、4…小節尾搶拍＋下一小節頭重音）；最後兩小節回到鋼琴長和弦，1.4 秒淡出；輕微殘響。
畫面跟銅管：剪紙圓在重音處彈一下、主演色塊在重音處放大、票房第一張票在第二張撞上時抖、印章與中央紅標落在銅管上；黑條、螺旋隨第 4 拍後半的小鼓點頭。
音效：開頭重擊；換章前一小節 riser、換章那拍重擊；片尾前兩小節 riser＋重擊；黑條滑入的「咻」、剪紙卡落下的悶擊、剪紙圓彈出、數字停住的「嗒」、印章蓋下——全部對準時間表的事件。
母帶：同拍疊加的地方降一點（換章重擊上的大鼓、銅管重音、印章）、重擊與打擊樂起音前 2～4 ms 短淡入並收一點高頻瞬間（避免 AAC 預回音突波）、慢速音量騎乘、16 kHz 低通、4 倍超取樣真峰值正規化、前瞻限幅只壓最尖的約 1 dB；成品響度 −14 LUFS、真峰值 ≤ −3 dBTP。

【程式規則】
1. 先寫一份時間表（每一章第幾格開始、用哪種轉場、章內每個項目登場的拍點、音效事件），畫面與配樂都只讀這份表。
2. 每一格的畫面只由「格數」算出來（不要 CSS transition、計時器、Math.random；亂數用固定種子）。
3. 數字一律用滾動（舊數字往上滑出、新數字從下滑入），不要逐格硬換。
4. 大面積閃光每秒最多 3 次；每格平均亮度 ≥ 10%（光圈轉場的底用深棕，不要純黑）；不要整片微幅呼吸縮放。
5. 會循環的圖形（同心色環）顏色要跟著每一環自己走，繞回的那一下要藏在畫面外，不然整圈會一格變色。
6. 版面依字數自動算：每個欄位有字級上下限，縮到下限還放不下就停下來告訴我哪個欄位太長、最多約幾字。
7. 中文字型只載入用到的字；做完排一張「全字測試圖」（每種字型串接各排一次）確認沒有缺字。
8. 先出 12～20 張抽格總覽給我看（每章中段、每個換章點前後），再整支算圖；1920×1080、30 fps。
```

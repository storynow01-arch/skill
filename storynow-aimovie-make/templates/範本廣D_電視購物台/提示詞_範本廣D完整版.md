# 提示詞：範本廣D 完整版（電視購物台）

> 在沒有這個 skill 的地方，把下面整段貼給 AI，再附上你的文本，就能做出同風格的影片。
> 有 skill 時不用貼：直接說「廣D」＋給文本，照 README 寫 storyboard，`make_ad.py` 一行出片。

```
請把我附上的文本做成一支「電視購物台」廣告影片（沒有旁白、沒有字幕），規格與規則如下，全部照做。

【要做的事】
先讀文本，找出可以「喊」的好康：一個「原本 → 現在」的對比（一定要是文本裡有的數字，不可以編）、
（可選）一個加碼數字、1～3 個數字吊牌、兩個可以同時拿的好處、1～3 個打勾重點、（只有真的有期限或名額時）一個倒數、
一支電話或報名方式、一句兩行標語、名稱。先給我一張表（每一區放什麼字、預估秒數）讓我確認，確認後才寫程式。

【故事（一個橫向連續的攝影棚，不剪接）】
彩色測試條＋「即將開播」→ 轉台雜訊 → 台標在爆炸星上砸下、再飛到左上角變小（殘影）→
卡通主持人（西裝、油頭、八字鬍、拿麥克風）從下面彈上來，對白泡泡「大家好！」→ 鏡頭沿著舞台往右甩，一區一區看：
  原價區：黃色價格牌滑入、數字吃角子老虎停住 →「原價！」貼紙 → 主持人嚇到「原價耶！」→ 鼓滾奏、鏡頭慢慢推近、牌子越抖越大 →
          紅線劃掉 → 價格牌掉下去 →「現在只要 ○」在爆炸星上大爆炸、彩紙、主持人跳起來（星星眼）→ 紅色大橫幅 →「還沒完！」貼紙甩出
  加碼區：「再加碼！」→ 金卡滑入、反光掃過、數字滾動停住 → 收銀機「鏘！」＋錢幣雨
  吊牌區：1～3 張吊牌從上面落下、彈一下、左右搖晃
  禮盒區：小鳥拍翅飛進來、招牌往下展開 → 兩個禮盒彈出、蓋子跳開 →「可同時申請」→「雙重好禮 ×2」大爆炸
  膠囊區：標題＋爆炸星 → 1～3 個打勾膠囊從右滑入
  倒數區：鬧鐘搖晃＋倒數時鐘每拍翻一格 → 主持人看錶冒汗「快！快！」→「心動不如行動！」
  撥打區：電話響（跳、震）→「立即撥打！」→ 號碼一位一位跳出 → 網址 → 全部縮小淡出 → 收尾大貼圖（標語兩行在大爆炸星上）＋名稱橫幅＋彩帶彩紙
主持人全程在左邊：姿勢跟著事件換（指、往上指、嚇到、蓄力、歡呼、揮手、看錶），講話時嘴巴開合、偶爾眨眼，跳起來時空中拉長、落地壓扁，每拍輕輕彈一下。

【版面與風格】
攝影棚：每區一座金色燈泡拱門（燈泡三顆一組跑馬燈）、紅色舞台地板、紅黃條紋分隔柱；背景是旋轉光芒，顏色隨區漸變（中心亮、邊緣深）；
甩鏡 18 格（急進急出），甩的時候有白色速度線，背景與拱門比前景早 5 格先動。拍點整個畫面推一下並晃動。
螢幕外框：右上 LIVE 燈閃＋「現場直播」、下方紅色跑馬燈（左邊黃底標籤）、最下面 180 像素是整片靜止的藍色專線列（號碼、網址、地址）。
綜藝立體字：多層位移疊字當擠出＋粗外框＋斜體（不要 text-shadow）；字型 Reggae One，缺字退回 Noto Sans TC 900；數字用 Anton。
配色：黃 #ffe600、紅 #ff1e1e、藍 #1e4dff、螢光綠 #39ff14、墨 #1a1030、金 #ffc21a。

【節奏】
138.46 BPM（一拍 13 格、30 fps）。開場＋原價區約 7.5 秒，其他每區 3.5～5 秒，撥打＋收尾約 6 秒；再依字數加停留。片長由內容決定。

【配樂（numpy 合成，聲音和畫面讀同一份時間表）】
搖擺大樂隊：降 B 大調 I–vi–ii–V，walking bass、ride 搖擺、刷鼓、電鋼琴、銅管短奏，第四區起升半音；
原價區揭曉前完全抽空只剩鼓滾奏＋上升音，揭曉時「登登登——登！」＋鈸＋大鼓；倒數區只剩低音＋大鼓。
罐頭音效：測試音、轉台、低音「登登登」（嚇到）、觀眾「哇～」、劃掉的「唰」、掌聲、喇叭、收銀機、錢幣叮噹、滴答、電話鈴、跳起來的「啵～」、鳥叫。
響度 −14 LUFS、峰值 −2 dBTP。

【程式規則】
1920×1080、30 fps；每一格只由格數決定（不用 CSS 動畫、計時器、Math.random）。數字用滾動，不要逐格硬換。
畫面最下面 180 像素保持靜止。交付前用連續格檢查上面每一個動作，並確認沒有字超出貼圖或畫面。
```

# 提示詞：範本廣I 完整版（點線面）

> 在沒有這個 skill 的地方，把下面整段貼給 AI，再附上你的文本，就能做出同風格的影片。
> 有 skill 時不用貼：直接說「廣I」＋給文本，照 README 寫 storyboard，`make_ad.py` 一行出片。

```
請把我附上的文本做成一支「點線面」廣告影片（沒有旁白、沒有字幕），規格與規則如下，全部照做。

【要做的事】
先讀文本，決定「看完要記得哪一句」，把能上畫面的東西分給一個點的升維旅程：
  圖紙標題：左上角一行（24 字內，可省），
  0D 開場：小字一行（可省）、開場句（14 字內最好）、問句一行（可省），
  1D、2D、3D 三維：每維挑一個跟內容有關的物件（相機、平板、咖啡杯、書本、店面、電腦、獎盃、日曆之一），
    配一個主標註（15 字內最好，例：一個重點、一個數字）和一個小標註（23 字內），
  4D 片中片：全景大字一行、片中片標題（18 字內）、副標一行、左右兩句口號（各 7 字內），
  收尾：名稱（10 字內；點會落在名稱後面當句點）、副標、標語、網址或電話。
1D、2D、3D、片中片四段最多可以省略一段。
先給我一張表（每一段的物件與畫面上的字、預估秒數）讓我確認，確認後才寫程式。只講一件事；字太長就改寫；不要編造文本沒有的事（尺寸線不標數字）。

【故事（製圖紙上一個不中斷的鏡頭，主角是一個墨點）】
0D 點：米色製圖紙（細格＋粗格，格線比前景早 4 格動），作圖十字虛線展開，墨點「啵」地彈出、旁邊寫座標 P (0, 0)，
  開場小字、開場句、問句由左往右一筆一筆寫出來（前緣有一條紅色筆尖線）；點跟著拍子小跳，然後往後蓄力、橫向壓扁 →
1D 線（第一種顏色：紅）：點衝出去拉出一條地平線，接著當筆尖一筆一筆勾出第一個物件的線稿（點沿著線走、筆畫跟著出現），
  最後落在物件的亮點上「喀嚓」一閃，物件的紅色部分亮起，尺寸線從中間往兩邊展開；物件上方寫主標註、地平線下寫小標註、左邊寫「1D」→
2D 面（第二種顏色：藍）：點跳到第二個物件，描出外框 → 色面從左上角沿對角線「啪」地鋪滿（只有紅藍）→ 細節一格格彈出（回彈）
  → 左右滑出兩個縮小、紅藍互換的分身（3～4 層殘影），鏡頭微微拉遠 →
3D 體（第三種顏色：黃）：點在紙上畫出立方體展開圖（等角投影的十字形），五個面一拍一拍摺起來成黃色方塊（每面有明暗），
  藍色平台降到方塊頂、一根橫桿「喀」地裝上 → 點變成噴頭來回掃，第三個物件在方塊頂上擠出成 2.5D（正面＋往後上方的側面與背面），
  由下往上一層層印出來（看得到層線）→
4D 時間（全彩）：鏡頭拉遠成全景，衝擊一拍：所有物件跟拍子跳、滿場紅藍黃黑幾何積木彈跳旋轉、地平線變成往右流的彩色時間軸，上方寫出全景大字；
  點飛到上方長成一個鏡頭（圓框、光圈葉片轉動），鏡頭鑽進去 → 片中片（底片齒孔、REC、SCENE 4D）：場記板拍下飛走、標題與副標寫出，
  四個積木演員（紅圓、藍方、黃三角、黑點）依序從左邊跳進來，疊成一個角色（身體、頭、帽子、眼睛），左邊寫出第一句口號，
  燈泡亮起寫出第二句，角色轉一圈噴出彩色紙片 → 拉回全景，鏡頭縮回一個點 →
收回：黃→藍→紅→地平線依序縮進那個點 → 名稱一筆一筆寫出來（極細字），點被筆尖推著走，最後跳上去落在名稱後面當句點（虛線圓＋P (0, 0)），
  名稱下方尺寸線展開，副標（紅）、標語、網址依序寫出。
右上角一直有維度尺 0D–1D–2D–3D–4D，目前那一維亮起、圓點滑過去；收回時滑回 0D。圖紙外框、右下角標題欄（寫名稱）、左下角比例尺 1 : 1 靜止。
鏡頭重擊：彈出、拉線、閃光、鋪色、每摺一面、全景衝擊、演員落地、名稱出現時整個畫面推一下震一下；主角有 5 層漸淡殘影（不用 blur）。

【版面與風格】
紙 #f2efe8、墨 #1b1b1b、格線 #d8d2c4、灰字 #8a8478、紅 #e63946、藍 #1d4ed8、黃 #f4b400。包浩斯式的幾何積木。
字型：極細幾何黑體 Noto Sans TC（100 寫大字、300 寫標註），英數 Space Grotesk；中文字型只載入用到的字。
所有標註字在畫面上至少 34 px，主要字（開場句、主標註、片中片標題與口號、名稱、副標、標語）至少 44 px（要把鏡頭縮放算進去）。

【節奏】
120 BPM，一拍 15 格、一小節 60 格（30 fps）。0D 約 4 秒、每一維約 5 秒、4D 全景＋片中片 8 秒、收尾約 5 秒；三維都畫約 33 秒。

【配樂（numpy 合成，聲音和畫面讀同一份時間表）】
極簡打擊，每升一維加一層樂器：0D 只有節拍器滴答 → 1D 加 sub 低音（咚 . 咚咚）→ 2D 加和弦墊 → 3D 加鼓組（kick、clap、hat，進 4D 前一段鼓花）
→ 4D 全編制：16 分撥弦琶音、鋼琴動機、銅管、弦樂、四拍 kick → 收回時樂器一層層退場，最後只剩一聲滴答。C 大調 I–V–vi–IV。
音效：彈出「啵」、拉線與每一筆麥克筆「刷」、快門閃光、鋪色「啪」＋低衝擊、細節 blip、分身「咻」、摺面「啪」、組裝「喀」、列印嗡嗡、
riser＋全景衝擊、鑽入「咻」、演員彈跳、疊起「喀」、燈泡「叮」、轉圈「咻」、收回反向吸入、名稱衝擊、句點落下「叮」。
混音最後做真峰值（超取樣）前瞻限幅，只壓最尖的幾毫秒；響度 −14 LUFS、峰值 −2 dBTP 以下。

【程式規則】
1920×1080、30 fps；每一格只由格數決定（不用 CSS 動畫、計時器、Math.random）。
每一筆、每一個彈出、每一摺、片中片每個動作、名稱與每行字的格數，以及主角路徑與鏡頭關鍵格，全部先在時間表裡算好，畫面只照表畫，配樂讀同一份。
物件用一組折線部件定義一次（標顏色、外框或細節），1D／2D／3D 用不同畫法畫同一組部件；2.5D 自己算等角投影與擠出，不用 3D 引擎。
所有字不可以超出畫面或互相重疊；字太長就改寫，不要縮小到看不清。
交付前用連續格檢查（每一筆線稿、鋪色、摺方塊、列印、全景、鑽入片中片、收回、句點落下）。
```

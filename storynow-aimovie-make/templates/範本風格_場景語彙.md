# 範本風格：共用場景語彙

範本 A／B／C／D 吃**同一份 storyboard**。任何文本先拆成下面 9 種場景，就能用任一範本輸出。
換範本＝換 Composition（`TemplateA`／`TemplateB`／`TemplateC`／`TemplateD`）＋換配樂，分鏡與旁白都不用改。

## 文本 → 場景的拆法
| 內容 | 用哪種場景 |
|---|---|
| 開場、章節名 | `title` |
| 生活情境、問題、痛點（2–4 個現象＋最後一個是問題） | `scenario` |
| 一個名詞的定義、關鍵句 | `definition` |
| 2–4 個並列重點（三個原因、三個構造、步驟） | `cards` |
| 對照、迷思 vs 正解、A＋B | `vs` |
| 一個關鍵數字 | `stat` |
| 課中檢查 | `quiz`（旁白放一行「……」停 2 秒） |
| 重點回顧＋下一節預告 | `recap` |
| 片尾 6 秒測驗（無旁白） | `qaEnd`（`"sec": 6`） |

## 欄位
| type | props | 對齊旁白的欄位 |
|---|---|---|
| `title` | `eyebrow`（節次如 1-3）、`title`、`en` | — |
| `scenario` | `heading`、`icon`（emoji）、`pills[]`、`lastIsProblem`（預設 true）、`spin` | `cueMap[i]`：第 i 個 pill 在第幾句出現 |
| `definition` | `label`、`bigText`、`highlight`（bigText 裡的一段）、`sideNotes[]` | `cueMap[0]` 句子出現、`cueMap[1]` 標亮、`noteCues[i]` |
| `cards` | `heading`、`cards[{icon, title, note}]`（2–4 張）、`footer` | `cueMap[i]` |
| `vs` | `left/right{frame: danger／success／primary, icon, text}`、`mid`（vs、＋、≠）、`footerPill` | `cueMap[0..1]` |
| `stat` | `value`（數字）、`suffix`（%、億、位）、`label`、`sub` | 第 0 句開始計數 |
| `quiz` | `question`、`options[]`（2–3 個）、`answerIndex`、`afterNote` | `revealCue`：揭曉那一句（通常是「……」的下一句） |
| `recap` | `takeaway[]`（1–3 句）、`recap[]`（選用）、`nextTeaser` | `takeCues[i]`、`nextCue` |
| `qaEnd` | `question`、`options[4]`、`answerIndex`、`answerSec` | 無旁白 |

## storyboard 頂層（範本共用）
```jsonc
{
  "mode": "teach", "snapBars": true,           // 場景長度補足到整數小節，切點對拍
  "narrator": "學長",                           // 範本 A 對話框名牌
  "hud": {"left": "WORLD 1-3"},                 // 範本 A 左上角
  "voice": {"name": "zh-TW-YunJheNeural", "rate": "+18%", "pitch": "+4Hz"},
  "music": {"genre": "chiptune", "bpm": 140, "key": "C"},   // 由範本決定（見各範本 README）
  "scenes": [ ... ]
}
```

## 字數建議（超過會自動縮字，但太長仍不好看）
| 欄位 | 建議 |
|---|---|
| title | ≤ 10 字 |
| heading、bigText | ≤ 14 字 |
| pills、cards.title | ≤ 8 字 |
| cards.note、sideNotes | ≤ 12 字 |
| vs.text | ≤ 14 字（會自動換行） |
| takeaway | ≤ 16 字 |

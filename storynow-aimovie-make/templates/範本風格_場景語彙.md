# 範本風格：共用場景語彙

範本 A／B／C／D 吃**同一份 storyboard**。任何文本先拆成下面 9 種場景，就能用任一範本輸出。
換範本＝換 Composition（`TemplateA`／`TemplateB`／`TemplateC`／`TemplateD`）＋換配樂，分鏡與旁白都不用改。

## 文本 → 場景的拆法
| 內容 | 用哪種場景 |
|---|---|
| 開場、章節名 | `title` |
| 生活情境、問題、痛點（2–4 個現象＋最後一個是問題） | `scenario` |
| 一個名詞的定義、關鍵句 | `definition` |
| 2–4 個並列重點（三個原因、三個構造、步驟） | `cards` |
| 對照、迷思 vs 正解、A＋B | `vs` |
| 一個關鍵數字 | `stat` |
| 課中檢查 | `quiz`（旁白放一行「……」停 2 秒） |
| 重點回顧＋下一節預告 | `recap` |
| 片尾 6 秒測驗（無旁白） | `qaEnd`（`"sec": 6`） |

## 欄位
| type | props | 對齊旁白的欄位 |
|---|---|---|
| `title` | `eyebrow`（節次如 1-3）、`title`、`en` | — |
| `scenario` | `heading`、`icon`（emoji）、`pills[]`、`lastIsProblem`（預設 true）、`spin` | `cueMap[i]`：第 i 個 pill 在第幾句出現 |
| `definition` | `label`、`bigText`、`highlight`（bigText 裡的一段）、`sideNotes[]` | `cueMap[0]` 句子出現、`cueMap[1]` 標亮、`noteCues[i]` |
| `cards` | `heading`、`cards[{icon, title, note}]`（2–4 張）、`footer` | `cueMap[i]` |
| `vs` | `left/right{frame: danger／success／primary, icon, text}`、`mid`（vs、＋、≠）、`footerPill` | `cueMap[0..1]` |
| `stat` | `value`（數字）、`suffix`（%、億、位）、`label`、`sub` | 第 0 句開始計數 |
| `quiz` | `question`、`options[]`（2–3 個）、`answerIndex`、`afterNote` | `revealCue`：揭曉那一句（通常是「……」的下一句） |
| `recap` | `takeaway[]`（1–3 句）、`recap[]`（選用）、`nextTeaser` | `takeCues[i]`、`nextCue` |
| `qaEnd` | `question`、`options[4]`、`answerIndex`、`answerSec` | 無旁白 |
| `kmap`、`terms`、`readTable`（只有範本D，數位邏輯設計專用） | 見 [`科目包/數位邏輯設計`](../科目包/數位邏輯設計/README.md) | 同左 |

**念法另寫（2026-10-08，所有吃 build.py 的範本）**：`lines` 裡的一句可以寫成物件 `{"text": "字幕原文", "say": "實際念的字"}`——字幕用 `text` 的專業寫法，配音念 `say`。
用在 TTS 會念錯的地方：二進位與格雷碼（`00、01、11、10` → `零零、零一、一一、一零`）、一長串編號（改中文數字念得清楚）。

**科目包（2026-10-08）**：storyboard 頂層寫 `"subject": "<科目>"`，`build.py` 會併入 [`科目包/<科目>/念法.json`](../科目包/README.md)；科目專用的念法、場景用法、教法放科目包，不放全域。

## storyboard 頂層（範本共用）
```jsonc
{
  "mode": "teach", "snapBars": true,           // 場景長度補足到整數小節，切點對拍
  "narrator": "學長",                           // 範本 A 對話框名牌
  "hud": {"left": "WORLD 1-3"},                 // 範本 A 左上角
  "voice": {"name": "zh-TW-YunJheNeural", "rate": "+18%", "pitch": "+4Hz"},
  "music": {"genre": "chiptune", "bpm": 140, "key": "C"},   // 由範本決定（見各範本 README）
  "brand": {"dir": "D:/…/03_素材/brand"},     // 選用：封面 cover.jpg＋片頭 intro.mp4＋LOGO logo.png（見下方「品牌素材」）
  "scenes": [ ... ]
}
```

## 字數建議（超過會自動縮字，但太長仍不好看）
| 欄位 | 建議 |
|---|---|
| title | ≤ 10 字 |
| heading、bigText | ≤ 14 字 |
| pills、cards.title | ≤ 8 字 |
| cards.note、sideNotes | ≤ 12 字 |
| vs.text | ≤ 14 字（會自動換行） |
| takeaway | ≤ 16 字 |

## 品牌素材（封面＋片頭＋LOGO，範本 A～D 共用、選用，2026-10-05）

> 只有使用者要求加封面／片頭／LOGO 時才寫 `brand`；storyboard 沒有這個欄位就跟以前一樣，什麼都不加。
storyboard 頂層加 `"brand": {"dir": "<資料夾>"}`，資料夾裡放 `cover.jpg`、`intro.mp4`、`logo.png`（檔名不同可寫 `"cover"`／`"intro"`／`"logo"`；只放其中幾個也可以）。

| 素材 | 怎麼用 |
|---|---|
| LOGO | 正片全程畫在右上角（距右 40、距上 26、寬 220，同範本E）；**封面與片頭不加**。品檢把 LOGO 當保留區：文字或卡片碰到就列必修。範本A 的 SCORE、範本D 的標題寬度與片尾全景會自動讓開 |
| 封面 | 靜止 3 秒，自動裁掉上下緣的黑邊（截圖帶進來的視窗標題列） |
| 片頭 | 放大到 1080p，最後一格淡出 0.6 秒到正片的底色（白板＝淺灰），正片不再從黑畫面淡入 |

順序＝封面 → 片頭 → 淡入 → 正片，由 `make_video.py` 在算圖後接上，再整支做響度（−14 LUFS、峰值 −1.5 dBTP）。
第⑪步最終品檢要加 `--jump-skip 0-<封面＋片頭秒數> --silence-ok 3.5`（make_video 跑完會印出這兩個值）。

## 範本I（漫畫風）、範本J（地圖風）、範本K（宇宙風）、範本L（黏土玩具風）（2026-10-07～08）

範本I～L 直接吃上面 9 種場景，欄位和 A～D 相同，同一份分鏡可直接換成 `--template I／J／K／L`。各場景的版面見 [`範本I_漫畫風/README.md`](範本I_漫畫風/README.md)、[`範本J_地圖風/README.md`](範本J_地圖風/README.md)、[`範本K_宇宙風/README.md`](範本K_宇宙風/README.md)、[`範本L_黏土玩具風/README.md`](範本L_黏土玩具風/README.md)。

## 範本H（螢幕模擬）的場景（2026-10-07）

範本H 不吃上面 9 種場景，用自己的 4 種：`title`、`screen`（電腦螢幕操作）、`phone`（手機）、`recap`。
`screen`／`phone` 的 `props.actions` 是一串操作（click、type、enter、load、focus、zoom、highlight、callout、tap、message…），
每個操作寫 `cue`（旁白原文片段），build.py 換算成秒數，找不到就中止。欄位見 [`範本H_螢幕模擬/README.md`](範本H_螢幕模擬/README.md)。

## 範本M（手繪線稿教學）的場景（2026-10-10）

範本M 吃上面 9 種場景（欄位同 A～L，同一份分鏡可直接換成 `--template M`），**另外多一種 `code`（程式執行）**，只有範本M 會畫：

| 型別 | 欄位 | 時間 |
|---|---|---|
| `code` | `file`（檔名）、`code[]`（每行程式，照原樣含縮排）、`steps[]`：`{line 高亮第幾行（0 起算）, out 這步印出的字, vars {變數: 值}, ok true 打勾／false 打叉}`、`outTitle`（輸出視窗標題，預設「輸出」）、`heading` | `typeCue`：第幾句開始打字（預設 0，約 40 格打完）；`steps[i].cue`：第幾句旁白開始這一步。沒寫 `cue` 的步驟平均分配在前後兩個有 `cue` 的步驟之間；同一句的多個步驟平均分在那一句裡 |

`code` 場景請加 `verify`（`{"type": "code", "lang": "python", "src": "…", "stdout": "…"}`），A1 程式碼執行會真的跑一次、比對輸出、確認輸出出現在畫面上。
其他範本沒有 `code` 的畫面，有 `code` 的分鏡請用範本M。欄位見 [`範本M_手繪線稿教學/README.md`](範本M_手繪線稿教學/README.md)。

## 範本N（行前通知）的場景（2026-10-10）

範本N 吃範本M 的全部場景（9 種共用＋`code`），另外多 7 種行前通知專用場景：`when`（桌曆＋時鐘＋時數章）、`drive`（俯視地圖開車停車）、`walk`（校園步行路線）、`building`（大樓電梯＋簽到退）、`seats`（教室座位亮到名額）、`steps`（流程節點＋方格進度）、`stamp`（文件蓋章＋注意事項）。
欄位與時間（`cueMap`）見 [`範本N_行前通知/README.md`](範本N_行前通知/README.md) 的「場景」表。地圖、大樓、教室是示意圖，畫面上的字只能用通知裡有的資訊。

# 範本J 完整版提示詞（地圖風 Map Quest）

> **兩種用法**
> 1. **在這個 skill 裡**：說「範本J」，Claude 照 `README.md` 寫 `storyboard.json`，用 `make_video.py --template J` 出片。規則都已實作在 `engine/template/src/tpl/TemplateJ.tsx`（地圖元件 `lib/map`），不必再貼。
> 2. **在沒有這個 skill 的地方**：把「提示詞本體」整段複製過去，只改【填寫區】。風格會很接近，細節不會跟引擎版一模一樣。
>
> **和原始提示詞的差別**：原始提示詞只說「地圖風」；羊皮紙探索地圖、紅色虛線路線、圖釘、墨線水彩地標、蠟封章都是製作時決定的；收進範本時加上字幕底漸層、數字往上數改成滑動淡入淡出（為了通過最終品檢、保留特效）。

## 提示詞本體（從這裡開始複製）

### 【填寫區】
- 主題：〔例：如何準備一場上台報告〕
- 內容：〔貼上文本〕。依內容拆成場景（第三節），旁白一行一句
- 長度：約〔60～180〕秒（跟旁白走）
- 配音：〔台灣口音男聲，語速自然〕

### 一、工作方式
1. 先給我看分鏡表（場景、畫面重點、旁白），確認後才動手；確認後一路做到成片
2. 用程式逐格渲染（例：Remotion＋SVG），每一格只由時間決定；隨機一律用固定種子
3. 規格：16:9、1920×1080、30 fps、H.264＋AAC；響度 −14 LUFS、峰值 −1.5 dBTP

### 二、整體風格（一張大探索地圖）
- 羊皮紙底 #ecdcb0（四周燒黃邊、淡格線），墨色 #4a2c17；地形有海岸、湖 #a9c8c6、等高線、山、樹 #9aae6a、圖例框、大羅盤
- **每個場景是地圖上的一站**，站點蛇行排列（每列 3 站）；換場前 10 格鏡頭出發、換場後 22 格到站，中途稍微拉遠
- **紅色虛線路線 #b8322a** 和鏡頭同步畫到下一站；到站時紅色圖釘落下並留在地圖上
- 地標插畫先描墨線、再上水彩、最後描細節；註記卡（米白紙卡＋墨框＋紅圖釘）、紅緞帶標題、蠟封章（編號、VS、問號）
- 左上角固定一張小資訊卡：地圖名＋「STATION 3／9」
- 字型：標題與內文 Noto Serif TC 900；手寫註記霞鶩文楷；英文小標 Cinzel
- 內容只放在 y < 900（下面留給字幕）

### 三、場景
| 內容 | 畫面 |
|---|---|
| 開場（title） | 紅緞帶小標＋卷軸展開（英文、大標題、副標）；左下「起點」分出幾條紅色岔路加問號；右下大指南針轉入 |
| 情境（scenario） | 標題註記卡＋情境地標；路口分出小路連到右側註記卡，念到才出現；最後一張是問題：紅框、紅路、蠟封章打「？」 |
| 定義（definition） | 大型地標被手繪紅圈圈起、頂端升起紅旗；右側大卡寫定義，念到重點詞時刷金色並變紅；下方便條補充 |
| 並列重點（cards） | 紅緞帶標題；2～4 個小地標沿小路排開，念到哪張路就畫到哪；下方編號註記卡；最後一條印章結論 |
| 對照（vs） | 同一路口分兩條路：錯的墨色虛線＋紅叉蓋「此路不通」，對的紅色路線＋金光蓋「正確路線」；中間蠟封章 VS |
| 數字（stat） | 石碑從地面升起帶揚塵，數字刻在碑上從 0 往上數：每位數換數字時舊的往上滑出淡出、新的從下滑入淡入，約 1.2 秒、前快後慢（**不要一格一格硬換字**） |
| 隨堂測驗（quiz） | 題目卡；路口分 2～3 條路到選項；揭曉時正確的路亮紅＋金光暈＋打勾，其他變淡打叉 |
| 回顧（recap） | 左邊小地圖重畫走過的站、逐站打勾；右邊回顧清單逐條打勾；木製路標寫「NEXT 下一節」 |
| 片尾測驗（qaEnd） | 題目卡＋四個寶箱選項；揭曉時答案寶箱翻開冒金光、被紅圈圈起 |

### 四、字幕
- 畫面底部置中（y≈954），Noto Serif TC 900、深墨色粗體
- 字幕下方固定一條木桌色漸層底（y 900→1080），地圖移動時字幕後面穩定；緊接上一句時直接換字、不淡入

### 五、聲音
- 民謠吉他配樂，120 BPM、G 調；旁白期間音樂自動壓低
- 音效：換站捲紙「咻」、每個註記出現「啵」、數字與測驗「叮」

### 六、品質檢查（渲染整支之前）
- 每個場景抽 3 格：文字不超出卡片、不互相重疊、不進 y>900；圖示不能是空白或「?」
- 鏡頭連續內插、不要用取餘數造成跳回原位；大面積閃動每秒 ≤3 次；變化用 6 格以上漸變
- 旁白念到的詞，畫面同時出現

> 有 skill 時不用貼：直接說「廣R」＋給文本，照 README 挑章、寫 storyboard，`make_ad.py` 一行出片。
> 出處：showreel 母提示詞「make a dynamic 60-second motion graphics video that shows what an incredible motion designer you are, like it's your showreel for a résumé. go all out.」延伸的「廣告 30 風格」第 1 批第 09 支（終端機駭客 Terminal，《駭客軍團》片頭感，逐字見 `原始提示詞_09.txt`）；這份是把它落地成可重複的規格，並讓任何文本都能套用。

```
請把我附上的文本做成一支「駭客終端風（終端機駭客 Terminal，《駭客軍團》片頭感）」的短廣告（沒有旁白、沒有字幕），規格與規則如下，全部照做。

【要做的事】
故事裝置：一台電腦的終端機與 tmux；整支是「有人在終端機打指令查詢這個主題」，所有資訊都以指令輸出出現。提示字元 guest@主機:~$（主機名用文本裡的英文名、網域或工具名，小寫英數），指令逐字打出、在拍點上按 Enter。
先讀文本，從下面 7 種章裡挑 4～6 章（第一章一定是「開機自檢」、最後一章一定是「sudo join」，中間可任選、順序可換）：
1. 開機自檢：BIOS 自檢快速捲動（「主機-BIOS (C) 名稱」、幾行取自文本的自檢項目＋右邊綠色 PASS、琥珀色 login 行，右上 POST 進度條）→ 硬切 → 打 ./主機 --start、Enter → 「載入核心 [████░░] 100% ✓」→ 名稱用 6×7 兩格粗筆畫的 ASCII 方塊大字（實心綠格＋右下斜線陰影格＋暗點底）由左往右解碼掃描出現（掃描前緣是亂碼字元）；名稱沒有英數就用楷體大字同樣掃描 → 一行副標逐字打出（青色、字距寬）→ 全名滑入。
2. ASCII 大字＋資訊：whoami → 使用者名 → neofetch → 左邊小 ASCII 名稱掃描、右邊「使用者@主機」、分隔線、2～6 列「鍵：值」一列列從右滑入、8 色色塊 → echo $SLOGAN → 標語大字逐字打出（綠色發光＋方塊游標）。
3. ls 清單：ls -l 目錄 → total N → 2～9 列像資料夾一樣滑入（drwxr-xr-x、使用者、4096、名稱/、[標籤]、# 說明，剛出現那一列淡綠底）→ 「✓ N directories · 統計」→ 反白一列列往下掃。
4. tmux 窗格：垂直分割線從右邊推進來、水平分割線從下面推上來，把畫面切成 2～4 格，上一章的畫面留在左上格被推擠兩拍後換掉；每格同時打一個指令並輸出幾行（清單 ▸、tree ├── └──、[ OK ] 紀錄、make 的 CC … ✓＋進度條＋✓ BUILD SUCCESS），最後一行琥珀色 ★；作用中窗格（綠框綠標籤）跟拍子輪流；章末最後一格放大成全螢幕接下一章。
5. 數字查詢：cat 檔案 → 1～2 個 TUI 細框（左上嵌 [ 標籤 ]），框裡小字＋大數字吃角子老虎滾動停住＋單位 → 0～3 列小數字（單位是 % 就畫文字進度條）。
6. systemctl 狀態：systemctl status 對象 → 2～6 個服務一個個從右滑入（● 名稱.service — 說明／Active: active (running)／灰色備註，● 跟拍子閃）；右邊 [ htop ] 監控條（跟拍子跳）＋往左捲的負載折線圖、[ ping ] 視窗一行行回應。
7. sudo join：sudo join 名稱 → [sudo] password for 使用者: → 琥珀色 PASSWORD 框裡 ●●●●●● 一拍一顆 → 框變綠、驗證中進度條、3 個 ✓ 項目 → 落在拍點上 ACCESS GRANTED 大框從 1.25 倍彈到 1（反白一次）＋歡迎大字＋琥珀小字 → root@主機:~# uid=0(使用者) groups=名稱 → 整個終端機視窗在 15 格內縮成畫面中間的一個視窗（露出點陣桌面和左右兩排檔案圖示），視窗裡：ASCII 名稱掃描、標語彈上來（前半綠、後半白）、灰色副標、$ open 網址逐字打出。
先給我一張表（第幾章／章型／畫面上的字／預估秒數）讓我確認，確認後才寫程式。
數字只能用文本有的數字（不要寫 CPU 時脈、記憶體、ping 毫秒這類裝飾假數字）；所有項目、服務、驗證項目的字都要出自文本，不要編造。字放不下就改寫成名詞片語，不要縮小字。指令字（ls、tmux、cat、systemctl、sudo、clear…）與介面字（PASS、OK、BUILD SUCCESS、ACCESS GRANTED、驗證中、身分驗證…）可以保留。

【風格】
配色：終端機底 #16261f、桌面 #12201a（深綠放射漸層＋32 px 綠色點陣）、標題列 #203a2e、窗格邊框 #3d6250、磷光綠 #3dff8a、暗綠 #2a9a5c、琥珀 #ffb84d、青 #5ce1e6、白 #e8f5ec、次要 #93b8a3。
視窗：全螢幕（24,18 起 1872×868、圓角 10）、標題列 52 px（紅黃綠三圓點、「使用者@主機: ~ — 目前指令」、右邊平滑往左捲的十六進位資料流）；終端機字 32 px、行高 50 px。
字：英數 IBM Plex Mono 400／700，中文霞鶩文楷 Mono TC 400／700（串接 IBM Plex Mono → 霞鶩文楷 Mono TC → Noto Sans TC）。ASCII 方塊字與文字進度條用 div 格子畫，不靠字型的 █ ░。
畫面最下方 180 px 是靜止的 tmux 狀態列：上半是快捷鍵提示（^B % 垂直分割、^B " 水平分割、^B z 放大窗格、^B d 離開）與「session: 名稱」，下半綠條是 [主機]、每章一個視窗名（0:boot 1:ls 2:panes…），目前那一章反白，右邊網址；整支只有換章那格改高亮，其他都不動。
招牌轉場：章尾打 clear 按 Enter，整個畫面逐行由下往上加速捲走；視窗高度收成一行標題列（邊框發光），下一章再從中間展開；進 tmux 用窗格分割、出 tmux 用最後一格放大；最後整個終端機縮成 logo 視窗。章首邊框亮一下。

【節奏與聲音】
tech house 126 BPM、F 小調，一拍 14.29 格；每一章從小節頭開始、長度是整小節；指令的 Enter 落在 16 分音符上；字依讀字量（每秒 7 字，英數算半個字）決定停多久。
第一章：每兩小節換和弦的暗墊底（低通 700 Hz）＋反拍 hi-hat；第二章起四拍大鼓、第 2、4 拍拍手、反拍 open hi-hat、16 分音符反拍 closed hi-hat、切分 sub 低音（含高八度的一下）、16 分音符撥弦琶音；最後兩小節回到墊底，1.4 秒淡出。
音效：開頭重擊；換章前一小節 riser、換章那拍重擊；縮成 logo 前兩小節 riser＋重擊；每個打出來的字一聲輕鍵盤、Enter 的「咚嗒」、輸出行與數字停住的嗶、BIOS 開機嗶一聲、ACCESS GRANTED 重擊＋主和弦琶音、轉場的咻——全部對準時間表的事件。
母帶：換章那拍的大鼓與拍手降一點、打擊樂起音前 1～2.5 ms 短淡入並收一點高頻瞬間（避免 AAC 預回音突波）、開場墊底拉高讓響度範圍 < 9 LU、慢速音量騎乘、16 kHz 低通、4 倍超取樣真峰值正規化；成品響度 −14 LUFS、真峰值 ≤ −3 dBTP。

【程式規則】
1. 先寫一份時間表（每一章第幾格開始、用哪種轉場、每一行指令開始打字與按 Enter 的拍點、每一行輸出登場的拍點、音效事件），畫面與配樂都只讀這份表。
2. 每一格的畫面只由「格數」算出來（不要 CSS transition、計時器、Math.random；亂數用固定種子）。
3. 數字一律用滾動（舊數字往上滑出、新數字從下滑入），不要逐格硬換。
4. 大面積閃光每秒最多 3 次（ACCESS GRANTED 只反白一次、4 格）；不要整片微幅呼吸縮放。
5. 下方 180 px 的狀態列整支不動；clear 捲動只捲視窗裡的內容。
6. 版面依字數自動算：每個欄位有字級上下限，縮到下限還放不下就停下來告訴我哪個欄位太長、最多約幾字。
7. 中文字型只載入用到的字；做完排一張「全字測試圖」（每種字型單獨與串接各排一次）確認沒有缺字。
8. 先出 12～24 張抽格總覽給我看（每章中段、每個換章點前後），再整支算圖；1920×1080、30 fps。
```

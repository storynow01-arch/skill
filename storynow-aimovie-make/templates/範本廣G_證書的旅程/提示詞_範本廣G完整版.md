# 提示詞：範本廣G 完整版（證書的旅程）

> 在沒有這個 skill 的地方，把下面整段貼給 AI，再附上你的文本，就能做出同風格的影片。
> 有 skill 時不用貼：直接說「廣G」＋給文本，照 README 寫 storyboard，`make_ad.py` 一行出片。

```
請把我附上的文本做成一支「水彩繪本・證書的旅程」廣告影片（沒有旁白、沒有字幕），規格與規則如下，全部照做。

【要做的事】
先讀文本，決定「看完要記得哪一句」，把能上畫面的東西分給繪本裡的位置：
  紙片主角上的字（6 字內，例：證書、入場券、會員卡）、
  開場房間：左上小字（18 字內）、大標（9 字內）、右上 0～2 行小字（13 字／10 字內）、
  1～4 道門：每道門一個印章（1～2 行、每行 4 字內）＋小圓章 1 字＋蓋章後的紅色大字（9 字內）與上方小字（例：第一關），
    門上方三選一：一句話（12 字內）、一條等式（例：會員卡＝免費加入＝生日再送一杯，整條 23 字內，最後一段蓋章後才寫）、或左邊一間掛招牌的小屋（11 字內），
  最後塗鴉牆：名稱（一格一字的塗鴉卡；6 字內一排、7～10 字兩排、更多改一張橫幅）、紙片的對話泡泡（8 字內）、標語（20 字左右）、網址或電話。
門數可以 1～4 道；除了紙片上的字、大標、每道門的印章、牆上名稱，其他都可以不放。
先給我一張表（每頁畫面上的字、預估秒數）讓我確認，確認後才寫程式。只講一件事；字太長就改寫；不要編造文本沒有的事。

【故事（桌上一本攤開的水彩繪本，一個跨頁一個場景，換場只用翻頁）】
開場：房間角落（矮書櫃、書、盆栽、檯燈、地上的坐墊、右邊有窗簾的窗戶），一張有眼睛、會臉紅的紙片睡著冒 Zzz；
  蠟筆一個字一個字寫出大標 → 紙片醒來伸懶腰、抬頭看右上小字被寫出來、飄起來飛到窗邊 →
翻頁：右頁先翻起來（3D 翻頁、書頁投影），紙片晚 8 格才被翻頁的風帶過去，先往左上甩、再落到新頁面的等候點 →
每一道門：上方的字寫出來，拱門（彩色拱框、藤蔓小花、圓門牌寫第幾道）兩片門板打開、門後發光，
  紙片飛過門（穿過時一圈光環＋彩色小點），停到門右邊、一臉擔心 → 木頭印章從畫面上方砸下來「咚」（紙片被壓扁、印章有 3 層殘影、
  鏡頭先推近再在拍點上震一下）→ 紅色章印（圓章或方章、印泥顆粒）停 1.4 秒讓字讀清楚，這時紙片的臉淡掉 →
  章縮成小圓章收進紙片底下的虛線格子 → 紙片開心跳起來轉一圈 → 紅蠟筆寫出這一關的大字（或等式補上最後一段）→ 翻頁。
  最後一道門是高潮：門更大、多等一拍、章更大、水彩紙花炸開。
最後一頁塗鴉牆：牆上本來就貼著四張塗鴉（房子、太陽、花、彩虹），紙片飛到正中央被兩條紙膠帶貼上，
  名稱一格一字的塗鴉卡從兩側旋轉飛上來（每張卡不同底色、角落一個小塗鴉、頂端紙膠帶），紙片害羞地說出對話泡泡，
  上方寫標語、下方寫網址；大和弦時再撒一次紙花，紙片跟著拍子輕晃，鏡頭慢慢拉遠。
紙片全程有表情：睡覺、眨眼、看向正在寫的字、擔心、開心、害羞（波浪嘴）；紙邊隨飛行速度波動，快速移動畫 4 層漸淡殘影（不用 blur）。
鏡頭延遲跟隨紙片（取過去 14 格的平均位置），開場與最後一頁收回正中。

【版面與風格】
桌面 #EFE2CD（放射漸層）、散著幾支蠟筆與便條紙；書皮 #E8A6A0、跨頁 1680×900 放在 (120,70)、中間有書溝陰影。
水彩背景用程式畫（紙紋＋暈染＋邊緣積色＋顆粒）：房間奶油黃牆與薄荷綠地板、藍天綠丘、粉色黃昏、晴空淡彩虹、薄荷晨光淡紫丘、塗鴉牆奶油底與彩色圓點。
字型：繪本圓體 HachiMaruPop；它是日文字型會缺繁體字，串接霞鶩文楷 TC → Noto Sans TC 補字，先排一張全部用字的測試圖確認；中文字型只載入用到的字。
蠟筆字用顆粒遮罩，每個字從大一點、歪一點、低一點彈到定位。章紅 #D9483B。

【節奏】
90 BPM，一拍 20 格、一小節 80 格（30 fps）。蓋章、翻頁、收尾落在拍點上；翻頁 44 格。
片長由內容決定：開場約 6～7 秒、每道門約 6 秒（最後一道多 0.7 秒）、塗鴉牆約 8～9 秒，再依字數加停留（3 道門約 35 秒）。

【配樂（numpy 合成，聲音和畫面讀同一份時間表）】
F 大調（F–Dm–Bb–C–F–Am–Bb–C），每小節看它落在哪一頁決定配器：開場音樂盒獨奏 → 第一道門加撥弦低音、豎琴分解和弦、沙鈴
→ 第二道門起加輕柔弦樂 → 最後一道門弦樂變厚、旋律高八度 → 塗鴉牆音樂盒主題回來 → F add9 溫暖大和弦（弦樂＋音樂盒上行）淡出。
音效：醒來鈴鐺上行、飄起來的小風、翻頁沙沙（聲像右到左）＋風、門開豎琴、穿過門的亮晶晶、蓋章前兩拍弦樂顫音漸強 →「咚」＋小鈴鐺，
高潮章前四拍定音鼓滾奏＋反向鈸 → 咚＋鈴聲琶音＋弦樂齊奏；貼上輕咚、塗鴉卡每張一個噗＋鈴聲上行、小小掌聲、害羞兩個音樂盒音、眨眼極輕的啵、蠟筆寫字沙沙。
混音最後做前瞻峰值限幅（只壓最尖的幾毫秒），響度 −14 LUFS、峰值 −2 dBTP 以下。

【程式規則】
1920×1080、30 fps；每一格只由格數決定（不用 CSS 動畫、計時器、Math.random）。
翻頁、門開、穿過、蓋章、寫字、塗鴉卡、眨眼的格數全部先在時間表裡算好，畫面只照表畫，配樂讀同一份。
所有字不可以超出頁面或印章；字太長就改寫，不要縮小到看不清。
交付前用連續格檢查上面每一個動作（尤其翻頁時紙片晚一拍、每一次蓋章、章縮進格子、塗鴉卡飛上牆）。
```

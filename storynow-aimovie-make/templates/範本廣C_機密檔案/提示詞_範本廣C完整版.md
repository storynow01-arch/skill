# 提示詞：範本廣C 完整版（機密檔案）

> 在沒有這個 skill 的地方，把下面整段貼給 AI，再附上你的文本，就能做出同風格的影片。
> 有 skill 時不用貼：直接說「廣C」＋給文本，照 README 寫 storyboard，`make_ad.py` 一行出片。

```
請把我附上的文本做成一支「機密檔案」廣告影片（沒有旁白、沒有字幕），規格與規則如下，全部照做。

【要做的事】
先讀文本，整理成一份「任務」：任務名稱、地點或目標（要被紅筆圈起來的那段字）、一句任務內容、
（可選）出發點→目的地與一句說明、（可選）2～3 個線索（亮點，每個 8 字內）、（可選）2 項準備事項、
最後的結論（通知標題＋一句話＋2 字印章，例：核准、錄取、通過、報到）、名稱、標語、網址。
先給我一張表（每份文件上的字、預估秒數）讓我確認，確認後才寫程式。只講一件事；字太長就改寫；不要編造文本沒有的事。

【故事（一個連續的俯拍桌面，不剪接）】
檯燈亮起（從半暗到亮）→ 牛皮紙檔案夾從左邊滑進來落在桌上 → 木柄印章從空中落下（越近越大、影子變深），蓋下紅色「極機密」，木柄抬走 →
紅色封條上下撕開 → 封面以左邊為軸 3D 翻開 → 文件一份份被抽出來攤在桌上（快的時候畫 4 層逐漸透明的紙片殘影，落桌時影子變小）：
  任務簡報：打字機逐字打出（剛打下的字略重再沉下去、每字墨色深淺略不同），紅筆把重點圈起來、在另一行畫底線 →
  目標地圖：抽象陸塊＋格線＋指北針，紅色虛線航線從出發點一路畫到目的地，圖釘按下 →
  線索：兩張拍立得（幾何插圖、底下手寫說明逐字寫出）、一張便利貼從上方掉下來（手寫＋小箭頭），迴紋針夾上 →
  偵探牆：每張線索上按圖釘，紅線從目的地拉到每張線索；鏡頭拉遠框住整面牆 →
  裝備清單：打字、兩個方框逐條打勾 →
  最後一份通知從下方滑進來：音樂抽空只剩低音提琴，時鐘滴答越來越快、刷鼓滾奏上升；木柄大印章落下蓋「核准」，鏡頭重擊＋震動，全樂團爆發 →
所有文件依序收回檔案夾、封面闔上 → 封面蓋上名稱章、打字打出標語與網址。
主角：一支紅桿鋼筆（俯視，金色筆尖與夾子）——畫圈、畫底線、畫航線、手寫、打勾都是它；不寫字時懸在下一個重點旁邊，
抬筆時筆身略大、影子拉開；最後轉個角度躺在封面右側。背景比前景早一步動（鏡頭先移、文件後到）。

【版面與風格】
木桌（深淺木紋條）、牛皮紙 #c9a46c、紙 #f3ecdb、紅 #c1272d、便利貼 #f4d34c；檯燈：中心暖光、四周暗角；燈光下有浮塵慢慢飄。
字型：英文打字機 Special Elite（中文退回宋體）、手寫霞鶩文楷 TC、印章用粗宋體 900（印章有內外框、斑駁沒吃滿的印泥）。
拍點（落桌、蓋章、圖釘、迴紋針、闔上、名稱章）整個畫面推一下 1.5～7%。

【節奏】
100 BPM，一拍 18 格（30 fps）。開場檔案夾約 4 秒；每份文件進場＋打字 2～4 秒（打字每字 2～4 格）；蓋章前抽空約 3 秒；收回闔上＋封面約 4 秒；
再依畫面上的字數加停留（每 6 字半拍）。片長由內容決定（約 25～40 秒）。

【配樂（numpy 合成，聲音和畫面讀同一份時間表）】
冷爵士：低音提琴 walking bass（Dm9–B♭maj7–Gm7–A7♭9）、刷鼓＋ride（搖擺）、電鋼琴、鐵琴；線索段加弱音小號主題；
拉遠時銅管漸強一小節；通知段抽空（只剩低音每拍一下、時鐘滴答加速、刷鼓滾奏、上升音）；蓋章那一刻銅管齊奏＋鈸＋大鼓；
闔上齊奏重音；最後 ba-DUM 收尾。音效：檯燈開關、紙張滑動、落桌、蓋章、撕封條、打字機每字＋行尾叮＋回車、筆刷、圖釘、迴紋針。
響度 −14 LUFS、峰值 −2 dBTP。

【程式規則】
1920×1080、30 fps；每一格只由格數決定（不用 CSS 動畫、計時器、Math.random）。畫面最下面 180 像素不要放逐字出現的字。
交付前用連續格檢查上面每一個動作，並確認紅筆圈與底線對準字、沒有字超出紙張。
```

# 科目包

skill 本體（SKILL.md、engine、templates）只放**所有科目都適用的規則**；某一科才用得到的東西放這裡，一科一個資料夾。

## 一個科目包有什麼

| 檔案 | 內容 | 誰會讀 |
|---|---|---|
| `README.md` | 這科的教法、專用場景怎麼用、踩過的坑、做過的影片 | 做這科影片前 Claude 先讀 |
| `念法.json` | 這科專用的 edge-tts 念法（`"寫法": "念法"`） | `build.py`：storyboard 寫 `"subject": "<科目>"` 時併入全域詞典 |

## 怎麼用

storyboard 頂層加一行（值＝這裡的資料夾名稱）：

```jsonc
{ "subject": "數位邏輯設計", "style": "...", "scenes": [ ... ] }
```

沒寫 `subject` 就只用全域詞典（`engine/scripts/pron_zh-TW.json`），跟以前一樣。

## 新增一個科目

1. 複製 `程式設計實習/`（空白模板）改成新科目名稱
2. 做第一支影片時把遇到的念法、教法、坑補進去
3. 要新增畫面場景（例如卡諾圖）：程式寫在範本裡（`engine/template/src/tpl/Template<代號>.tsx`），**用法寫在科目包的 README**，範本 README 只留一行指過來

## 判斷放哪裡

| 放全域（skill 本體） | 放科目包 |
|---|---|
| 每科都會遇到：網址寫法、年份數字、IP 逐字念、`say` 另寫念法的機制 | 只有這科有：AB／BC／CD 拆字母、格雷碼念法、卡諾圖畫法、這科的專業詞庫 |

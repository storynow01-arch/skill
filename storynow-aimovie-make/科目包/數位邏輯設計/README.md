# 科目包：數位邏輯設計

storyboard 加 `"subject": "數位邏輯設計"`。

## 教法（2026-10-08，依使用者自己錄的解題影片）

第一版照課本講（用 m 編號找格子），學生看不懂。改成使用者的教法：

1. **從布林式開始**：每一項換成 0／1（有上橫線寫 0）→ 場景 `terms`
2. **用座標找格子**：左邊找列、上面找行，交叉處寫 1；不用 m 編號 → `kmap` 的 `place`
3. **逐個變數比對**：圈裡的格子，不變的變數「保留」、有跳動就「淘汰」，再從圈畫箭頭寫結果 → 場景 `readTable`＋`kmap` 的 `arrow`

反相寫法：畫面用**上橫線**（term 寫 `A'B`，畫成字母上方橫線）；字幕與旁白用「A bar」，**bar 念四聲「霸」**（`念法.json` 已設，2026-10-09 使用者指定）。

## 專用場景（程式在範本D：`engine/template/src/tpl/TemplateD.tsx`）

| 場景 | 畫面 |
|---|---|
| `kmap` | **卡諾圖**：先畫格子＋左上斜線與變數名 → 橘色格雷碼標頭 → 格子左上小字編號 m0…（依格雷碼順序一格一格寫）→（選用）左邊真值表 → 依編號由小到大填 1（紅）／X（藍）／0（灰）→ 各組用不同色馬克筆圈起來（跨邊界自動拆兩段、往外多畫一截表示接到另一邊）→ 化簡結果逐項寫出（顏色同圈；沒有真值表時寫在格子右邊直排）。格子照手畫順序（外框 → 中間十字 → 細分） |
| `terms` | **布林式換成 0／1**：上方寫整條式子（有上橫線），下方每一項一張粉彩卡，字母在上、對應的 0／1 寫在正下方（1 紅、0 藍），底下一行規則 |
| `readTable` | **逐個變數比對**：把圈裡每一格的 0／1 列成表，一欄一欄看——都一樣就寫保留的字母（0 加上橫線，綠色）＋「保留」，有跳動就打紅叉＋「跳動淘汰」，最後「→ 這一圈的項」 |

**kmap 的 props**：`rows`／`cols`（格雷碼字串，例 `["0","1"]`、`["00","01","11","10"]`）、`rowVar`／`colVar`（例 `"A"`、`"BC"`）、`showIndex`、`ones`／`dc`（最小項編號）、`zeros`（`false`＝空格不寫 0）、`table`＋`varNames`＋`fn`、
`groups: [{cells: [最小項…], term: "A'B", cue, color, termCue, arrow}]`（`termCue`＝先圈、講完才寫結果；`arrow: true`＝從圈畫箭頭到右邊那一項）、`place: [{code: "0001", cue}]`（照座標填 1：左邊列標、上面行標各畫一條紅底線，交叉的格子寫 1）、`note`；
時機用 `gridCue`／`headCue`／`indexCue`／`tableCue`／`fillCue`／`noteCue`（第幾句旁白），速度用 `indexStep`／`fillStep`（格數）；`cell` 指定格子大小（預設 4 格＝170、8 格＝150、16 格＝118）。

**terms 的 props**：`terms`、`fn`、`exprCue`、`termCues`、`rule`、`ruleCue`
**readTable 的 props**：`vars`、`codes`、`label`、`color`、`rowsCue`、`verdictCues`、`termCue`

## 念法

- `念法.json`：AB／BC／CD 逐字母念（edge-tts 會把連寫當單字）
- **格雷碼、二進位一律另寫 `say`**：`{"text": "…00、01、11、10…", "say": "…零零、零一、一一、一零…"}`（edge-tts 會把 10、11 念成「十」「十一」）
- 一長串編號（0、1、3、2…）`say` 改中文數字，語音辨識比對才不會誤判必修

## 踩過的坑

- 語音辨識會把單獨的英文字母聽成中文近音字（比、低、把）→ 品檢報必修時先用耳朵確認，確定是誤判才 `--force`
- `final_qa.py` 的 `--text` 要給檔案路徑；`--terms` 不要放單一字母（會當掉）
- `final_qa` 的唸法比對（F9）對 AB／BC／CD 仍會提醒（它單獨合成這幾個詞、沒套詞典），實際旁白已套，人耳確認即可
- 要示範「用電腦驗算」：中間插一段範本H（終端機 `python check.py`），用 splice 接片（場景交界切開、0.5 秒交叉淡化、剪掉 H 頭尾黑場）
